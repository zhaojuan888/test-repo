## 审计方法地图（专题串联）

> 把本库三大审计专题按「**行业 → 循环 → 交易真实性**」三个维度串成一张方法地图，进任何审计/尽调项目都能按图取程序。

- **行业审计对照**（企业规范 ↔ 审计风险点 镜像）：[[行业审计对照/index]] — 房地产业（含长兴新农都 FDD 衔接）+ 保险业 CAS-25
- **IPO 审核关注要点**（六大内控循环）：[[IPO审核关注要点/index]] — 销售收款 / 采购付款 / 存货生产 / 资产管理 / 资金活动 / 研发
- **贸易真实性与融资性贸易**：[[贸易真实性与融资性贸易/index]] — 四流合一 / CAS-14 总额净额 / 长兴新农都贸易合同核查
- **税控地图**（税务合规全景，跨行业）：[[税控地图]] — 税种合规 / 金税四期发票 / 优惠骗享 / 稽查处罚 / 行业特殊（FDD 税务取数路径）

**串联逻辑（怎么用这张地图）：**
1. 进一个**行业**项目（如长兴新农都·房地产）→ 先看「行业审计对照」定位该行业特有风险点；
2. 按风险点映射到**内控循环**（「IPO 审核关注要点」）→ 取对应通用控制点与审计程序；
3. 凡涉及**贸易/收入**合同 → 叠加「贸易真实性与融资性贸易」的四流合一 + 总额净额判断，防融资性贸易。
