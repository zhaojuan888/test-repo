# 准则条文库

> 企业会计准则（CAS）体系 — 按准则号自动聚合

## 已收录准则

```dataview
TABLE topic AS "准则主题", key_judgment AS "关键判断", cases AS "关联案例"
FROM "2-知识库/会计准则"
WHERE type = "concept"
SORT standard ASC
```

## 需要补充案例的准则

```dataview
TABLE topic AS "准则", file.mtime AS "最后更新"
FROM "2-知识库/会计准则"
WHERE length(file.outlinks) < 3
SORT file.mtime ASC
```
