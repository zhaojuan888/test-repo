# 处罚案例 → 执业应对手册

> 每一类处罚问题，回答四个问题：**① 该做什么（程序与方法）② 做到什么程度（勤勉尽责边界）③ 怎么预防（事前机制）④ 反面案例（谁栽了）**。
> 核心不是"事后检测出问题"，而是"事前预防 + 事中做够"，让自己不踩同样的坑。

---

## 一、收入确认（第一高频）

### 1. 总额法 / 净额法判断失误

| 维度 | 内容 |
|------|------|
| **反面案例** | 紫天科技虚增 18.7 亿（吊销 CPA）；普利制药（罚 630 万）；星光农机（警示函） |
| **该怎么做** | 逐笔验证五指标：①首要责任 ②存货风险 ③定价权 ④信用风险 ⑤实物控制 |
| **做到什么程度** | 每笔无控制权业务，底稿必须有"五指标逐项判断表"，不能一句"采用总额法"带过；判断结论要可复核 |
| **怎么预防** | 收入确认政策底稿**模板化**——强制列五指标判断表；贸易/代理类业务默认按净额法评估，除非有充分证据 |

### 2. 红字冲销异常

| 维度 | 内容 |
|------|------|
| **反面案例** | 普利制药全年冲销占营收 23%、虚构收入 37% 红字冲回 |
| **该怎么做** | 逐笔核查冲销原因、是否期后重新确认（循环冲销）、对应原始凭证 |
| **做到什么程度** | 全年红字冲销 > 营收 10%，必须编制冲销明细并追查至结论，不得只列金额 |
| **怎么预防** | 分析程序里加"红字冲销占比"指标，超阈值自动预警；年末冲销笔笔留痕 |

### 3. 客户频繁更换 / 全链条伪造

| 维度 | 内容 |
|------|------|
| **反面案例** | 华道生物两年三次换客户（29家→7家→3家）；广道数字六年虚增 87-99%（暂停证券业务 6 个月） |
| **该怎么做** | 穿透核查新老客户工商信息 + 现场走访 + 回款来源追溯；函证全程控制 |
| **做到什么程度** | 报告期客户更换 ≥ 2 次 → 必须穿透到"谁、为什么、资金从哪来"；函证不得由被审计单位代发代收 |
| **怎么预防** | 建立"客户名单连续性"监控——新旧客户对比是固定分析程序；函证独立性是红线 |

## 二、存货

### 4. 存货 / 收入增长背离

| 维度 | 内容 |
|------|------|
| **反面案例** | 江平生物存货 +246% vs 收入 +9.26% |
| **该怎么做** | 比率分析 + 盘点日至报表日变动双向测试（出入库单 + 物流单据） |
| **做到什么程度** | 存货增速远超收入增速时，必须核查期间全部出入库记录，不能只抽少量合同 |
| **怎么预防** | 存货增长率 vs 收入增长率作为固定比率分析项；盘点日≠报表日时强制双向测试 |

---

## 三、内控与程序（"形式化"是共性病根）

### 5. 穿行测试形式化

| 维度 | 内容 |
|------|------|
| **反面案例** | 庚星股份无验收资料/出库单却认定内控有效（罚 99 万） |
| **该怎么做** | 每个控制环节必须取得**实际运行证据**；新增业务独立评估，禁止类比旧业务 |
| **做到什么程度** | 无证据 = 未执行。穿行测试每一环节都要有对应单据，缺一项就标记为内控缺陷 |
| **怎么预防** | 穿行测试清单化——逐环节勾选"已取得证据 / 未取得"；新增业务走独立风险评估 |

### 6. 利用专家工作未复核

| 维度 | 内容 |
|------|------|
| **反面案例** | 海钦股份未复核评估专家预测 → 高估可收回金额、少计减值（警示函，同所同客户连续两年被罚） |
| **该怎么做** | 专家估值关键假设（收入预测/折现率/折扣率/留抵税额）逐项与历史数据、合同条款对账 |
| **做到什么程度** | 复核轨迹三步留痕：假设来源 → 对比基准 → 复核结论；"利用专家"≠"抄数字进底稿" |
| **怎么预防** | 专家工作复核模板化（关键假设逐项核对表）；税务口径假设也纳入复核，不默认"专家说了算" |

### 7. 两套系统 / 底稿异常未追查

| 维度 | 内容 |
|------|------|
| **反面案例** | 普利制药两套软件系统数据重大差异，底稿已记载却未核实 |
| **该怎么做** | IT 审计比对两系统同科目金额；底稿任何异常标注必须追查到明确结论 |
| **做到什么程度** | 底稿已记载异常 → 必须有对应追查结论，否则 = 未勤勉尽责 |
| **怎么预防** | 建立"异常 → 追查 → 结论"闭环台账；底稿复核时专门检查"有没有悬而未决的异常标注" |

## 四、结果可控（质控底线，最不能破）

| 维度 | 内容 |
|------|------|
| **反面案例** | 紫天科技隐匿/伪造底稿 → 吊销 CPA；普利制药罚 630 万；中兴财光华全所停业 12 个月 |
| **该怎么做** | 底稿真实完整，禁隐匿/篡改/事后补编；关键结论双人复核；全程留痕 |
| **做到什么程度** | 每个事项六栏闭环：异常描述 → 已执行程序 → 获取证据 → 追查结论 → 定级 → 复核人 |
| **怎么预防** | 把"底稿真实"当执业红线而非合规要求；质控内核失效是最高频处罚点，承接续任业务先回顾前年处罚 |

---

## 共性规律（三个"病根"）

1. **形式化**：庚星（穿行）、海钦（专家复核）——有程序但无实质，是最大病根
2. **职业怀疑缺失**：广道（六年不疑）、普利（两套系统不疑）——异常摆在眼前却不追
3. **证据不闭环**：紫天（无证据认定内控）、江平（不查期间变动）——下了结论却没证据支撑

**预防总纲**：把以上每一条"做到什么程度"变成**底稿模板的必填项**，让"做够"成为流程默认，而不是靠自觉。
