##  学习连续天数

```dataviewjs
const pages = dv.pages('"6-每日笔记"')
  .where(p => p.learned === true)
  .sort(p => p.file.name, 'desc');

let streak = 0;
const today = dv.date("today");
for (let p of pages) {
  const d = dv.date(p.file.name);
  if (!d) continue;
  const diff = today.diff(d, 'days').days;
  if (diff === streak) { streak++; }
  else { break; }
}
dv.span(`**${streak} 天连续学习**  ${streak >= 7 ? '' : ' 目标: 7 天'}`);
```

##  复习队列（按最久未看排序）

```dataview
TABLE type AS "类型", category AS "分类", file.mtime AS "上次修改", (date(today) - file.mtime).days AS "未看天数"
FROM "2-知识库"
WHERE status != "archived"
SORT file.mtime ASC
LIMIT 10
```
