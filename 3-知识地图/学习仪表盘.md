##  学习连续天数

```dataviewjs
const pages = dv.pages('"6-每日笔记"')
  .where(p => p.learned === true)
  .sort(p => p.file.name, 'desc');

let streak = 0;
const today = dv.date("today");
for (let p of pages) {
  const d = dv.date(p.file.name);
  if (!d) continue;
  const diff = today.diff(d, 'days').days;
  if (diff === streak) { streak++; }
  else { break; }
}
dv.span(`**${streak} 天连续学习**  ${streak >= 7 ? '' : ' 目标: 7 天'}`);
```

## 考点覆盖（主动回忆追踪）

> 数据来自 [[2-知识库/税法/每日税务知识卡#📝 考点自检清单（57 点覆盖）]]。每日「考点自测」考到即勾选 `- [x]`，你自评为模糊改 `- [/]`，确保每条都复习到。

```dataviewjs
const file = await dv.io.load("2-知识库/税法/每日税务知识卡.md");
const lines = file.split("\n");
let total=0, done=0, fuzzy=0, todo=0;
const fuzzyList=[];
for (const l of lines) {
  const m = l.match(/^\s*- \[([ x\/])\]\s*(.+?)\s*(<!--测于.*-->)?$/);
  if (m) {
    total++;
    if (m[1]==="x") done++;
    else if (m[1]==="/") { fuzzy++; fuzzyList.push(m[2]); }
    else todo++;
  }
}
dv.paragraph(`**已测 ${done} ／ 待测 ${todo} ／ 模糊 ${fuzzy}**（共 ${total} 点）`);
if (fuzzyList.length) dv.paragraph("**待巩固（模糊）：**\n- " + fuzzyList.join("\n- "));
```
