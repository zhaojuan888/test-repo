# 学习仪表盘

> 每日进步一点。Dataview 自动驱动，不手动维护。

---

##  学习连续天数

```dataviewjs
const pages = dv.pages('"6-每日笔记"')
  .where(p => p.learned === true)
  .sort(p => p.file.name, 'desc');

let streak = 0;
const today = dv.date("today");
for (let p of pages) {
  const d = dv.date(p.file.name);
  if (!d) continue;
  const diff = today.diff(d, 'days').days;
  if (diff === streak) { streak++; }
  else { break; }
}
dv.span(`**${streak} 天连续学习**  ${streak >= 7 ? '' : ' 目标: 7 天'}`);
```

##  本周学习记录

```dataview
TABLE learned_topic AS "主题", reviewed_count AS "复习篇数"
FROM "6-每日笔记"
WHERE file.day >= date(today) - dur(7 days) AND learned = true
SORT file.day DESC
```

## 🤖 本周 AI 技能学习

```dataview
TABLE ai_skill AS "技能", learned AS "完成"
FROM "6-每日笔记"
```

##  复习队列（按最久未看排序）

```dataview
TABLE type AS "类型", category AS "分类", file.mtime AS "上次修改", (date(today) - file.mtime).days AS "未看天数"
FROM "2-知识库"
WHERE status != "archived"
SORT file.mtime ASC
LIMIT 10
```

##  知识盲区检测

### 链接少于 2 条的孤立笔记

```dataview
TABLE type AS "类型", file.mtime AS "创建日期"
FROM "2-知识库"
WHERE length(file.outlinks) < 2 AND status != "archived"
SORT file.mtime ASC
LIMIT 5
```

### 还没有关联案例的准则

```dataview
TABLE file.mtime AS "最后更新"
FROM "2-知识库/会计准则"
WHERE length(file.outlinks) < 2
SORT file.mtime ASC
```
