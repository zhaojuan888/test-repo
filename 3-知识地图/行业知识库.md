# 行业知识库

## 行业风险因子

```dataview
TABLE risk_factors AS "风险因子", related_cases AS "关联案例"
FROM "2-知识库/行业研究"
WHERE type = "industry"
SORT file.mtime DESC
```

## 科创板 / 创业板定位核查
