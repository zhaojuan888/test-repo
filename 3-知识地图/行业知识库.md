# 行业知识库

> 医药/制造/建安/贸易 — 行业风险因子 + 可比公司 + IPO 审核重点

## 行业风险因子

```dataview
TABLE risk_factors AS "风险因子", related_cases AS "关联案例"
FROM "2-知识库/行业研究"
WHERE type = "industry"
SORT file.mtime DESC
```

## 科创板 / 创业板定位核查

TABLE topic AS "核查维度", key_indicators AS "关键指标"
