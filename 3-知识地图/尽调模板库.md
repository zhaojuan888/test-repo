# 尽调模板库

> FDD 财务尽调流程 + 模板 + 经验沉淀

## FDD 流程模板

```dataview
TABLE phase AS "阶段", key_procedures AS "关键程序"
FROM "2-知识库/审计程序"
WHERE contains(tags, "FDD") AND type = "procedure"
SORT phase ASC
```

TABLE industry AS "行业", report_type AS "报告类型"
