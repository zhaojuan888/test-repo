# 税控地图

> **企业税务合规全景导航**。骨架参考中国注册税务师协会（CCTAA）法律法规库「智能图表」工具集（威科 Wolters Kluwer 承建）：各税种申报工具、税率查询、中国对外税收协定对比、外籍个税纳税义务判定、发票合规助手、大企业税务风险分析及防控指引、财务报表/合并报表模板、审计准则指引。
>
> **审计/尽调视角定位**：我们不是去报税，而是①**识别企业税务风险**（金税四期预警、稽查重点）、②**验证计税准确性**（税率/税基/优惠适用）、③**评估合规缺口**（申报 vs 账面 vs 合同 vs 资金）。合规口径以法规原文为准，本图只做"定位 + 取程序路径"。

## 一、税控地图总览（怎么用这张图）

税控全景分**六大模块**，审计取数从"行业风险 → 税种 → 程序"逐层下钻：

| 模块 | 核心问题 | 主要工具/入口 |
|------|----------|----------------|
| ① 税种合规 | 该交什么税、交多少、口径对不对 | 各税种申报工具 / 税率查询 |
| ② 发票与金税四期 | 发票真不真、四流一致不一致 | 发票合规助手 / 四流合一 |
| ③ 税收优惠 | 享受的优惠是否合规、有没有骗享 | 研发加计扣除 / 高新小微 |
| ④ 跨境与特别纳税 | 关联交易、协定待遇是否合规 | 税收协定对比 / 同期资料 |
| ⑤ 稽查与处罚 | 被查风险、裁量区间 | 稽查重点 / 裁量基准 |
| ⑥ 行业特殊 | 所在行业特有税种风险 | 土增税 / 不动产租赁等 |

## 三、金税四期与发票合规（发票合规助手 → 四流一致）

- **金税四期**：税务 + 银行 + 工商 + 社保 + 海关数据联网，自动比对私户流水、进销项品类、税负率。
- **发票合规助手**（威科 smartChart）：发票商品编码（税收分类编码）校验、进销项匹配度分析。
- **与审计主线同源**：四流合一（合同流/发票流/货物流/资金流）正是 [[审计程序/贸易真实性与融资性贸易/index|贸易真实性核查]] 的核心。凡涉收入/成本合同，先过"四流一致 + 总额净额判断"再谈计税。

```dataview

FROM "2-知识库/税法"
WHERE contains(tags, "金税四期")
SORT file.name ASC
```

## 四、税收优惠与研发加计扣除

- 常用优惠：高新技术企业（15% 税率）、小型微利（所得额减免）、西部大开发（主营≥60%）、研发加计扣除（100%）、六税两费减半。
- **骗享是稽查重点**：收入占比/人员/费用口径任一不达标即补税+滞纳金（重药控股补税 7600 万案例）。
- **审计四口径交叉**：会计利润 / 高新口径 / 加计扣除口径 / IPO 口径逐项调节（见 [[审计程序/IPO审核关注要点/研发循环]]）。

> 深度明细（研发加计扣除标签聚合）见 [[税务专题库]]「研发费用加计扣除」段。

## 五、跨境与特别纳税调整

- **转让定价**：同期资料（主体文档/本地文档/特殊事项文档），追溯期最长 10 年（蓝帆医疗跨境补税 1.96 亿案例）。
- **工具**：CCTAA 智能图表「中国对外税收协定对比表」「新个税外籍在华纳税义务判定工具」「大企业税务风险分析及防控指引」。
- 涉外合同/关联交易是 FDD 高风险区，需单独评估协定待遇与反避税（CFC、受控外国企业、离岸架构）。

## 七、行业特殊税务风险（房地产 → 长兴新农都）✅

- **土地增值税**：非房地产开发企业（如长兴新农都商铺转让/返租）**不得加计扣除 20%**，仍按转让环节据实申报，不适用预征制（见 [[土地增值税征管口径-2026年第3号公告]]「与长兴新农都的关联」）。
- **不动产租赁 5%**：售后包租返租模式租金/停车费按 5% 简易计税（见 [[2026不动产出租停车费-5%征收率口径]]）。
- **房产税 + 城镇土地使用税**：自用/出租房产计税差异（见 [[房产税与城镇土地使用税]]）。
- 行业对照与审计程序：[[审计程序/行业审计对照/房地产业-企业财务规范对照]]（含长兴新农都 FDD 衔接段）。

## 八、审计/尽调视角导航（FDD 取程序路径）

> 像 [[审计程序库]] 的「审计方法地图」那样，把税务风险串成可执行的取数路径：

1. **进行业** → 看 [[审计程序/行业审计对照/房地产业-企业财务规范对照|行业审计对照]] 定位特有税种风险（如房地产→土增税）；
2. **定税种** → 按本图第二节映射该行业的税种清单与库内笔记；
3. **验计税** → 取税率/税基/优惠适用，比对「申报表 vs 账面 vs 合同 vs 资金」；
4. **查合规** → 过金税四期预警点（四流一致、私户、税负率）与稽查重点；
5. **出结论** → 风险等级 + 补税敞口 + 披露建议，并入 FDD 报告税务章节。
