## 政策有效期 · 到期倒计时总表 ⏳

> 自动聚合 `2-知识库/税法` 下所有带有效期字段的笔记，按失效日升序**实时倒计时**。本表与 [[税控地图]] 第九节、月度复核自动化联动：status=expired 的会被清出税控地图并归档至 `7-归档/`，确保"只留有效、到期可见"。
>
> 字段约定（tax_clause 模板）：`status`（effective/pending/draft/sunset/expired）、`effective_date`、`expiry_date`（空=长期）。

### ① 全部带失效日条目（实时倒计时，按失效日升序）

```dataview
TABLE
  status AS "状态",
  effective_date AS "施行",
  expiry_date AS "失效",
  choice(date(expiry_date) >= date(now), (date(expiry_date) - date(now)).days + " 天", "⚠️已过期") AS "剩余"
FROM "2-知识库/税法"
WHERE file.name != "index" AND expiry_date
SORT date(expiry_date) ASC
```

### ② 待生效条目（未到施行日）

```dataview
TABLE
  effective_date AS "施行日",
  expiry_date AS "失效日",
  note AS "备注"
FROM "2-知识库/税法"
WHERE file.name != "index" AND effective_date AND date(effective_date) > date(now)
SORT date(effective_date) ASC
```

### ③ 长期有效 / 待发布（无失效日）

```dataview
TABLE
  status AS "状态",
  note AS "备注"
FROM "2-知识库/税法"
WHERE file.name != "index" AND !expiry_date
SORT status ASC
```

> 🔎 **近期重点盯防**：`电池消费税`（2026-09-01 施行，pending）、`房产税与城镇土地使用税`（2026-09-01 起减半、2027-09-01 起全额，pending→sunset）即将生效；`不动产出租停车费5%`、`车辆购置税新能源减半`、`印花税离岸贸易免征`、`契税改制重组优惠`、`资源税/城建税六税两费减半` 均于 **2027-12-31 sunset**。每月 1 日自动化会核对上述日期并清出真正失效项。
