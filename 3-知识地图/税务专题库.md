# 税务专题库

> 金税四期 + 各税种 + 研发加计扣除 + 特别纳税调整

## 按税种

```dataview
TABLE topic AS "专题", regulation AS "法规依据", risk_level AS "风险等级"
FROM "2-知识库/税法"
WHERE type = "tax_clause"
SORT topic ASC
```

## 金税四期专题

```dataview
TABLE topic AS "监控点", detection_method AS "检测方法", risk_level AS "风险等级"
FROM "2-知识库/税法"
WHERE contains(tags, "金税四期")
SORT risk_level DESC
```
