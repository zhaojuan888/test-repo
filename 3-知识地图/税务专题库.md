# 税务专题库

> 金税四期 + 各税种 + 研发加计扣除 + 特别纳税调整

## 按税种

```dataview
TABLE topic AS "专题", regulation AS "法规依据", risk_level AS "风险等级"
FROM "2-知识库/税法"
WHERE type = "tax_clause"
SORT topic ASC
```

## 金税四期专题

```dataview
TABLE topic AS "监控点", detection_method AS "检测方法", risk_level AS "风险等级"
FROM "2-知识库/税法"
WHERE contains(tags, "金税四期")
SORT risk_level DESC
```

## 研发费用加计扣除

```dataview
TABLE topic AS "核查点", caliber AS "口径", common_error AS "常见错误"
FROM "2-知识库/税法"
WHERE contains(tags, "研发加计扣除")
SORT file.mtime DESC
```

## 特别纳税调整

```dataview
TABLE topic AS "调整事项", trace_period AS "追溯期", risk_amount AS "典型金额"
```
