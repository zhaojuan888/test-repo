# 标签地图（跨库按标签聚合）

> 与「行业知识库」「企业财务规范-知识地图」等**按文件夹**的 MOC 互补：这里按**标签**聚合，
> 一句话查出「所有行业的审计风险点」「所有 CAS 收入相关笔记」等跨文件夹视图。
> 标签受控词表见 [[标签规范]]。

## 所有行业审计风险点（跨行业）

```dataview
TABLE industry AS "行业", tags AS "标签"
FROM "2-知识库/行业研究"
WHERE contains(file.tags, "风险点")
SORT industry ASC
```

## 所有企业财务规范（跨行业对照）

```dataview
TABLE industry AS "行业", tags AS "标签"
FROM "2-知识库/企业财务规范"
WHERE contains(file.tags, "核算规范") OR contains(file.tags, "内控")
SORT industry ASC
```

## 全部准则笔记（CAS 视角）

```dataview
TABLE standard AS "准则", tags AS "标签"
FROM "2-知识库/会计准则"
SORT standard ASC
```

## 待复核 / 草稿（质量看板）

```dataview
TABLE status AS "状态", type AS "类型"
FROM "2-知识库"
WHERE status = "草稿" OR status = "待复核"
SORT file.mtime DESC
```

## 待归类（staging 产出）

```dataview
TABLE source AS "来源文件", converter AS "转换工具"
FROM "0-收件箱"
WHERE contains(file.tags, "staging")
SORT file.ctime DESC
```

## 全部笔记（总索引，按更新时间）

```dataview
TABLE type AS "类型", status AS "状态", tags AS "标签"
FROM "2-知识库"
SORT file.mtime DESC
```
