# 本机审计技能索引（78 个已装技能 · 按审计场景分类）

> **用途**：本机 `~/.workbuddy/skills/` 已装技能的**审计场景速查表**。表中"技能目录名"即安装标识。
> **建立原因**：知识库多处笔记引用 ``audit-report-checker``、``fdd-process-guide``、``陈版主技能-chen-yiwei-perspective``、``ima-skill`` 等为空链接（技能名≠笔记名），本笔记统一承接这些引用，并提供安装/核查方法。
> 描述文字均取自各技能 `SKILL.md` 的 frontmatter，**未做推断**。

## 安装与核查方法

- **本机技能库路径**：`C:\Users\WIN11\.workbuddy\skills\`（该目录是**软链**，实际指向 `C:\Users\WIN11\.config\opencode\skills`，WorkBuddy / OpenCode / Kimi **三端共享同一份**）
- **已装技能**：直接在对话中说出触发词即可调用；核查是否安装 → `ls C:\Users\WIN11\.workbuddy\skills\`
- **新装技能**：优先到**审计人 Skill 集市** `cgzcpa.com/skill` 核对是否已存在同类（避免与本机重复装）；安装前必须做 **P 级安全审计**（扫 `eval`/`exec`/网络调用/危险模式），因为技能 = SKILL.md 指令 + 可执行脚本，Agent **会以你的权限执行**
- **技能即代码**：从网上装技能≈往本机塞一段未审计代码，风险模型同 npm 装包但门槛更低 —— 见 [[每日AI技能卡]] 动态 #44「Agent Skills 安全审计」
