# 制造业（通用）— 审计高风险领域速查

> 来源：天健《行业审计指南07-机械制造业》+ 工业企业审计实务指南 + 2025-2026 监管案例
> PPI 连续三年负增长，制造业利润承压，资产减值风险全面上升

## 行业宏观背景

| 宏观因素 | 审计影响 |
|---------|---------|
| PPI 持续负增长 | 存货跌价（成品售价下跌）、固定资产减值迹象 |
| 产能利用率偏低（汽车 70.3%、光伏产能过剩） | 长期资产减值测试 |
| 出口贸易摩擦加剧 | 客户信用风险（ECL 参数更新）、海外收入真实性 |
| 宽松货币政策 | 借款费用资本化合理性、利息资本化停止时点 |

---

## TOP 5 审计关注点

### 1. 收入确认 — 总额法 vs 净额法

制造业中**贸易类/供应链类业务**最易出现判断错误：

| 判断 | 审计程序 |
|------|---------|
| 是否取得商品控制权 | 逐笔检查合同——运输责任、存货风险、定价权 |
| 是否承担信用风险 | 核查应收账款坏账的实际承担方 |
| 是否有实物物流 | 获取物流单据、仓库记录——警惕"空转贸易" |

### 2. 存货跌价

| 风险场景 | 审计程序 |
|---------|---------|
| 原材料价格大幅下跌 | 比较账面成本 vs 近期采购价/市场价 |
| 产品售价持续下降 | 比较估计售价 vs 近期实际售价 |
| 库龄 > 1 年的存货 | 逐项分析呆滞原因、NRV 测算 |
| 定制化产品客户取消订单 | 评估是否已全额计提跌价 |

### 3. 固定资产 / 在建工程减值

| 风险场景 | 审计程序 |
|---------|---------|
| 产能利用率 < 60% | 是否存在减值迹象（CAS 8 第 5 条） |
| 技术迭代（如燃油→电动） | 专用产线可收回金额测算 |
| 在建工程长期挂账未转固 | 核查是否已达预定可使用状态 |
| 利息资本化 | 资本化期间、暂停资本化条件 |

### 4. 研发费用与高新企业资格

| 风险 | 审计程序 |
|------|---------|
| 研发费用 vs 生产成本混同 | 工时记录追溯、设备使用日志 |
| 高新企业资格维持 | 科技人员 ≥ 10%、研发费用 ≥ 3-5%、高新收入 ≥ 60% |
| 研发加计扣除合规 | 四口径差异调节（会计/高新/加计扣除/IPO） |

### 5. 关联方交易

| 风险场景 | 审计程序 |
|---------|---------|
| 关联采购价格偏高 | 与非关联供应商价格对比 |
| 关联销售毛利率异常 | 与第三方客户毛利率对比 |
| 资金归集/资金占用 | 企业信用报告、银行账户归集协议 |
