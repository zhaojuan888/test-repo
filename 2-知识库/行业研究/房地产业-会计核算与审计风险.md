# 房地产业 - 会计核算与审计风险

> 基于财政部会计司官方《房地产业会计核算手册》整理（权威、非规范性文件）。房地产业务链条长（土地获取 → 开发建设 → 预售 → 竣工交付 → 税务），会计处理高度依赖**收入确认时点、借款费用资本化、存货跌价、预售合同负债、存货转投资性房地产**五大节点，是年报审计高风险行业。

## 一、行业特性与审计定位

| 维度 | 要点 |
|------|------|
| 业务模式 | 拿地—开发—预售—交付，资金密集、周期长（通常 >1 年达预定可销售状态） |
| 存货属性 | 开发产品/在建开发成本/拟开发土地均属**存货**（对外出售），土地使用权用于建出售房屋的，计入房屋建筑物成本而非单独无形资产 |
| 收入确认 | 预售不确认收入，收款计入**合同负债**；控制权转移（通常交付）时一次性确认 |
| 监管重点 | 预售资金监管专户、增值税预缴、土增税清算、企业所得税预计毛利 |
| 审计高危 | 收入跨期、股权收购拿地是否构成业务、借款费用资本化、存货跌价、成本分摊 |

## 二、关键会计处理（按业务环节）

### 1. 土地获取阶段
- **出让取得**：支付保证金 → 成交确认 → 取得土地使用权并满足存货确认条件，计入「开发成本—土地征用及拆迁补偿费」。
- **股权收购取得土地使用权（重点）**：通过收购持有土地的项目公司股权间接拿地。
  - 个别报表：达到控制的，确认为**长期股权投资**，初始成本按 CAS 2 / 企业合并准则确定。
  - 合并报表：取决于标的企业是否**构成业务**。实务中通常用**集中度测试**（取得总资产公允价值几乎相当于其中土地使用权等核心可辨认资产）→ 大概率**不构成业务** → 不按企业合并处理、不确认商誉，购买成本按相对公允价值分摊至可辨认资产（土地作为**存货**初始成本），随经济利益消耗转入成本费用。
  - 若构成业务，则按企业合并，可能产生商誉。

### 2. 开发建设阶段（成本归集 + 借款费用资本化）
- **成本归集**：前期工程费、建筑安装工程费、基础设施建设费、公共配套设施费、开发间接费用，均归集至「开发成本」，按成本核算对象分摊（占地/建筑面积/预算造价法等）。
- **借款费用资本化**（准则依据：借款费用准则 / CAS 17）：
  - 开发存货属**符合资本化条件的资产**（建造期 >1 年）。
  - 资本化金额以**含土地使用权的建造成本**为基础（土地使用权计入房屋建筑物成本）。
  - 资本化期间：开始时点须同时满足（资产支出已发生 + 借款费用已发生 + 购建活动已开始）；**非正常中断连续 >3 个月暂停**；北方冬季施工等可预见必要停工属**正常中断**，不暂停。
  - 分录：利息资本化 → 借「开发成本—资本化借款费用」，费用化部分 →「财务费用」。
- **存货减值**（成本与可变现净值孰低）：
  - 已完工开发产品：可变现净值 = 估计售价 − 销售费用 − 相关税费。
  - 在建开发成本：可变现净值 = 估计售价 − 至完工估计成本 − 销售费用 − 税费。
  - 计提（借：资产减值损失；贷：存货跌价准备）；影响因素消失可**转回**；结转出售时**转销**（借：存货跌价准备；贷：主营业务成本）。

### 3. 预售阶段（合同负债、销售佣金资本化）
- **认筹金**：仅表示优先选房诚意金，收取时计入「其他应付款—购房意向金」，未选到房退还。
- **定金 / 房价款**：预售模式下不满足时段法（买受人不控制在建商品、违约金不足以补偿已发生成本+利润），属**时点法**；转让控制权前已收款（不含增值税）确认**合同负债**，增值税部分「应交税费—待转销项税额」。
  - 定金含增值税，价税分离：借「银行存款」；贷「合同负债」+「应交税费—待转销项税额」。
  - 首付款、按揭款、一次性/分期款同理计入合同负债。
- **客户违约金**：单方解约收取的违约金属偶然利得，计入「营业外收入」（非日常活动），退房时借合同负债+待转销项，贷营业外收入+银行存款。
- **销售佣金**：为取得合同发生的增量成本，开发周期 >1 年满足资本化条件，确认为「**合同取得成本**」资产，随收入确认摊销入「销售费用」。

### 4. 竣工交付阶段（收入确认、成本结转）
- **收入确认时点**：客户取得房屋**控制权（通常交付时）**确认收入，预售与现房同规则。
  - 借「合同负债 / 银行存款」「应交税费—待转销项税额」；贷「主营业务收入」「应交税费—应交增值税（销项税额）」。
  - 同时结转成本：借「主营业务成本」；贷「开发产品」。
- **面积补差款**：交付时实测面积与合同面积差异结算，补差款比照房款处理（含税价分离）。
- **装修服务**：统一精装交付 = 与售房同一履约义务（交付时确认）；独立精装加载包 = 单独履约义务（按时段/时点法单确认，成本在「合同履约成本」单独归集）。
- **代收业主款项**：维修基金/契税/登记费等代收代付，计入「其他应付款」，垫付时「其他应收款」。
- **销售退回**：控制权转移前的退房不算销售退回；转移后退回冲减收入并转回成本。

### 5. 存货转为投资性房地产
- 场景：持租代售、资产优化、政策驱动（商改租/工改租）。**用于开发后出售的土地使用权不得确认为投资性房地产**。
- **转换日**：通常为租赁期开始日；自行开发尚未使用但董事会书面决议明确出租意图的，为决议日。
- **成本模式**：按账面价值（存货跌价准备结转）借记「投资性房地产—成本」，贷记「开发产品」；后续计提折旧/摊销（借其他业务成本），租金收入「其他业务收入」；减值适用资产减值准则、**不得转回**。
- **公允价值模式**：按转换日公允价值入账；公允价值 < 账面 → 差额借「公允价值变动损益」，> 账面 → 贷「其他综合收益」；后续不折旧，按资产负债表日公允价值变动；**公允价值模式不得转回成本模式**。

### 6. 税务处理（增值税）
- **预售预缴**：收到预收款按 3% 预征率预缴增值税（一般计税 9%、老项目简易 5%），借「应交税费—预交增值税」；纳税义务发生时点多为**交房时**。
- **交房结转**：待转销项税额 → 应交增值税（销项税额）；预缴 → 未交增值税。
- **土地价款扣减销售额**（一般计税）：销售额 =（全部价款和价外费用 − 当期允许扣除土地价款）÷（1+9%）；土地价款含向其他单位支付的拆迁补偿费（需凭证）；扣减的销项税额抵减「主营业务成本」（交房时开发成本已结转）。
- ⚠️ 2026-01-01《增值税法》正式施行，相关增值税规定按新法及配套法规执行。

## 三、审计风险点 TOP（房地产业）

| # | 风险点 | 典型错误 / 审计关注 |
|---|--------|---------------------|
| 1 | **收入确认跨期** | 在预售/未交付时提前确认收入；或以竣工备案而非交付确认；面积补差款漏计 |
| 2 | **股权收购拿地—是否构成业务** | 集中度测试判断不当，不该确认商誉的确认了商誉；可辨认净资产公允价值分摊错误 |
| 3 | **借款费用资本化滥用** | 资本化期间起止点不当、非正常中断未暂停、存货 vs 固定资产界限、土地成本是否纳入基数 |
| 4 | **存货跌价计提不足** | 尾盘/去化周期长/周边竞品降价未充分计提；减值转回/转销依据不足 |
| 5 | **预售款核算** | 定金/认筹金错列预收账款 vs 合同负债 vs 其他应付款；增值税价税分离错误（待转销项） |
| 6 | **销售佣金资本化与摊销** | 合同取得成本未资本化或摊销基础与收入不匹配；费用化操纵利润 |
| 7 | **存货转投资性房地产** | 转换日认定、成本/公允价值模式选择、公允价值模式后续计量、减值准备不得转回被违规转回 |
| 8 | **成本归集与分摊** | 成本核算对象划分、公共配套/土地价款分摊方法随意；借款利息分摊错误 |
| 9 | **税务（土增/所得税）** | 增值税预缴不足、土增税清算、所得税预计毛利结转；土地价款扣减销售额凭证不实 |

## 四、关键审计程序清单
1. 取得预售许可证、商品房买卖合同台账，核对**交付/竣工备案时点**与收入确认期间，执行截止测试。
2. 对股权收购拿地项目，复核**集中度测试**底稿，验证是否构成业务及商誉/存货成本分摊。
3. 测算借款费用资本化：复核资本化期间、专门/一般借款分配、土地成本基数。
4. 存货跌价测试：取得可变现净值依据（售价、至完工成本、税费），结合去化周期与市价。
5. 函证/核对预售资金监管专户余额，验证合同负债、待转销项税额列报。
6. 抽查销售佣金协议与摊销计算，验证合同取得成本。
7. 检查存货转投资性房地产的董事会决议/租赁协议，复核计量模式与公允价值依据。
8. 复核土增税、企业所得税计提与预缴，验证土地价款扣减销售额的合规票据。
