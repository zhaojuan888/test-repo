# 汽车制造业 — 会计核算与审计风险速查

> 来源：财政部会计司《汽车制造业会计核算手册》（截至 2025 年 10 月已生效准则，非规范性文件，仅供参照）
> 行业定位：资金与技术双密集、产业链协同复杂、研发周期长；销售含经销 / 代理 / 直营三模式，衍生车联网、辅助驾驶、碳排放权、二手车、出口等新业务。

## 行业特性与审计定位

| 关键特征 | 审计含义 |
|---------|---------|
| 研发（技术研究 / 平台 / 模块 / 车型开发）投入大、周期长 | 费用化 vs 资本化分界是利润操纵高发点（见 §2.1） |
| 采购侧普遍收取供应商返利 | 返利实质为采购成本调整，影响存货成本 / 主营业务成本（见 §2.2） |
| 整车销售三模式（经销 / 代理 / 直营） | 收入确认时点取决于"控制权转移"约定；运输是否单项履约义务决定总额 / 净额（见 §2.3） |
| 销售返利、积分、质保、车联网等多为"向客户提供的重大权利 / 单项履约义务" | 交易价格分摊 + 合同负债递延，跨期确认风险高（见 §2.4–2.7） |
| 新业务（车联网 / 辅助驾驶）软硬件混合 | 履约义务拆分 + 时段法 / 时点法判断（见 §2.7） |

## 一、关键会计处理（按业务循环）

### 1.1 研发活动

**内部研发（研究阶段 vs 开发阶段）**
- 研究阶段（技术研究立项 / 研究、项目规划与启动阶段）：支出费用化，期末结转管理费用—研究开发费。
- 开发阶段（设计开发与实施、试生产准备与验证阶段）：须同时满足无形资产准则第九条**五个条件**方可资本化（技术可行 / 意图 / 经济利益方式 / 资源支持 / 支出可靠计量），计入"研发支出—资本化支出"。
- 资本化后续：尚未达到预定用途的开发支出**无论有无减值迹象每年减值测试**；项目暂缓须减值测试，失败则全额计提减值并转销；通过量产启动（**SOP 节点**）达到预定用途时，资本化支出余额转入无形资产。
- 借款费用：开发阶段 ≥1 年且形成资本化无形资产的，相关借款费用可资本化（CAS 17）。

**外部研发合作**
- 委托研发：委托方承担风险报酬+享成果所有权→按自行研发区分阶段；不承担风险且成果满足无形资产定义→外购技术确认为无形资产。
- 受托方（研发机构）：按 CAS 14 区分时段法（产出不可替代+有权就累计完工收款）/ 时点法确认"研发及技术服务"收入，通过合同履约成本归集。
- 技术许可 / 转让：受让方确认无形资产；出让方按"知识产权许可属于时段还是时点"判断收入确认方式。

### 1.2 采购与供应商返利

- 供应商返利实质为**采购成本调整**：合同已明确返利条款且能合理预计价格变动→按估计确认存货采购成本；无法预计的，返利确定时——若零部件已用于整车且整车已售出→冲减**主营业务成本**，未使用或整车未售→调整**存货采购成本**（原材料 / 库存商品等）。
- 委托加工：发出材料计"委托加工物资"，收回时包含加工费及其他可归属成本。

### 1.3 整车销售 — 三模式收入确认

| 模式 | 所有权 / 存货风险 | 收入确认（销售公司/主机厂） |
|------|------------------|------------------------------|
| 经销 | 经销商买断，承担存货风险 | 常见约定：车辆**出库**即转移控制权→出库确认收入；或送达交付中心验收后确认 |
| 代理 | 代理商不拥有所有权、不承担存货风险，赚佣金 | 销售公司作为主要责任人**总额法**；终端客户提车时确认收入 |
| 直营 | 自建线上线下，直接面向终端 | 客户提车（控制权转移）确认收入；控制权转移前运输费计合同履约成本 |

- 运输活动：控制权转移**前**发生→不构成单项履约义务，运费进合同履约成本；转移**后**发生→可能构成运输服务，再判主要责任人（总额法）/ 代理人（净额法仅确认佣金）。

### 1.4 销售返利、重大权利与销售退回

- **现金返利（已采购商品）**：属**可变对价**，按"极可能不会发生重大转回"的金额确认收入，不包合返利部分；每资产负债表日重估调整（预计负债—经销商返利）。
- **未来采购价格折扣**：若客户能享超一般市场的折扣→构成**向客户提供的重大权利（单项履约义务）**，交易对价在整车与"经销商返利"合同负债间分摊。
- **应付客户对价**：市场支持 / 形象店 / 广告促销等补贴，未取得可明确区分商品→**冲减交易价格、冲减当期收入**（孰晚时点）。
- **销售退回**：控制权转移时按预期有权收取对价确认收入、按预期退还金额确认"预计负债—应付退货款"，同时确认"应收退货成本"资产；每期末重估退货率，作为会计估计变更。

### 1.5 产品质量保证

- **保证类质保**（如 3 年/10 万公里，法定必须）：不适用单项履约义务，按 CAS 13 + 企业会计准则解释第 18 号，销售时按历史经验预提→主营业务成本，贷预计负债；1 年以上部分列非流动负债（一年内到期列"一年内到期的非流动负债"）；期末复核、到期有余额转回/补提。
- **服务类质保**（延保、终身保养等）：构成单项履约义务，主机厂为主要责任人按**总额法**确认收入，交易价格在整车与服务间按单独售价分摊，分摊部分先列"合同负债"，时段内/完成时确认。

### 1.6 积分与商城业务

- 销售发放积分属"客户额外购买选择权"，若构成**重大权利**→单项履约义务，对价在整车与"合同负债—会员积分"间分摊；客户兑换时确认收入，过期转回。
- 积分商城兑换：销售公司取得商品控制权（主导定价/设计、承担存货风险）→主要责任人；仅代收代付+佣金→代理人（净额法确认佣金）。

### 1.7 车联网与辅助驾驶（新业务）

- **车联网**：整车与网络服务可明确区分→两项履约义务，交易价格按单独售价分摊。主机厂预先采购流量包、可自主分割定价、承担未售出风险→主要责任人（转让权利时确认收入）；否则代理人（净额法，按收客户与付运营商差额确认）。
- **辅助驾驶**：硬件与整车重大整合不可区分；软件若可明确区分→单项履约义务。独立运行功能（不依赖服务器）→时点法（交付/订阅生效时确认）；依赖服务器运行（如高阶 NOA）→时段法（车辆预计使用期/订阅期内分期确认）。

### 1.8 碳排放权 / 二手车 / 出口（简述）

- 碳排放权：优化产能布局盘活碳资产，按相关准则确认资产与损益。
- 二手车：构建交易业务，关注存货确认与跌价。
- 汽车出口：海外出口布局，关注外币、收入确认与关税处理。

### 1.9 税务要点

- 消费税：乘用车按气缸容量/超豪华小汽车征收，生产（进口）环节缴纳。
- 增值税：整车销售 13%；研发/技术服务、延保服务注意税率差异（如延保 6%）。
- 企业所得税：研发费用加计扣除、高新优惠；委托/合作研发归集口径。

### 1.10 重要会计估计（审计重点）

- 存货减值（整车/零部件滞销，库龄 + NRV）、固定资产折旧（寿命/残值）、无形资产摊销（使用寿命有限/不确定）、保证类质保预计负债（经验数据与持续评估）。

## 二、审计风险点 TOP

### 1. 研发支出资本化滥用（高危）
- 风险：在技术研究/规划启动阶段即资本化，或项目失败后不及时转销，虚增利润、少计费用。
- 程序：逐项目检查节点评审纪要、SOP 节点证据；复核五个条件满足性；检查暂缓/失败项目的减值测试与转销；借款费用资本化期间 ≥1 年且形成资本化资产。

### 2. 收入确认 — 三模式时点与总额/净额
- 风险：经销模式将"出库"误作"终端销售"提前确认；代理/运输环节错用净额法隐匿规模或错用总额法虚增。
- 程序：抽查销售合同控制权转移条款；判断运输是否单项履约义务及主要责任人/代理人身份；比对整车出库、验收、收款时点。

### 3. 可变对价估计不足（返利/退货）
- 风险：现金返利、退货率估计偏低→收入高估；未重估调整。
- 程序：复核预计负债—经销商返利、应付退货款的模型（历史数据/采购行为）；期末重估痕迹。

### 4. 应付客户对价未冲减收入
- 风险：市场支持/广告/形象店补贴计入销售费用而非冲减收入→收入高估。
- 程序：检查大额市场补贴性质（是否取得可明确区分商品），验证冲减收入处理。

### 5. 质保预计负债计提与转回
- 风险：保证类质保预提不足，或到期后贷方余额不及时转回。
- 程序：复核单车预提标准（历史概率×金额）、流动/非流动列报；检查到期余额处理。

### 6. 积分/服务类质保重大权利未分摊
- 风险：将积分、延保等直接全额确认收入→跨期/提前确认。
- 程序：判断重大权利与单项履约义务；检查交易价格分摊与合同负债递延/转回。

### 7. 新业务履约义务拆分与时段/时点
- 风险：车联网/辅助驾驶软硬不分、时段法误判（应分期却时点、或反之）。
- 程序：评估可明确区分性、主要责任人/代理人、是否依赖服务器运行。

### 8. 供应商返利跨期/误计
- 风险：返利未冲减存货成本或主营业务成本，或跨期。
- 程序：检查返利条款与实现销售状态，验证计入成本而非损益/收入。

### 9. 存货减值
- 风险：整车/零部件滞销未充分计提跌价。
- 程序：库龄分析 + NRV 测算，关注长库龄与改款换代车型。
