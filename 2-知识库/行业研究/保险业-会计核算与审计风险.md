# 保险业 - 会计核算与审计风险

> 基于财政部会计司官方《保险业会计核算手册》整理（权威、非规范性文件）。保险业 2023-01-01 起全面执行**新保险合同准则（CAS 25，2020 修订）**，会计核算发生根本性重塑：保费不再确认为「收入」，而是保险合同负债的变动；核心科目为**未到期责任负债、已发生赔款负债、合同服务边际（CSM）**。审计高度依赖精算假设与计量模型。

## 一、行业特性与审计定位

| 维度 | 要点 |
|------|------|
| 监管强度 | 偿付能力、准备金、资金运用均受严格监管（金融监管总局） |
| 核心准则 | 新保险合同准则 CAS 25（2023 全面施行）+ 新金融工具准则 CAS 22 |
| 业务分类 | 原保险、再保险、投资合同、受托管理、保险资金运用 |
| 收入逻辑 | 保费**不确认收入**（收入准则一般不适用），而是未到期责任负债变动；仅投资/服务成分适用收入准则 |
| 利润载体 | **合同服务边际（CSM）**——类似"利润蓄水池"，随服务履行摊销释放 |
| 审计高危 | 保险合同组划分、计量方法选择、准备金假设、分出再保险、投资合同分类、过渡衔接 |

## 二、关键会计处理（新准则口径）

### 1. 保险合同组划分（计量单元）
- **保险合同组合 → 保险合同组**：具有相似风险且统一管理的合同归为组合（如机动车辆险组合）；组合进一步细分为**合同组**（计量单元）。
- 合同组由签发日间隔**不超过 1 年**且预计获利水平相似的合同组成。
- 至少分为三组：初始确认时**存在亏损**的组 / 无显著亏损可能的组 / 剩余组。

### 2. 计量方法选择
- **一般方法**：默认，以合同组为单元确认计量。
- **保费分配法（简化）**：责任期 ≤1 年，或简化处理结果无重大差异（预计履约现金流量在赔案前不重大变化）；特殊账务（未到期责任负债不设置未来现金流量现值/非金融风险调整/CSM 明细）。
- **浮动收费法**：适用于**具有直接参与分红特征**的保险合同（保单持有人参与清晰可辨认基础项目、相当大部分回报随基础项目公允价值变动）——本质是投资相关服务合同。

### 3. 保费确认与保险服务收入
- 收到保费先入「预收保费」，匹配至保险合同初始确认后转入「未到期责任负债—未来现金流量现值—保费」。
- **新准则下保费不是收入**：保险服务收入在责任期内分摊确认。
- **保费分配法**下：保险服务收入 = 已收和预计收取保费 − 投资成分 − 重大融资成分，分摊至当期，借「未到期责任负债—计入收入」、贷「保险服务收入」。
- 退保、加保、减保、保单贷款均通过未到期责任负债/已发生赔款负债相关明细核算。

### 4. 保险合同负债（准备金）
- **未到期责任负债** = 未来现金流量现值 + 非金融风险调整 + 合同服务边际（亏损组为亏损部分）。
- **已发生赔款负债**：赔案发生后的赔付义务（含投资成分与保险成分拆分）。
- **合同服务边际（CSM）**：初始确认时锁定，随提供保险服务摊销（借未到期责任负债—CSM，贷保险服务收入—CSM 摊销）；亏损组无 CSM 摊销。
- **期末评估**：各合同组期末重计量（履约现金流量变动、金融变动额、CSM/亏损部分变动）。

### 5. 赔付支出
- 赔付金额拆分**投资成分**（退未到期责任负债）与**保险成分**（借保险服务费用）。
- 发生赔案按估计额入账，核赔通过后冲回估计、按确定金额重做，实际支付时贷银行存款。

### 6. 分出再保险
- 不适用浮动收费法；计量考虑**再保险分入人不履约风险**。
- 科目：「分保摊回未到期责任资产」「分保摊回已发生赔款资产」；合同服务边际可借可贷（净利得/净成本）。
- 须计量**亏损摊回部分**；再保险合同组分出时间间隔 >1 年不得归入同一组。

### 7. 投资合同与保险资金运用
- **投资合同**（非相机参与分红特征）属**金融负债**，适用 CAS 22：科目「投资合同金融负债（保户投资款）」；含适用收入准则的服务成分须分拆至「投资合同服务负债」。
- **保险资金运用**：金融资产按 CAS 22 分类（摊余成本 / FVOCI / FVTPL），受新金融工具准则与预期信用损失（ECL）约束。
- 浮动收费法下作为基础项目持有的投资性房地产，后续计量可选全部公允或成本模式（依据 CAS 3），选定后不得混用、公允不可转回成本。

### 8. 亏损合同组与过渡衔接
- **亏损合同组**：初始确认亏损部分，后续履约现金流量变动优先冲减亏损部分；从盈利转亏损/亏损转盈利须分别处理 CSM 调整与亏损部分。
- **首次执行衔接**（CAS 25 施行）：可选追溯调整法 / 修正追溯调整法 / 公允价值法；**过渡日**通常为首次执行日前最近会计年度期初；多项会计政策选择（金融变动额分解 OCJ/损益、保费分配法适用等）一经确定不得随意变更。

## 三、审计风险点 TOP（保险业）

| # | 风险点 | 典型错误 / 审计关注 |
|---|--------|---------------------|
| 1 | **保险合同组划分不当** | 组划分（签发间隔 ≤1 年、获利水平相似）错误，影响 CSM 与亏损认定 |
| 2 | **计量方法选择** | 保费分配法适用条件不符（责任期 >1 年或赔案前现金流重大变化）；浮动收费法下"直接参与分红特征"判定错误 |
| 3 | **保费与保险服务收入** | 新旧准则混淆，将保费直接确认收入；投资成分/重大融资成分拆分错误 |
| 4 | **准备金计量假设** | 折现率、赔付率、退保率、费用假设不合理；CSM 初始与后续变动计量错误 |
| 5 | **分出再保险** | 分保摊回资产计量、再保险分入人不履约风险、亏损摊回部分漏计 |
| 6 | **投资合同金融负债分类** | 工具准则适用错误；含服务成分未分拆（收入准则部分） |
| 7 | **保险资金运用金融资产** | CAS 22 分类与 ECL 减值（应收款项、债权投资）计提不足 |
| 8 | **亏损合同组与期末评估** | 假设变更导致亏损部分/CSM 变动处理错误 |
| 9 | **过渡衔接** | 首次执行新准则方法选择、比较信息披露、其他综合收益累计金额调整不当 |
| 10 | **偿付能力/监管披露** | 保险合同金融变动 OCJ/不能转损益列报、监管资本相关披露不完整 |

## 四、关键审计程序清单
1. 了解精算模型与关键假设（折现率曲线、赔付/退保假设），执行精算估值复核与敏感性分析。
2. 测试保险合同组划分逻辑（签发间隔、获利水平），验证计量方法适用条件。
3. 复核保费分配法与浮动收费法的选择依据及一贯性。
4. 重新计算未到期责任负债、已发生赔款负债、CSM 的期末计量与摊销。
5. 检查分出再保险合同账单与分保摊回资产计量，评估分入人不履约风险。
6. 测试投资合同金融负债分类与服务成分分拆；复核保险资金运用金融资产分类与 ECL。
7. 验证过渡日选择、首次执行衔接处理与比较信息披露。
8. 评估偿付能力相关披露与保险合同金融变动 OCJ/不能转损益列报。
