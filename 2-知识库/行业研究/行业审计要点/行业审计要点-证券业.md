# 证券业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——证券业》第五篇「重要的审计领域及审计程序」。证券公司审计四大核心是**经纪（客户资金安全与收入完整）、自营（金融资产存在与公允价值）、两融（信用风险）、资管（表外刚性兑付）**；金融工具估值与减值判断贯穿全程。

## 一、行业经营与核算特点
- 持牌经营、受证监会高度监管（风险控制指标、净资本、流动性监控）；业务线多元化：经纪、资产管理、自营投资、投行、融资融券/约定购回/股票质押、IB、投资咨询。
- 收入确认：经纪/资管/投顾手续费多按系统计提，实务中存在**收付实现制倾向**；自营投资收益随金融资产处置确认，成本结转方法影响利润。
- 标志性科目：代理买卖证券款、结算备付金、存出保证金、交易性金融资产、可供出售金融资产、持有至到期投资、融出资金/证券、衍生金融工具、手续费及佣金收入。金融资产以**公允价值**计量为主，估值与减值判断是审计重心。

## 二、关键业务流程
经纪（开户→交易委托→清算→交收三方存管）→ 自营（投资决策→账户/资金调度→交易→估值）→ 资管（产品设立→募资→投资运作→兑付）→ 投行（承揽→承做→发行/保荐→持续督导）→ 融资融券（适当性审查→授信→盯市→平仓）。各业务前中后台应分离并独立风控、合规稽核。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 经纪手续费收入完整/截止 | 收入跨期；以支抵收少计营业税；系统数据与财务记录差异 | 高 |
| 代理买卖证券款存在/完整 | 挪用客户资金；客户透支或余额为负；账外自营 | 高 |
| 自营金融资产存在/完整/权利 | 未提供全部自营账户（银行间、清算所、信托/资管计划户）；已质押/回购证券误确认 | 高 |
| 金融工具公允价值合理性 | 利用估值政策调节损益；停牌/低流动性债券长期挂面值 | 高 |
| 可供出售权益工具减值 | “非暂时性下跌”判断不当，浮亏转损益或滞留资本公积，操纵当期利润 | 高 |
| 融出资金/证券真实性及信用风险 | 两融客户与公司存在特定关系形成账外自营；极端行情强平失败 | 高 |
| 约定购回/股票质押回购信用风险 | 类贷款无信用账户，一旦发生信用风险损失大 | 中高 |
| 资管产品表外风险 | 合同保本保收益承诺、劣后担保触发未入账、历史兑付代垫资金 | 中高 |
| 投资收益成本结转方法 | 借通道按“通道”而非“具体投资项目”结转成本，少结转多计收益 | 中高 |
| 投行/投资咨询收入截止 | 按收付实现制确认，收入未计入正确期间 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 经纪手续费收入分析+CAATs | 收入完整/截止 | 逐月对比客户交易量与市场成交量、经纪收入变动；核对恒生（总收入）与新意（交交易所费）系统轧差；引入计算机审计团队测试 | 
| 代理买卖证券款资金验算 | 挪用/完整性 | 分析性资金验算；查客户投诉与资金流水透支；对成交额大、余额变动大客户电话访谈/函证 | 
| 自营账户清单+管理层声明 | 自营存在/完整 | 获取全部市场（中登沪深、银行间、上清所、基金直销、信托/资管户）自营账户清单，声明书承诺已提供全部账户 | 
| 金融资产函证 | 自营存在/权利 | 中登沪/深分公司、基金公司直销、中央国债、上海清算所分别询证（用对方模板）；亲自接收电子回函 | 
| 公允价值复核 | 估值 | 股票用收盘价；银行间/低流动性债券用万德估值并与面值对比；场外品种查档案“实质重于形式” | 
| 可供出售权益工具减值测试 | 减值 | 逐项判断浮亏比例、持续时间、发行方经营状况；查会计政策一贯性、转回是否经损益 | 
| 两融维担比例与盯市 | 两融信用风险 | 重算维持担保比例；查盯市与强制平仓执行；评估融出证券非暂时严重下跌减值；重算利息收入 | 
| 资管表外风险核查 | 表外风险 | 查合同保本条款、宣传“承诺保本”；历史兑付是否代垫；抽样劣后产品是否触发担保及账务处理 | 
| 投行/咨询收入复核 | 收入截止 | 台账+项目进度表+合同复核承销/财务顾问收入；跨期项目匹配进度；期后检查/函证；督导费谨慎确认 | 
| 投资收益成本结转复核 | 成本结转 | 按具体投资项目（非通道）复核成本结转；对比合理做法重算差异对利润影响 | 

## 五、特殊会计事项
- **金融工具分类与计量**：交易性、可供出售、持有至到期；长期债券（含长期可供出售债券）须用实际利率法摊销，复核应收利息与利息调整（YIELD/COUPDAYBS 测算）。
- **可供出售权益工具减值**：区分暂时性（资本公积）与非暂时性下跌（转资产减值损失），判断直接影响当期损益，是自营审计重中之重。
- **担保品/回购披露**：交易所国债回购、约定购回、买断式逆回购、银行间正回购（逐笔核对中央国债/上清所“质押/待购回”字段）；买断式过户证券不得确认为自营。
- **衍生工具**：初始双边权利义务相等常不入账，须查备查登记簿与期末公允价值确认。

## 六、监管关注 / 与其他行业差异
- 指南审计案例：①经纪人佣金调节利润（12月佣金为负，人为调低以完成利润指标）；②通道成本结转少结转成本、多计投资收益。均指向利润操纵。
- 监管高发：金融工具估值公允性、减值计提充分性、两融信用风险、资管刚性兑付/表外风险。
- 与银行业差异：证券业主对象是**客户交易资金与自营头寸估值**，银行主对象是**信贷资产信用风险与拨备**；二者均重度依赖函证与系统控制测试。
