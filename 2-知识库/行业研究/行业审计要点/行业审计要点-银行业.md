# 银行业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——银行业》第五篇「重要的审计领域及审计程序」。商业银行审计固有风险与内部控制风险均高，四大核心领域为：**信贷业务（贷款减值与五级分类）、资金业务（金融资产估值与分类）、现金及柜台业务（存款与现金）、中间业务（表外与手续费收入）**。

## 一、行业经营与核算特点
- 持牌经营、强监管（银监/央行监管指标约束），资产负债表庞大；负债以吸收存款为主，资产以发放贷款和金融资产投资为主。
- 收入主要来自利息收入（贷款、金融资产）与手续费及佣金收入（中间业务），利润对利率、信用风险高度敏感。
- 标志性科目：发放贷款和垫款、贷款减值准备、贴现资产、垫款、存放/拆放同业、交易性/可供出售/持有至到期金融资产、吸收存款、应付利息、抵债资产；大量表外科目（银行承兑汇票、开出保函、信用证、未决承诺）。

## 二、关键业务流程
信贷（贷前审批→放款→贷后管理与风险分类→利息计提→减值准备计提→转让/收回/核销/抵债）→ 资金（前中后台分离的交易、清算、估值）→ 现金及柜台（开户、存取款、计息结息、对账、重要空白凭证、金库/ATM）→ 中间业务（理财发行与销售、委托贷款、代理与咨询顾问类手续费）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 风险描述 | 常见舞弊/错报情形 |
|---|---|---|
| 贷款减值准备计提 | 单项/组合准备依赖现金流预测、迁徙率等主观假设 | 人为调节减值准备金额操纵利润；异常回拨 |
| 贷款五级分类 | 分类依赖人工判断，直接影响减值计提 | 人为调整风险分类粉饰资产质量；同一客户分类不一致 |
| 利息收入确认 | 计息系统自动计提，非应计贷款停息挂账 | 人为调节利息收入金额；逾期超90天利息未转表外 |
| 信贷资产真实性与完整性 | 贷款、贴现、垫款、承兑汇票均可能虚构 | 与借款人勾结违规放贷；空壳承兑、票据重复挂账 |
| 金融资产分类与估值 | 四分类及公允价值依赖模型与报价 | 违规重分类规避"持有至到期污染条款"；估值参数不审慎 |
| 存款与利息支出 | 存款量大、信息化高，难以全面审计 | 其他金融机构存款未重分类；应付利息计提不足 |
| 表外与手续费收入 | 表外业务未在表外上账、以收抵支 | 表外承兑汇票未入账；手续费收入以收抵支少计 |

## 四、关键审计程序

| 审计程序 | 目的 | 关键执行要点 |
|---|---|---|
| 贷款明细表与监管指标分析 | 锁定审计重点 | 取贷款/减值明细表核对总账；分析不良率、拨备覆盖率、集中度、资本充足率等监管指标波动 |
| 贷款抽样与函证 | 验证存在与可收回性 | 按类别函证贷款及利息；检查期后还款/垫款；关注新增减少异常与信贷资产转让 |
| 五级分类与减值测试 | 验证分类与计提充分性 | 抽查档案判断分类合规性；单项准备重测现金流/折现率；组合准备检查迁徙率与一贯性 |
| 贴现/承兑汇票监盘与核对 | 验证表外与实物 | 监盘票据、空白承兑；核对保证金比例与历史；检查到期垫付与期后收回 |
| 金融资产估值与分类测试 | 验证计价与分类 | 活跃市场价比对外部报价；无报价利用估值专家；测试持有至到期重分类"污染条款" |
| 存款与应付利息重算 | 验证负债完整性 | 科技部取分户账与业务状况表核对；抽样函证；重算应付利息与利息支出；截止测试 |
| 手续费及佣金收入分析 | 验证收入真实完整 | 实质性分析；检查合同/协议判断风险报酬转移；表内外核对防漏记；截止测试 |
| 信息系统审计前置 | 支撑实质性程序 | 高信息化下先测评内控、引入IT审计，据以界定实质性重点 |

## 五、特殊会计事项
- **贷款减值**：单项（现金流折现）与组合（迁徙率模型）结合计提，须评价假设合理性并作回溯分析。
- **金融资产四分类**：交易性/可供出售/持有至到期/应收款项类，关注重分类与持有至到期"污染条款"（CAS 22）。
- **表外业务**：银行承兑汇票、保函、信用证、未决承诺仅在表外核算，须关注完整性。
- **非应计贷款**：本金或利息逾期超规定天数停息挂账，逾期超90天利息转表外。

## 六、监管关注 / 与其他行业差异
- 监管指标（不良率、拨备覆盖率、拨贷比、集中度、资本充足率、存贷比）是审计重点与监管通报高发区。
- 与制造业差异：以风险组合测试为核心，大量依赖信息系统审计与实质性分析，而非逐项细节测试。
