# 影视业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——影视业》第五篇「重要的审计领域及审计程序」。影视企业审计三大核心领域：**收入确认（时点：许可证+载体转移+经济利益流入）、制作成本（真实性/单部归集）、存货与成本结转（版权类存货、计划收入比例法）**。

## 一、行业经营与核算特点
- 智力+资本密集型，产品为无形影视作品，可低成本复制，播映权可按轮次/区域/期限分割转让；单部作品独立核算，联合摄制（控制/不控制/共同控制）普遍。
- 收入确认均为**时点确认（非时段）**：
  - 电影票房分账：取得《电影公映许可证》+院线上映后，按分账结算金额确认（票房分账收入=(票房总收入−电影专项基金−税金−发行费)×分账比例）。
  - 电影版权：取得公映许可证+母带交付+经济利益很可能流入。
  - 电视剧：取得《电视剧发行许可证》+播映带/载体转移购货方+经济利益很可能流入。
- 标志性科目：存货（原材料=剧本、生产成本=在拍影视剧、库存商品=完成拍摄影视剧）、主营业务收入/成本、应收账款（电视台/院线）、预付/预收制片款（联合摄制）。
- 成本结转方法：**计划收入比例法**（取得许可证后 24 个月内结转为主流），另有零毛利法、固定比例法；方法一经确定不得随意变更。

## 二、关键业务流程
剧本/立项（立项委员会授权）→ 筹备（采购剧本/道具，编预算）→ 拍摄（剧组，成本归集入生产成本）→ 后期制作 → 取得发行/公映许可证 → 发行（供带电视台/院线，分账结算）→ 确认收入并按计划收入比例法结转成本 → 二轮/多轮发行。
联合摄制：作为控制方收合拍款（预收制片款）或作为不控制方投合拍款（预付制片款）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入确认时点/跨期 | 许可证取得前确认收入；延迟或提早供带调节；12 月末取许可证当年集中确认；跨年上映提前/延后 | 高 |
| 收入金额/虚构交易 | 长年限版权卖断给非电视台客户（疑似关联方）；收视率/播放集数/首播台等或有条款未恰当处理；期后销售退回未冲回 | 高 |
| 制作成本真实性/完整性 | 劳务费占比高（总成本的 50%–80%）且多现金支付，虚假成本；大额成本无合同/发票；成本暂估不当 | 高 |
| 成本结转（计划收入比例法）操纵 | 预计 24 个月总收入高估→少结转成本、虚增毛利 | 高 |
| 存货（影视作品）跌价 | 完成拍摄长期未售、超 24 个月仍有发行计划未完成、改编权将到期无拍摄计划、在拍过长→未提跌价 | 中高 |
| 应收账款坏账/账龄操纵 | 同一客户 A 剧应收与 B 剧预收对冲、以短账龄收款项冲减长账龄应收，调节余额或账龄结构 | 中 |
| 联合摄制核算 | 控制/不控制判断错误；分成结算成本计算不准确 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入—许可证/合同/供带核查 | 时点/跨期 | 取得公映/发行许可证核对取得时间并公开查询；合同原件核对分账比例/结算方式；供带记录（内部流转审批、录带公司确认、物流/签收单）；查询播放时间比对；截止测试重点关注 12 月末取证的当年确认 |
| 收入—函证/退回/客户 | 虚构/金额 | 大额定额函证（列剧名、合同额、收带时间）；查期后补充合同与大额冲回；非电视台长年限卖断合同→了解实质、查客户、实地走访、函证、期后收款 |
| 制作成本审计 | 成本真实 | 询问进度判断科目列示（筹备=原材料/预付，开机=在拍，完成+许可证=完成拍摄）；单部总成本合理性（电视剧约 50–100 万/集，古装/战争高，电影常上亿）；同类型成本比例（劳务最高）；大额成本追查合同/发票/结算单；现金支付追查备用金领取+制片人/财务签收 |
| 成本暂估复核 | 暂估 | 结合期后付款、已签大额合同、制作流程复核暂估合理性 |
| 成本结转复核（计划收入比例法） | 结转操纵 | 重算结转率=总成本/预计 24 月总收入；当期结转=收入×结转率；复核预计总收入（已签合同+未签预测，二轮价通常低于首轮 40%–50%）；按案例重算电视剧制作/分成成本 |
| 联合摄制分成 | 核算 | 取各方盖章的分成结算成本计算表，复核（累计收入−可扣拍摄成本×进度−收入×发行费率）×享有比例；向应付结算方函证 |
| 存货监盘（版权） | 存货存在 | 取得全部影视剧清单与账面核对；查发行/公映许可证原件（申报机构=被审计单位）；取联合投资/引进协议、授权书明确版权份额；改编权/剧本合同检查权利内容 |
| 存货跌价 | 跌价 | 逐剧分析：完成长期未售/超 24 个月/改编权将到期/在拍过长→提跌价或全额结转 |
| 应收账款 | 坏账/账龄 | 复核账龄政策（行业 2–3 年 50%、3 年以上 100%）及账龄正确性（防 A/B 剧对冲、短冲长）；按电视台模板函证（合同额−已收=函证额）；替代测试（期后收款/合同） |

## 五、特殊会计事项
- **收入时点（非时段）**：许可证+载体转移+经济利益流入三要件齐备；电影票房分账按公式净额确认。
- **成本结转三法**：计划收入比例法（主流，配比期 24 个月）、零毛利法、固定比例法；取得许可证后 24 个月内结转，方法一经确定不得随意变更，变更需披露。
- **存货核算**：原材料（剧本）/生产成本（在拍）/库存商品（完成拍摄）；发出采用个别计价法；盘点以核查版权等权利文件为准。
- **联合摄制**：控制方（执行制片方）全额确认制作成本+分成成本；不控制方（预付制片款，超出部分确认收入）；共同控制按合同实质判断。
- **税务**：营业税改增值税；文化相关优惠按政策适用。

## 六、监管关注 / 与其他行业差异
- 证监会/注协处罚高发：收入跨期（年末取许可证集中确认）、虚构发行收入（关联方/非真实客户）、制作成本真实性（现金支付、劳务费）、计划收入比例法下预计收入高估虚增毛利、存货跌价不充分。
- 与「制造业」差异：无实物存货，存货为版权/在拍作品，成本按单部归集不分配；收入按时点而非时段确认，播映权可多轮转让。
