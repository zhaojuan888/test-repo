# 网游业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——网游业》第四、五篇。网游企业审计核心领域：**虚拟道具收入递延、总额/净额法、收入舞弊（刷量）、版权金摊销与减值、研发资本化、税收优惠资格**；高度依赖计费系统后台数据，须 IT 审计支撑。

## 一、行业经营与核算特点
- 以虚拟道具收费为主流；产业链角色分开发商、发行商/平台商、运营商。运营依赖充值系统、计费系统、玩家账户数据库。
- 收入确认：玩家消耗虚拟货币购道具时确认；按道具寿命递延（即时/时长/永久）。联合运营按总额/净额法判断。
- 标志性科目：预收款项（充值未消耗）、营业收入（递延确认）、无形资产（版权金/开发支出资本化）、长期待摊费用（版权金摊销）、研发费用。

## 二、关键业务流程
研发（立项→开发→测试→上线）→ 发行/运营（自主或联合平台，充值→消费）→ 计费系统记账（充值计入预收，消耗递延收入）→ 分成结算（与平台/IP 方）→ 回款。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入递延/跨期（道具寿命估计） | 永久道具按付费玩家生命周期分摊，估计主观；随意调整递延期间调节利润 | 高 |
| 总额/净额法判断错误 | 联合运营中未同时满足"主要义务方/自主定价/选供货商/定规格"四项仍按总额法，虚增营收 | 高 |
| 收入舞弊（自充值/刷量） | 通过自有/关联账号刷充值虚构流水；渠道刷量；IP/MAC 异常 | 高 |
| 后台数据真实性 | 计费系统数据被篡改或统计口径不一；充值/消耗/分摊数据不可靠 | 高 |
| 版权金摊销/减值不当 | 代理游戏未达预期仍按原期限摊销；衰退期未计提减值 | 中高 |
| 研发支出资本化不当 | 小型游戏与大型端游资本化条件把握不当；研究/开发阶段划分不清 | 中高 |
| 高新/双软资格造假 | 不符合实质条件强行申报享 15% 或两免三减半 | 中 |
| 预付开发费/分成暂估 | 长账龄预付开发费未转损益/减值；分成支出滞后未暂估 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入确认政策+递延测算复核 | 递延/跨期 | 复核道具分类（即时/时长/永久）及递延依据；玩家生命周期测算（流失率 1/流失率，或加权）；差异>10% 调整 |
| 总额净额法判断 | 总额净额 | 检查是否同时满足四项（主要义务方/自主定价/选供货商/定规格） |
| 运营数据导出与分析（IT审计） | 数据真实性 | 现场观察运营部从计费系统导出（带查询语句截图）；注册/活跃/付费/ARPU 趋势与收入吻合 |
| 收入数据核对 | 收入舞弊 | 系统充值/消耗/分摊数据与收入、预收核对；已订未充/已充未耗/已耗未分摊勾稽 |
| 账号测试（IT审计） | 刷量 | 抽样账号登录/IP/MAC/消费记录异常排查；自充值识别 |
| 函证+收款结构分析 | 收入 | 点卡经销商函证；收款渠道/账户结构分析 |
| 版权金摊销与减值 | 摊销/减值 | 查代理合同与游戏流水；商业运营未达预期则调减摊销期或计提减值 |
| 研发资本化五条件 | 资本化 | 立项/人员能力/发行规划/资金；大型端游严格资本化，小型页游费用化 |
| 高新/双软核查 | 资格 | 逐条核 6 项实质条件；研发费用占比（收入<5000万≥6% 等）；3 年内持续符合 |
| 分成/服务器成本 | 成本 | 收入流水与分成结算单一致；暂估分成；服务器支出占成本比同行比对 |

## 五、特殊会计事项
- 虚拟道具收入：即时道具使用确认；时长道具按使用期递延；永久道具按付费玩家生命周期分摊（无权威经验数据，企业自估，须 IT 数据支撑）。
- 总额/净额法：是否为服务提供主要义务方等四项决定收入列示，影响营收规模与毛利率。
- 版权金：取得代理权支付，授权期内平均摊销，通常不可退；游戏寿命低于预期需调减或减值。
- 税务：软件产品增值税超 3% 即征即退；高新 15%、研发加计、双软两免三减半。

## 六、监管关注 / 与其他行业差异
- 监管高发：收入真实性（自充值/刷量）、道具递延估计、总额净额法、版权金减值、研发资本化、税收优惠资格。
- 与"影视/传媒"差异：网游收入源于虚拟道具消耗递延，高度依赖 IT 系统后台数据，须 IT 审计；影视以票房/版权确认。
