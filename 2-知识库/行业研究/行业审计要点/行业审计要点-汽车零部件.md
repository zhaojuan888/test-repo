# 汽车零部件业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——汽车零部件业》第五篇「重要的审计领域及审计程序」。汽车零部件属技术/劳动力/资本三密集行业，既具一般生产制造企业的收入与成本主题，又在模具核算、组装加工、存货盘点等方面有独特处理。

## 一、行业经营与核算特点
- 技术、劳动力、资本三密集；作为汽车工业支柱，多为整车厂一级/二级配套商，按订单配套生产，产品种类多（注塑件到车身构件）。
- 内销一般按整车厂在联网系统发布的结算单（线上）、纸质结算单或邮件结算单时点确认收入；外销按报关出口或到货验收时点确认；部分二级配套商内销按产品到货验收确认。
- 成本核算需深入工艺流程，关注成本分摊合理性、投入产出率、产能利用率、单位能耗及成本波动，并对比同业上市公司指标。
- 标志性科目：原材料、生产成本/库存商品、应收款项（含质保金）、应付账款（含大额存货暂估）、模具相关资产/收入、预计负债（三包/质保）、存货跌价准备。

## 二、关键业务流程
采购（按配套订单采购，请购→订货→验收→入库→暂估/付款，供应商定点管理）→ 生产（按工艺与产能排产，工薪/制造费用归集，模具投用）→ 销售（接单→发货/结算单→开票→收款，含模具、组装加工、三包索赔）→ 特殊业务（销售返利、退回、组装加工、质保期费用计提）→ 回款（应收、票据，质保金期末留滞）。

## 三、主要审计风险领域

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入确认时点错 | 内销未按整车厂结算单时点、外销未按报关/到货验收确认；提前确认 | 高 |
| 应付暂估不实 | 存货暂估占比高，暂估单价/数量不实、长期挂账隐瞒利润或负债 | 高 |
| 模具核算不当 | 一次性销售与带件生产分摊混淆；收入/成本确认时点错调节利润 | 高 |
| 销售退回/返利 | 新收入准则下预计退货率估计不当；折扣折让无支持文件 | 中高 |
| 组装加工核算错 | 自产产品与装配劳务收入成本未分开核算，总额/净额混淆 | 中高 |
| 三包/质保费用 | 三包索赔清单责任归属不清；质保期费用跨期调节利润 | 中高 |
| 应收账款/坏账 | 规模大、含质保金；回款风险与坏账估计 | 中高 |
| 存货监盘舞弊 | 存货金额大、舞弊可操作性强；未纳入盘点或已售未发 | 中高 |
| 关联方资金占用 | 以购销掩盖非正常资金往来；关联方非关联化 | 中 |
| 废料让售收入 | 废料台账与产销量不匹配，账外处理 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入分析程序 | 收入异常 | 本期与上年收入、毛利率波动对比；主要产品/客户毛利率；增值税申报表估算全年收入；产能/水电能耗印证；收入与现金流匹配；废料让售数量与产销量波动核对 |
| 收入确认核查 | 时点错 | 了解确认政策，从外部独立来源取证据判断控制权转移；内销核对结算单时点、外销核对报关单/提单/电子口岸信息，必要时向海关函证；抽取发票/发货单/凭证核对日期 |
| 截止测试 | 提前确认 | 系统/分层抽样选取资产负债表日前后发货单与收入/应收明细账双向核对；取得期后销售退回记录查提前确认；结合应收函证查未获认可大额销售 |
| 应付暂估审计 | 暂估不实 | 取暂估明细表（供应商/品名/入库日期/数量/单价/暂估额）与报表核对；分析月度变动与长账龄；暂估单价与合同/市价比对；函证暂估数量及结算条款；期后发票/付款验证；未领用存货盘点验证 |
| 模具核算审计 | 核算不当 | 取模具收入成本明细表比变动；查合同结算条款区分一次性/带件；一次性销售查验收移送单时点；带件生产复核收入/成本按产量占带件总量比例分摊；函证增加模具验收时点 |
| 组装加工审计 | 核算错 | 查合同是否分别注明自产售价与装配劳务价；未注明者查区分方法（一般按成本占比）并与同业对比；核成本分摊与流程一致 |
| 三包/质保审计 | 费用调节 | 三包索赔按主机厂清单区分责任归属；质保费比较本期与上年占收入比、结合产品行情与期后发生；截止测试查期后大额维修费未入账 |
| 销售退回审计 | 退回不当 | 新准则下关注预计销售退回率（分客户分产品历史退货率+销售政策）；预计不会退回部分确认收入成本，预计退回部分计预计负债与应收退货成本 |
| 应收账款函证 | 虚增/坏账 | 对大额/长账龄/异常/关联方函证余额及发生额，保持发函控制；核查客户工商资料排查关联；回函不符查差异、未回函替代/期后回款测试；坏账准备计提比例合理性 |
| 存货监盘 | 存在/舞弊 | 存货金额大、舞弊可操作性强，将监盘作重点并增样本不可预见性；关注未纳入盘点范围、已售未发、受托代管；结合盘点查存货质量与跌价 |

## 五、特殊会计事项
- 模具核算：依客户是否承担、是否带件生产区分；一次性销售完工验收确认，带件生产按产量占合同约定带件总量比例分摊收入与成本。
- 组装加工：自产产品销售 + 加工费核算，自有产品与装配劳务收入成本应分开（总额法下自产按销售、加工按劳务）。
- 销售退回（新收入准则）：按"控制权"限制，预计不退回部分确认收入成本，预计退回部分计"预计负债"与"应收退货成本"，更趋谨慎。
- 三包索赔与质保期费用：依索赔清单区分责任，质保期维修费按各期完整性、准确性计提，防利润调节。
- 应付暂估：汽车零部件业存货暂估占应付账款余额比例高（存货/资产/费用暂估三类，存货暂估为主），真实性合规性为重点。

## 六、监管关注 / 与其他行业差异
- 证监会/注协处罚高发：收入确认时点错（结算单/报关）、应付暂估不实、模具/组装加工核算不当、质保/三包费用调节、关联方资金占用。
- 与「机械制造」差异：二者均订单式生产，但汽车零部件配套整车厂、按结算单时点确认且具模具/三包/组装加工等特有核算；机械制造偏向整机直销与安装/试运行条款。
- 与「金属加工」差异：汽车零部件无金属市价主导的"加工费"定价与套期保值业务，关注点在配套结算时点与质量索赔。
