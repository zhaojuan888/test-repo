# 金属加工业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——金属加工业》第五章「行业审计特点」。有色金属加工业定价模式为"原材料价格 + 加工费"，毛利率一般不高（毛利不超过加工费），原材料占比远大于加工费；属资本密集型、资金压力大，票据/信用证融资及套期保值业务普遍。

## 一、行业经营与核算特点
- 资本密集型，大宗原材料（铜、铝等）采购资金需求大、流动资金压力大，易产生假交易真融资（票据、信用证）。
- 定价模式"原材料价格 + 加工费"，边际利润≈加工费减工费，故毛利率一般不高；原材料市价波动直接传导至售价与成本。
- 销售模式含工厂交货、最终用户工地交货等，部分含安装/试运行；信用销售（按揭、融资租赁、分期、以租代售）复杂。
- 标志性科目：原材料、库存商品、应收账款（单位价值大、单笔金额大）、应付账款/应付票据/预付账款、套期保值（其他流动资产/公允价值变动损益/投资收益）、在建工程/固定资产、长短期借款。

## 二、关键业务流程
采购（大宗原料，请购→订货→验收→入库→暂估/付款，多用票据/信用证融资）→ 生产（按工艺与产能排产，水电能耗稳定）→ 销售（接单/定价→发货→开票→收款，含套期保值匹配现货）→ 套期保值（期货开仓/平仓对应采购合同或销售订单）→ 回款/融资（应收、票据贴现、信用证）。

## 三、主要审计风险领域

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入确认/特殊交易 | 创新交易模式掩盖实质；以发货/签收不当确认；年末集中发货冲业绩 | 高 |
| 毛利率异常背离市价 | 单位售价/成本明显背离当月市场均价；加工费不涨而毛利异动 | 高 |
| 收入与现金流不匹配 | 放宽信用期虚增收入，或虚假销售致应收无法收回 | 高 |
| 应付票据/虚假融资 | 无真实交易背景开票；保证金质押、逾期未兑付未披露；关联方占用 | 高 |
| 函证控制失效 | 未对询证函过程保持控制致虚增收入/采购（参考万福生科案） | 高 |
| 存货/成本调节 | 单位成本临近期末突降；工艺与核算方法不匹配；跨期 | 中高 |
| 套期保值无效/虚计 | 长期挂账持仓无对应现货；公允价值/损益计算错误 | 中高 |
| 在建工程转固/减值 | 转固时点或预转固价值不当；闲置设备未提减值；使用寿命估计不合理 | 中高 |
| 关联方交易非关联化 | 关联交易手续不全、无现金流或资金转回、一次性非核心交易 | 中 |
| 研发费用划分 | 研究/开发阶段支出混淆，应资本化误费用化或反之 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入分析程序 | 收入/毛利率异常 | 分产品分月比较单位售价/成本与权威市场均价；毛利率与同业对比；产能、水电能耗、劳动生产率印证销量；收入与经营性现金流匹配分析 |
| 收入截止/发生测试 | 提前确认 | 从凭证追查发票/合同/出库回执/运单；外销查报关单、提单，必要时向海关函证；截止测试核对开票通知、发票、签收时间 |
| 应收账款函证 | 函证失效/虚增 | 对大额、长账龄、异常、关联方客户函证余额及发生额；保持发函过程控制，回函不符查差异，未回函执行替代/期后收款测试；核查客户工商资料排查关联方 |
| 应付票据审计 | 虚假融资/披露 | 核对汇票种类/编号/到期日/收款人；复核承兑保证金并与其他货币资金勾稽；查企业信用报告（审计人员直取）；向银行/收款人函证；查逾期转短借/应付账款 |
| 应付账款/预付审计 | 低估负债/占用 | 暂估清单与送货单/入库单/合同核对并查期后开票；大额预付查是否关联方资金占用（转其他应收款）；主要供应商实地走访+工商核查 |
| 生产能力审计 | 虚增产量 | 采集设备原设计/实际产能、水电气结算单；生产稳定时动力耗用应稳定，产量大耗用少则疑点，印证财务数据真实性 |
| 成本审计 | 成本调节 | 了解工艺与核算方法是否匹配、前后一致；按行业指标（投入产出比、损耗率）分析单位成本；临近期末单位成本突降重点核查 |
| 套期保值审计 | 无效/虚计 | 向期货公司直发函证（持仓、保证金、变现限制）；台账与现货合同/点价单/领料单/发货单时间数量勾稽；重算公允价值与损益；长期挂账持仓无现货则作无效套保 |
| 在建工程/固定资产 | 转固/减值 | 立项文件与实际进度比较；现场观察是否已达预定可使用状态未转固；复核使用寿命与同行业折旧率；关注闲置与减值 |

## 五、特殊会计事项
- 套期保值：区分公允价值套期/现金流量套期，有效性测试与公允价值计量是难点；持仓期货长期挂账且现货不可执行应作无效套保并平仓。
- 借款费用资本化：专门/一般借款资本化起讫时间与资产范围，整体匡算合理性（金属加工业固定资产多在在建工程中转入）。
- 研发费用：合理区分研究阶段（费用化）与开发阶段（符合条件资本化），关注立项审批与领料单区分。
- 税务：增值税、企业所得税适用制造业；大宗原料涉及进口关税/增值税（如进口原料）。

## 六、监管关注 / 与其他行业差异
- 指南明确引证"中磊所万福生科IPO审计失败"——函证过程未保持控制致未发现虚增收入与采购，凸显应收/应付账款函证控制的重要性。
- 证监会/注协处罚高发：收入提前确认、虚假票据/信用证融资、函证失效、存货与成本调节、套期保值损益不实。
- 与「机械制造」差异：金属加工以"原材料价+加工费"定价、毛利薄且受金属市价主导，并有套期保值这一独特业务；机械制造单件价值更高、以销定产、确认时点更多样（含安装/试运行）。
