# 园林业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——园林业》第五篇「重要的审计领域及审计程序」。园林工程企业审计三大核心领域：**收入（完工百分比法下的合同总收入/预计总成本/完工进度）、存货（已完工未结算工程）、应收账款（政府/国企客户回款）**。

## 一、行业经营与核算特点
- 资金密集型、项目周期长（投标→施工→竣工→审价→决算，审价报告常滞后 3–5 年），以项目管理为主线，以成本管控为目标建立内控体系。
- 客户以地方政府/国有投资主体（市政园林）和房地产企业（地产园林）为主，2017 年园林绿化企业资质取消但地方招标仍普遍要求资质；PPP 模式应用广泛且回款风险高。
- 收入确认采用**建造合同完工百分比法**：招投标有明确工程量清单、结果能可靠估计的，按完工百分比确认合同收入与费用；边设计边施工、结果无法可靠估计的，不采用完工百分比法。
- 标志性科目：存货（已完工未结算/工程施工）、应收账款、工程结算（已结算未完工）、预收账款（投标/履约/质保金）、消耗性生物资产（需培育苗木）。

## 二、关键业务流程
立项评估（技术/成本/风险）→ 中标/签施工合同（办履约保证金）→ 编制预算（预计总收入/预计总成本）→ 施工采购（苗木、石材、劳务分包）→ 上报已完工程量（监理+业主确认）→ 进度款结算（完工量 70%–80%，竣工 75%–85%，决算 90%–95%）→ 竣工验收交付 → 第三方审价（3–5 年出报告）→ 质保金收回（余 5%–10%，质保期≥1 年）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入/完工进度操纵 | 预计总收入、合同预计总成本随意调节；完工进度（成本法/工程量法）人为操纵致收入跨期；变更联系单滞后确认、超预算补偿不确定 | 高 |
| 存货（已完工未结算）高估与减值 | 长期未决算的已完工未结算存货未提跌价；合同预计总成本＞总收入形成的合同预计损失未确认当期费用 | 高 |
| 应收账款坏账 | 政府/国企客户回款慢、账龄长，减值测试不足，坏账准备计提不充分 | 中高 |
| 采购真实性/体外支付 | 供应商多为个体工商户，虚假采购、不实领用；材料/劳务单价偏离市场行情，体外费用 | 中 |
| 工程结算完整性 | 已完工未及时结算或结算不实，虚增已完工未结算存货余额 | 中 |
| 消耗性生物资产（苗木）减值 | 自育/外购需培育苗木受气候、冻害、价格波动影响，毁损或跌价未计提 | 中 |
| PPP/政府回款风险 | 地方财政恶化、项目融资不到位、延期完工超支，影响收入可实现性与回款 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 合同总收入/预计总成本复核 | 收入操纵 | 新项目核对中标通知书、合同清单、施工图纸；在建项目查变更（变更联系单/补充协议/监理签证）；重大金额比对收入成本数量配比、单价 vs 市场价；分析预计毛利率是否偏离历史 |
| 完工进度与收入重算 | 收入操纵 | 取得完工进度计算表、收入确认计算表重新计算；优先以监理+业主确认的工程量完工进度验证，或以成本完工进度交叉验证 |
| 已完工作量外部证据核查 | 收入完整性 | 取得三方盖章竣工报告；产值确认单/监理月报/付款审批单等第三方证据；向客户、监理独立发函确认工程量；重要项目现场查看完工状态 |
| 累计实际成本核查 | 成本真实完整 | 供应商送货单/入库单/结算单与账面核对；监理月报核对完工进度；重要项目现场盘点清点；主要供应商发函；查期后单据防跨期 |
| 工程结算与应收账款确认 | 结算完整性/坏账 | 建在建项目清单，按合同重算应结算金额与账面比对；筛选完工 100% 项目查验收/移交单时点是否全额确认结算及应收；重算金额 |
| 存货跌价/合同预计损失 | 存货减值 | 筛选总成本＞总收入项目，查（超额×(1−完工%)）是否确认当期费用；长期未决算项目做减值迹象判断并计提 |
| 应收账款坏账 | 坏账 | 余额表结合合同付款条件查超期；超期单独减值测试并访谈重要客户；结合以前年度核销与期后回款验证充足性 |
| 采购/施工成本真实性 | 体外支付 | 请购单/合同/发票/送货单/入库单相互验证；已完成工程量工料机实际耗用 vs 理论耗用比对；供应商工商查询（新设、距离、规模匹配）；按月/季盘点库存 |
| 苗木/生物资产盘点 | 生物资产减值 | 对需培育苗木查收发存台账与现场存活状况；结合市价与冻害/气候风险测试消耗性生物资产可变现净值 |

## 五、特殊会计事项
- **完工百分比法适用判断**：有明确工程量清单→结果可靠估计，用完工百分比；边设计边施工→无法可靠估计，不确认收入（按准则以能收回成本确认）。
- **存货即建造合同已完工未结算**：单列存货跌价准备，对合同预计损失（总成本＞总收入）及长期未结算项目计提。
- **消耗性生物资产**：直接用于工程的苗木计入工程施工；需假植/定型培育的苗木计入消耗性生物资产。
- **税务**：2016 年营改增后施工/设计/养护均征增值税；跨区域经营且苗木、劳务等难取得专票，税负与利润受影响，采购需关注进项税合规。

## 六、监管关注 / 与其他行业差异
- 证监会/注协处罚高发：完工进度操纵致收入跨期、已完工未结算存货减值不充分、应收账款坏账、PPP 回款及并表。
- 与「建筑业」差异：同用完工百分比/建造合同，但园林存货以已完工未结算为主、材料含苗木（生物资产）；与「房地产」差异：园林是施工方，收入按完工百分比而非交付时点。
