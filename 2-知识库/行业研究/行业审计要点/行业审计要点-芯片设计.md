# 芯片设计业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——芯片设计业》第三篇「重要审计领域」。芯片设计（Fabless）企业审计五大核心领域：**收入（经销压货/舞弊）、研发费用（混同与资本化）、应收账款减值、存货减值、预付账款减值**。

## 一、行业经营与核算特点
- Fabless（无晶圆厂）模式：仅负责芯片设计与销售，生产委外代工厂（Foundry）；技术密集+资本密集，研发与流片投入巨大。
- 收入确认：芯片销售为主，经销模式常见，以客户签收/验收合格为收入确认时点；经销商压货、提前确认风险高。
- 标志性科目：存货（晶圆/芯片/委外加工物资）、应收账款、研发费用/开发支出（资本化）、预付账款（流片/代工预付款）。

## 二、关键业务流程
研发立项（工时系统+预算）→ 流片（晶圆投片，成功报告为关键里程碑）→ 委外代工（Fab 生产）→ 销售（经销/直销，签收确认）→ 收款（客户集中度高风险）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入确认（经销压货/提前确认） | 四季度突击确认；经销商频繁进出、压货虚增收入；签收/验收单据缺失或不可靠 | 高 |
| 收入舞弊（关联交易非关联化/体外循环） | 通过员工/前员工控制的经销商虚构交易；IP/MAC 重合的资金体外循环 | 高 |
| 研发费用与生产成本混同 | 量产调试用料计入研发费用美化毛利；研发领料与产领混淆 | 高 |
| 研发支出资本化不当 | 资本化时点前置（仅算法模拟即资本化）、研究阶段支出资本化、开发支出减值不足（如流片受阻未减值） | 高 |
| 应收账款减值 | 客户集中、长账龄（特种电路货款周期约 1 年）、放宽信用政策扩大应收 | 中高 |
| 存货减值 | 技术迭代、定制产品客户取消合作、行业下行周期导致滞销 | 高 |
| 预付账款减值 | 流片/代工预付款因技术更新、项目终止无法收回 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 评价收入确认政策+同行业对比 | 收入确认 | 对比卓易信息/寒武纪等同业政策；抽查合同关键条款（控制权转移、验收） |
| 实质性分析（收入/毛利穿透） | 收入舞弊 | 收入增速与海关/下游产量比对；月度波动分析；分产品分客户毛利率纵向横向"穿透分析" |
| 支持单据检查（含替代程序） | 收入确认 | 内销查签收单/物流，外销查报关单/提单；强势客户无验收报告时取 EDI/邮件/期后回款替代 |
| 函证（全过程控制） | 收入/应收 | 独立发函；未回函不单靠期后回款，须查合同单据；重要客户设问验收日期 |
| 截止测试 | 收入跨期 | 资产负债表日前后 1 个月双向追查（从发货记录追至收入） |
| 退换货+关联方穿透核查 | 收入舞弊 | 企查查比对法定代表人/股东；IP/MAC 重合排查；社保由发行人缴纳证明控制关系 |
| 经销商进销存与终端销售核查 | 经销压货 | 分层抽样（前二十大+新增退出+特殊关系）；序时库存测算"期初+采购-销售=期末"，负数必查；高风险经销商突击监盘 |
| 研发支出与生产成本混同检查 | 费用混同 | 研发领料追踪 BOM；通用物料分摊方法一贯；试制订单成本路径核实 |
| 研发工时系统穿透+薪酬分摊 | 研发费用 | 测工时系统防篡改；考勤/项目进度交叉验证；高管/核心人员薪酬分摊比例合理 |
| 资本化五条件逐项测试+流片里程碑+减值 | 资本化 | 查流片成功报告等里程碑；研究/开发阶段划分；获取减值测试报告并做敏感性分析（悲观情景补提） |
| 应收账龄重算+迁徙率+ECL | 应收减值 | 重算账龄防人为调整；复核预期信用损失模型及前瞻性调整；长账龄可收回性 |
| 存货跌价测算+库龄+监盘（含委外仓） | 存货减值 | 复核可变现净值参数；库龄越长风险越高；委外仓重点监盘防舞弊 |
| 预付账款减值测试 | 预付减值 | 获取减值测试表评估关键参数；管理层未计提则重测并补提 |

## 五、特殊会计事项
- 研发资本化：首次流片失败支出通常费用化；资本化起点以关键技术里程碑（首次流片成功）为准。科创板对流片资本化持谨慎态度，比例过高易引发问询。
- 流片费用：晶圆投片费用巨额且结果不确定，资本化需严格满足五条件。
- 税务：研发费用加计扣除、高新技术企业 15% 税率；申报口径与财务核算口径需匹配。

## 六、监管关注 / 与其他行业差异
- 证监会处罚/问询高发：收入舞弊（经销商穿透）、研发费用真实性、资本化激进、开发支出减值不足。
- 与"半导体制造/封测"差异：芯片设计（Fabless）无重资产生产线，重点在研发与存货（晶圆），制造环节在代工厂。
