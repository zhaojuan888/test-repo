# 电池材料业（锂电正极材料） 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——电池材料业》第三篇「重要审计领域」。锂电正极材料企业审计四大核心领域：**收入（虚增/返利）、存货（粉体存在性与跌价）、长期资产（转固与减值）、应收账款信用减值**。

## 一、行业经营与核算特点
- 锂电正极材料（三元/磷酸铁锂等），下游为大型电池厂（宁德时代、比亚迪），客户集中度极高；原材料（锂/钴/镍）现货价格波动大，定价多为"材料成本+加工费"。
- 收入确认：随销量确认；存在销售返利、年终折扣，且客户与供应商重叠（实为委托加工）情形。
- 标志性科目：存货（粉体原料/正极材料，外观难辨、计量专业）、应收账款（长账龄信用减值）、在建工程/固定资产（产线改扩建密集）、长期资产减值。

## 二、关键业务流程
采购（锂盐/前驱体，金属现货挂钩）→ 生产（粉体合成，水分敏感）→ 销售（直销大客户/经销，含返利）→ 回款（长信用期）→ 产能扩张（在建工程转固）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入高估/提前确认 | 通过贸易商体外循环售出再购回；突击新增非主流客户；业绩对赌/上市压力下虚增 | 高 |
| 收入舞弊（返利/商业实质） | 异常优惠信用期/价格；复杂返利未入账；客户供应商重叠按购销虚增营收 | 高 |
| 应收账款信用减值不足 | 行业下行、产能过剩下少计提信用减值损失 | 中高 |
| 存货存在性（虚增） | 粉体外观难辨，开袋冒充；散装料仓估算高估库存 | 高 |
| 存货跌价准备不足/操纵 | 预计售价口径随意；下行期少提、反弹期大幅转回平滑利润 | 高 |
| 长期资产（在建工程）转固不当 | 延迟转固以增加利息资本化、减折旧；厂房与产线未分步转固 | 高 |
| 长期资产减值不足 | 技术路线变更/产能过剩下忽视减值 | 高 |
| 政府补助 | 指南未单列专项风险；按通用审计程序关注与资产/收益相关的划分及递延（产线投资补贴附条件） | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 函证（全程独立控制） | 收入/应收 | 独立寄发；核对发函地址与工商一致；防伪标识；二次回函异常识别舞弊；替代程序覆盖全部未回函 |
| 主要客户销售分析+返利核查 | 收入高估/返利 | 月度/产品毛利率波动分析；检查销售返利账务处理与行业惯例 |
| 存货监盘（开袋+实验室检测） | 存货存在 | 增加不可预见性，中间堆存货开袋；送实验室测金属含量；料仓体积×堆积密度重算；专家监盘 |
| 存货跌价准备充分性 | 跌价操纵 | 结合库龄/售价波动；同行业比较；长库龄(1年以上)/技术淘汰(低镍→高镍)重点；转回须有客观证据且不超过原计提 |
| 在建工程减少分析+转固 | 转固不当 | 实地观察进度；监理报告；厂房与产线分步判断预定可使用状态；利息/薪酬/备品资本化正确 |
| 长期资产减值测试 | 减值不足 | 评估资产组划分；产能利用率/闲置；固定资产监盘；复核减值模型关键假设；利用专家工作 |
| 供应商/客户背景调查 | 收入舞弊 | 客户供应商重叠识别；关联方排查（实控人持股） |

## 五、特殊会计事项
- 存货计量：粉体（锂盐/前驱体/正极材料）外观难辨、水分敏感，监盘与实验室检测必要；可变现净值估计主观强。
- 在建工程：产线改扩建频繁，转固时点（厂房 vs 产线分步）与利息资本化金额重大。
- 政府补助：指南未单列专项审计程序，按通用审计处理——关注与资产相关/收益相关的划分、递延收益摊销、是否附条件（如投资强度/产能）。
- 税务：高新/研发加计；出口相关业务。

## 六、监管关注 / 与其他行业差异
- 监管高发：产能过剩下收入虚增、存货跌价操纵（计提与转回）、在建工程延迟转固、长期资产减值不足。
- 与"光伏/电子材料"差异：正极材料下游绑定电池巨头，客户集中度与返利更复杂；存货形态为粉体，存在性认定难度高。
