# 房地产业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——房地产业》第五篇「重要的审计领域及审计程序」。房地产开发企业审计三大核心领域：**收入（交付时点确认）、成本（归集结转）、借款费用（资本化）**。

## 一、行业经营与核算特点
- 资金密集型、项目周期长（拿地→开发→预售→竣工→交付→过户），财务记录信息单一，审计以会计记录为切入点判断真实完整难度大。
- 收入确认采用**交付时点**（非预售、非过户）：同时满足五条件（验收合格、合同履约、风险报酬转移、金额可靠、成本可靠）方可确认。
- 标志性科目：存货（开发成本/产品）、预收账款（预售款）、营业收入/成本、长期借款、应交税费（土增税/所得税）。

## 二、关键业务流程
拿地（保证金/出让金）→ 融资（银行借款，土地及在建抵押）→ 开发（施工/采购合同、动态成本）→ 预售（预售许可证、一房一价）→ 竣工备案 → 交付（风险报酬转移、确认收入）→ 产权过户 → 土增税清算。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入跨期/提前确认 | 预售阶段即确认收入；以过户而非交付为时点；面积误差>3%仍确认 | 高 |
| 成本归集结转不完整、随意 | 暂估成本长期不调整；决算审价差异滞后；不同业态结转方法不一致 | 高 |
| 借款费用资本化区间操纵 | 资本化开始/暂停/停止时点人为调节，影响当期损益重大 | 高 |
| 土地增值税清算补缴未预提 | 项目毛利率偏高，清算后巨补税全计入当期，违反配比/谨慎 | 中高 |
| 关联方资金占用 | 其他应收/应付大额进出，控股股东变相占用（上市公司重点） | 中 |
| 按揭阶段性担保披露遗漏 | 滚动担保无台账，12.31 时点金额取不到，附注披露不完整 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入确认标准测试 | 收入跨期 | 抽取样本核对：预售许可证范围、竣工备案表、测绘成果、交房通知签收；以交付期满为确认时点；面积误差>3%不确认 |
| 销售收入明细清单核对 | 收入完整 | 索取房号/面积/单价/预收/交付清单，与预收账款明细、合同领用归档交叉核对 |
| 成本结转测试 | 成本随意 | 查成本结转计算表编制与审核；暂估 vs 决算审价差异及时调整；不同销售部分结转方法一致性 |
| 借款费用重新测算 | 资本化操纵 | 索借款合同，结合施工进度判断资本化期间；重算专门/一般借款资本化利息 |
| 税金测算 | 土增税/所得税 | 按国税发[2009]31号测算预计毛利与实际毛利差异；土增税按收入占比预提；核对申报表 |
| 大额资金进出检查 | 关联方占用 | 筛银行账户大额进出，查凭证实质；其他应收/应付背景分析 |
| 担保抵押披露 | 披露遗漏 | 管理层声明书+抵押合同+贷款卡+银行函证；查受限货币资金、土地/房产原件质押 |

## 五、特殊会计事项
- **收入时点**：交付 vs 过户的法律差异；投资客延迟交付的特殊处理（交付期满风险转移可确认，面积误差>3%除外）。
- **借款费用**：开始（三条件）、暂停（非正常中断）、停止（竣工达交付条件）资本化时点。
- **税务**：营业税（旧项目）/土增税清算/企业所得税（31号文）预缴与汇算；预缴税金重分类至其他流动资产。

## 六、监管关注 / 与其他行业差异
- 证监会处罚高发：收入提前确认、成本不实、资金占用、担保披露遗漏。
- 与「房地产建安」差异：开发企业侧重存货（开发产品）与收入确认；建筑企业侧重完工百分比与建造合同。
