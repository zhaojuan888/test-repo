# 有线电视网络业审计风险与关键程序

> 蒸馏自中注协《行业审计指南——有线电视网络业》第五篇「重要的审计领域及审计程序」与第六篇审计案例。本行业审计三大核心：**BOSS 系统收入确认与分摊、预收款完整性、长期资产（埋地管网/在用户端设备）存在性与减值**。

## 一、行业经营与核算特点
- 主营有线电视网络建设、节目内容传输服务；受工信部与广电总局监管，开展互联网电视需"集成业务 + 内容服务"双牌照，基本收视费等资费由物价部门核定。
- 收入来源：基本收视费、入网安装/初装费、传输服务收入、增值服务收入（VOD、宽带数据等）。传统业务 ARPU 呈下降趋势，增值服务为利润增长点。
- 收入确认两类：①按 BOSS 系统业务记录以客户受益期分摊（基本收视费、增值、数据业务、合作分成）；②按合同约定受益期或履行完毕确认（节目传输、入网费）。存在一次/分期/按工程进度/按合同/分离确认等多种方式。
- 标志性科目：预收款项（先缴费后开通，个人客户余额大）、主营业务收入、应收账款（较少，主要为外省台传输费）、固定资产/在建工程（网络资产埋地或分布于用户端，占比高）、递延收益（入网费）、长期待摊费用（内容授权）。

## 二、关键业务流程
用户申请入网 → 签订入网协议 → BOSS 系统登记并开通资源 → 收费（先缴后开）→ 按月分摊确认收入（系统类）/合同确认（合同类）→ 营业款缴存 → 预收结转；网络侧：立项可研→设计会审→招标→到货验收→初验终验→竣工决算→在建工程转固定资产→折旧/摊销；内容侧：授权采购→成本分摊或运营分成。

## 三、主要审计风险领域
| 风险领域 | 风险描述 | 常见舞弊/错报情形 |
|---|---|---|
| 收入确认政策与 BOSS 一致性 | 系统数据与财务基础数据须一致，收入按受益期分摊 | 收入在当期收入与预收/应收间随意调节；篡改系统导出数据使与账面一致 |
| 收入舞弊（ presumption） | 基于收入确认存在舞弊风险的假定 | 虚构客户或合同、虚增在网用户数、虚列收入 |
| 预收款完整性 | 先缴后开，个人客户海量、余额大 | 预收不入账、长期挂账不结转、跨期确认 |
| 应收账款与坏账 | 余额较小但存在外省台等赊销 | 坏账计提不当、关联方款项未识别/未抵销 |
| 成本费用划分 | 成本与期间费用范围易混淆，资本性/收益性支出界限 | 应费用化计入资产、资本化支出误费用化 |
| 长期资产确认 | 固定资产/在建工程/无形资产/长期待摊的价值、利息资本化 | 提前结转固定资产、应转未转、资本化起止期间不当、权属/受限不清 |
| 长期资产减值 | 资产埋地/在用户端、技术迭代快，难监盘 | 减值准备计提不足；每用户/每千米造价异常未识别 |
| 隐匿负债 | 应付账款/预付中含未入账负债 | 料到单未到、供应商发票未处理导致负债漏记 |

## 四、关键审计程序
| 审计程序 | 目的 | 关键执行要点 |
|---|---|---|
| 用户数统计分析（分析程序） | 收入确认基础证据 | 从 BOSS 取用户数/价格/优惠/缴费统计；按在网类型与优惠策略分析；按收费标准受益期测算收视/宽带/增值/分成收入 |
| 会计政策评估与双向核对 | 确认方法合规 | 业务分类与确认政策符准则；BOSS 逐月分摊与财务数据双向比对；异常月度波动警惕舞弊 |
| 定价与税金测算 | 收入真实 | 取得物价部门批准文件（必要时函证物价局）；增值税申报表/开票系统、营业税测算与开票收入比对 |
| 收入细节与截止测试 | 防舞弊/跨期 | 抽销售发票核对开票/记账/业务日期；系统数据测算与报表核对；询问财务人员以外人员；虚构客户延伸检查（业务记录、现金缴费、银行流水、客户维护） |
| 预收款审计 | 完整/分摊 | 分月明细分析；抽业务系统记录、资源开通关停、收款凭证、银行流水；重算分摊；期后转销检查；长期挂账关注；函证（个人客户多不适用，注原因并执行替代） |
| 应收账款审计 | 真实/坏账 | 账龄分析、期后回款；关联方标明并抵销；函证（除非不重要或无效） |
| 营业成本审计 | 范围准确 | 月度波动与同行业毛利率比较；检查支持性文件；关注停机/注销等非常规；成本与收入口径配比；查其他应收/预付中应结转未结转成本 |
| 应付账款/预付审计 | 完整/隐匿负债 | 供应商对账单调节；查长期挂账；资产负债表日后入库资料查料到单未到；函证；预付列报（是否应在在建工程等） |
| 长期资产审计 | 确认/资本化/减值 | 固定资产原值大、埋地难监盘，结合内控与决算核实，必要时利用专家（CSA 1421）；折旧分析；在建工程转固勾稽、暂估、资本化利息重算；每用户/每千米造价与同行比判断减值 |
| 组成部分审计 | 多地营业分区 | 按地域设营业分区、统一总部管理；选取重要分区现场审计 |

## 五、特殊会计事项
- **一次性入网费/初装费/配套费**：按财会〔2003〕16 号记入"递延收益"，在合同规定或能合理确定的服务期限内平均摊销确认收入；合同未规定且无法合理估计的，按不低于 10 年分摊；终止服务或转让时余额一次确认。
- **收入多形式确认**：系统类（BOSS 按受益期分摊）与合同类（安装/传输，细节测试为主）并存；增值业务、买赠/捆绑销售需识别收入划分。
- **内容/新媒体成本**：授权期分摊（长期待摊→成本）或按运营分成（依运营商系统出账）；保底价 + 运营分成结合处理。
- **税务**：有线数字电视基本收视维护费、农村有线电视基本收视费免征增值税；营改增前后营业税/增值税分别处理。

## 六、监管关注与差异
- 监管：工信部为主管部门，广电总局负责内容监管；互联网电视须"集成 + 内容"双牌照；基本收视费等资费由物价部门核定；受三网融合、IPTV/网络电视竞争。
- 审计关注：收入舞弊假定、BOSS 系统数据可靠性（必要时 IT 审计/专家）、预收款完整性、长期资产（网络）确认与减值、隐匿负债。
- 与电信业差异：广电网络具区域垄断与牌照管制，收入以基本收视费 + 入网费为主，固定资产（网络）比重极高且埋地难监盘。
- 与零售业差异：面向企业/政府（传输）与个人（收视）混合，预收款模式、服务按受益期分摊、几乎无存货。
