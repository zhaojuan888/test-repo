# 零售业（连锁经营）审计风险与关键程序

> 蒸馏自中注协《行业审计指南——零售业（连锁经营）》第五篇「重要的审计领域及审计程序」。零售连锁审计三大核心：**收入真实性/截止、平销返利与促销服务费、门店存货盘点与跌价**。

## 一、行业经营与核算特点
- 以直营连锁为主（超市自营、百货联营），辅以特许经营；统一采购、统一配送、统一核算，轻资产、高杠杆（行业资产负债率约 63%）。
- 收入确认区分四种模式：自营（交付商品并收讫价款时按总额确认）、联营（统一收银、按约定扣点净额确认）、代销、租赁（权责发生制确认租金）。超市业态以自营为主，百货业态以联营为主。
- 标志性科目：主营业务收入、其他业务收入（进场费/陈列费/返利/促销服务费等）、存货、应付账款（供应商返利）、销售费用（租赁费/薪酬/广告费占比高）、预收（会员/礼品卡）。
- 高度依赖零售收银系统 + ERP + 供应链 + 财务系统，营业款多结算方式（现金/银联/医保/电商），门店分散、现金交易频繁。

## 二、关键业务流程
集中采购/招商（供应商合同、联营协议）→ 配送中心验收入仓（ERP）→ 门店铺货/联营专柜 → 门店销售收银（零售系统，多结算方式）→ 营业款缴存（营业缴款单→指定银行账户）→ 系统对账（收银系统 vs 银行流水）→ 供应商对账与返利/服务费结算 → 期末存货盘点与报损。

## 三、主要审计风险领域
| 风险领域 | 风险描述 | 常见舞弊/错报情形 |
|---|---|---|
| 收入真实性与完整性 | 收入来源分散、单笔小、现金多，主要依赖信息系统统计 | 账外收入、坐支现金、营业款未及时足额缴存；虚增门店收入 |
| 收入跨期 | 收入与预收/应收在期末被人为调节 | 资产负债表日前后提前或延后确认收入；系统外调节 |
| 存货存在性与完整性 | 品类繁多、存放地点分散、盘点工作量大、成本结转依赖 ERP | 门店/仓库盘亏不上报、账实不符；临期/残次商品未报损 |
| 存货跌价准备 | 部分商品受保质期限制，滞销商品存在减值 | 跌价准备计提不足或随意转回以调节利润 |
| 货币资金完整性 | 现金交易频繁、银行账户多、期末余额大 | 私设小金库、账外账、收银款截留 |
| 平销返利/促销服务费 | 与销量、销售额挂钩的返利冲减成本，服务费确认其他业务收入 | 返利计算错误、进项税转出遗漏、返利/服务费不入账 |
| 销售费用真实性与跨期 | 租赁费、职工薪酬、广告费占销售费用比重大 | 虚列广告费、租赁门店不实、费用跨期入账 |
| 信息系统依赖 | 收入成本高度依赖零售/ERP 系统 | 篡改业务系统导出数据使与账面一致，掩盖错报 |

## 四、关键审计程序
| 审计程序 | 目的 | 关键执行要点 |
|---|---|---|
| 主营业务收入分析性程序 | 核实交易合理性、识别异常 | 与上期比结构/毛利率；月度波动与季节性比对；门店间对比；客单量×客单价、单笔交易影响、月平效分析；毛利率同行业对比 |
| 收入与系统核对 | 防漏记/虚增 | 账面收入与零售系统销售总额核对；抽门店全年销售额与收款方式汇总核对；抽某日收入日报表/缴存银行日报表与系统、银行凭证核对 |
| 收入截止测试 | 防跨期 | 资产负债表日前后抽查门店凭证与系统当日销售额双向核对 |
| 成本倒轧与结转核对 | 成本准确 | 编制主营业务成本倒轧表，与存货收发勾稽；复核 ERP 结转成本与账面；关注供应商票面折扣等非常规调整 |
| 供应商返利/服务费审计 | 返利/服务费完整 | 采购部门统计与账面核对；抽供应商按协议匡算平销返利；函证返利及服务费；匡算进项税转出 |
| 存货监盘与计价 | 存在性/计价/跌价 | 仓库全部纳入监盘，抽部分门店（一般难达 20%-30%，利用内审盘点）；计价测试；期末结存单价与合同/发票比对；结合库龄/保质期测跌价 |
| 货币资金/收银核对 | 完整及时缴存 | 出纳每日网银流水与收银系统门店收款统计表、收入日报表核对；查坐支、账外账 |
| 销售费用审计 | 真实/不跨期 | 门店租赁明细表匡算租金、抽租赁合同、函证出租方；广告合同+播放编排表测算并函证；截止测试 |
| 组成部分与门店审计 | 集团审计充分性 | 按 CSA 1401 识别重要组成部分（超基准 5% 或特别风险）；抽重要门店现场审计（内控、截止、监盘、原始单据） |

## 五、特殊会计事项
- **平销返利**：与销量、销售额挂钩的返利、进场费、促销费、管理费等，按平销返利规定冲减当期成本，并作增值税进项税转出。
- **联营模式**：销售前商场不取得商品所有权，售出后所有权同时转移商场与顾客，按扣点净额确认收入、结转成本。
- **促销服务费**：向供应商收取的进场费、陈列费、促销费、管理费等确认其他业务收入。
- **会员/礼品卡**：预收性质，涉及积分、会员、买赠、捆绑销售等复杂核算。
- **税务**：连锁经营汇总纳税（国家税务总局公告 2012 年第 57 号）；营改增（财税〔2013〕106 号）；商业预付卡税收管理（国税函〔2011〕413 号）；部分鲜活肉蛋、蔬菜免征流通环节增值税。

## 六、监管关注与差异
- 证监会/注协处罚与问询高发：收入真实性（现金与电商）、存货盘点与跌价、平销返利税务、联营净额确认、关联方资金。
- 与制造业差异：零售无产品生产加工，存货仅购进与销售；收入与成本高度依赖信息系统、现金比重大、门店分散。
- 与批发贸易差异：零售面对终端个人、现金交易为主、门店众多且分散，内控与盘点难度更高。
- 信息系统审计为本行业特色领域，需对零售/ERP 系统一般控制与应用控制进行测试。
