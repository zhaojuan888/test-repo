# 服装业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——服装制造业》第五篇「重要实质性程序」与第六篇审计案例。服装制造（含品牌运营）审计三大核心：**加盟渠道收入真实性、退货/换货准备、存货跌价**。

## 一、行业经营与核算特点
- 以加盟/直营双渠道为主，常生产外包（贴牌/OEM），提前 2-3 月备货应对季节；盈利驱动为款型迭代+渠道铺货。
- 收入确认：直营/加盟发货确认；委托代销、附退回条件销售按准则；出口以报关单/提单为时点。
- 标志性科目：库存商品（产成品/备货）、原材料、委托加工物资、应收账款（加盟商）、应收票据、预收款项、存货跌价准备、应付票据。
- 行业痛点：季节性强、款型迭代快、退货/换货频繁、加盟商资金弱（个体户多，函证无公章）。

## 二、关键业务流程
设计打样 → 面辅料采购（预付款）→ 委外加工/自产 → 入库（库存商品）→ 备货发运（直营/加盟/出口报关）→ 加盟商收货确认 → 退款/退换（退货准备）→ 期末结算（折扣/补偿/补贴）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入虚增（加盟店虚假销售） | 向空壳/关联加盟商压货确认收入，期末退货冲回 | 高 |
| 销售退回/换货准备不足 | 附退回条件、退货换券未足额计提，收入高估 | 高 |
| 存货跌价准备计提不足 | 季末滞销款型、无订单产成品不减值；可变现净值测算随意 | 高 |
| 应付票据套现/虚构票据 | 以票据融资虚增现金流或隐匿表外负债 | 中高 |
| 应收票据（虚拟票据业务）风险 | 无真实交易背景票据，背书/贴现不实 | 中高 |
| 折扣/补偿/补贴少计（截留负债） | 买赠、降价补偿费、经销商租金补贴从销售额扣减未确认费用 | 中 |
| 出口收入不实 | 报关单/提单与账面不一致，虚构外销 | 中 |
| 委托加工物资核算不实 | 委外数量/工费归集错误 | 中 |
| 关联方/主要供应商核查不足 | 未识别关联方交易、空壳供应商 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入截止+出口核对 | 收入/出口 | 出口核对报关单/提单；截止测试（发运单+签收）；直营与系统核对 |
| 加盟商核查+函证 | 虚假销售 | 主要加盟商工商登记核查；个体户函证由负责人签字按手印（无公章）；期后退货追踪 |
| 销售退回/退货准备测算 | 退回准备 | 分销商退货准备 1%、退货换券 10% 准备重算；期后退货冲回测试 |
| 存货跌价准备测算 | 跌价不足 | 订单/非订单原材料、订单/非订单产成品分别按可变现净值测算；季末款型库龄分析 |
| 应付票据/应收票据核查 | 票据风险 | 票据台账与银行核对；查贸易背景；应付票据套现追查资金流向 |
| 折扣补偿/补贴检查 | 少计负债 | 查买赠、降价补偿费、租金补贴、合作协议折扣合同，确认费用/收入扣减完整 |
| 委托加工物资测试 | 核算 | 委外合同+工费+收发明细核对 |
| 主要供应商工商核查 | 关联方 | 主要供应商工商登记，识别关联方未披露交易 |

## 五、特殊会计事项
- **附退回条件销售/委托代销**：按准则以控制权/清单转移为确认时点；退货准备计提（分销商 1%、退货换券 10%）。
- **买一赠一、折扣券、降价补偿**：视作可变对价或销售费用，影响收入/费用划分；零售降价补偿费从出货扣减。
- **免费提供货架**：计入销售费用，税务上或视同销售。
- **应付票据套现**：资金流向核查，识别表外融资。
- **生产外包（贴牌）**：委托加工物资核算，毛利在加工费与产成品间分配。

## 六、监管关注 / 与其他行业差异
- 证监会处罚高发：加盟商压货虚增收入、存货跌价不足、票据违规。
- 与「一般制造业」差异：渠道（加盟）信用风险高、退货频繁需准备、季节性强跌价压力大、个体户函证特殊。
