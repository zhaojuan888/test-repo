# 垃圾焚烧发电业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——垃圾焚烧发电业》第五篇「重要的审计领域及审计程序」。垃圾发电企业审计三大核心领域：**BOT 资产计量模式（金融资产/无形资产/固定资产）、长期资产（入账/折旧/减值）、收入（发电/供热/处置费及增值税退税）**。

## 一、行业经营与核算特点
- 资金密集型、重资产，固定资产投资大且单位价值高；普遍以 **BOT/BOO/PPP/TOT 特许经营**模式运作，与地方政府签特许经营协议（通常 25–30 年），期满无偿移交相关资产。
- 收入来源多元且多受政府管制：①发电收入（售国家电网，电价由物价局核定）；②蒸汽/供热收入（煤热价格联动）；③垃圾/污泥处置费（政府按处理量付费）；④资源综合利用增值税即征即退。
- BOT 后续计量三模式：有权向合同授予方收现金→**金融资产模式**；向使用者收费→**无形资产模式**；拥有资产所有权→**固定资产模式**。办公设备、车辆不属期满移交资产，仍列固定资产。
- 标志性科目：长期资产（固定资产/无形资产/BOT 资产）、在建工程、应收账款（电费/处置费）、其他收益（政府补助/退税）、预计负债（大修/弃置义务）、递延收益、长期应付款（融资租赁）。
- 生产特点：产品为电与蒸汽，期末无在产品，成本月末全结转；存货主要为燃煤（占存货 80% 以上），减值测试是管理重点。

## 二、关键业务流程
项目开发（寻特许经营项目）→ 成立项目公司/签特许经营协议 → 融资（银行借款，资产抵押）→ 建设（BOT 建造，可能确认建造收入）→ 试运行/商业运营（处理垃圾、发电上网）→ 运营收费（按月抄表结算电费、按处理量结算处置费）→ 增值税即征即退 → 期满资产移交。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| BOT 资产计量模式混淆 | 金融资产/无形资产/固定资产模式误判；办公设备/车辆误计入无形资产；建造阶段是否确认建造收入判断不当 | 高 |
| 收入确认（时点/跨期/关联） | 电费/蒸汽/处置费跨期；关联交易手续不全、定价不公允、无现金流；放宽信用期虚增销售致应收无法收回 | 高 |
| 长期资产入账/折旧/减值 | 借款费用资本化不当；折旧年限/方法前后不一；专用设备工况差、负荷大或闲置，可收回金额低于账面却未提减值 | 高 |
| 政府补助/增值税退税错报 | 垃圾处置费作为收入还是政府补助分类混淆；退税金额计算错误 | 中高 |
| 预计负债（大修/弃置）及递延所得税 | 弃置费用/未来大修估计不足；折现率选取不当；递延所得税处理错误 | 中 |
| 应收账款（电费/处置费）坏账 | 对政府/电网回款减值测试不足 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| BOT 模式判定与资产分类 | 计量模式混淆 | 按解释 2 号流程图判断：合同授予方是否控制服务价格及保留重大剩余权益→金融资产或无形资产；检查办公设备/车辆是否误计入无形资产；复核折现率（一般用国债利率或地方债到期收益率） |
| 收入分析性复核+发生测试 | 收入确认 | 分产品毛利率、电价（物价局核定）、汽价（煤热联动）分析是否背离市场；从凭证追查发票/合同/电网结算单/抄表/垃圾处理量单据；截止测试（凭证/开票/抄表时间一致）；关联方销售核查（手续、公允、现金流） |
| 长期资产实质性程序 | 资产入账/折旧/减值 | 实地检查重要固定资产（首次审计扩大范围）；权属证据（不动产权证/行驶证/融资租赁合同）；在建工程转入查竣工决算/验收/估计入账并计提折旧；折旧政策前后一致；减值测试（可收回金额、折现率，减值一经确认不得转回）；借款费用资本化复核 |
| 无形资产（BOT）专项 | 计量 | 检查土地/专用设备/房屋无形资产台账与实物台账；复核预计负债涉及的递延所得税（确认时调增、使用/冲回时调减）；复核预计负债变动会计处理 |
| 政府补助/增值税退税 | 补助错报 | 按准则 16 号判断处置费是否属收入对价（与商品服务密切相关→主营业务收入）；按每月处理收入×退税率复核全年应退税额并与实收核对 |
| 预计负债 | 预计负债 | 复核弃置费用估计方法与现值计算；折现率合理性；因技术/法律/市场变动导致的预计负债变动会计处理 |
| 应收账款 | 坏账 | 结合收入审计函证主要客户；账龄与回款分析；关注关联 |

## 五、特殊会计事项
- **BOT（解释 2 号第五条）**：建造期间提供实际建造服务的，按建造合同确认收入并同时确认金融资产或无形资产；未提供实际建造服务（全部发包）不确认建造收入。A 股惯例下建造阶段通常不确认建造收入（与部分 A+H 公司国际准则做法不同）。
- **三模式划分**：收现金合同权利→金融资产；向使用者收费权利→无形资产；拥有所有权→固定资产。
- **政府补助**：与商品/服务对价密切相关的经济资源（如垃圾处置费）适用收入准则，计入主营业务收入；增值税即征即退计入其他收益。
- **借款费用资本化**：建设期专门/一般借款利息资本化计入 BOT 资产成本。
- **弃置费用/预计负债**：期满移交资产的后续大修、弃置义务按现值计入资产与预计负债，产生递延所得税资产/负债；预计负债变动需合规处理。

## 六、监管关注 / 与其他行业差异
- 证监会/注协关注高发：BOT 资产计量模式（金融资产/无形资产划分及建造收入确认）、收入跨期、政府补助分类、固定资产减值、关联方资金占用。
- 与「传统电力/制造业」差异：核心是特许经营+BOT 三模式，资产后续计量特殊、价格受政府管制、附移交与弃置义务；与「环保水务（BOT）」逻辑相近但处理对象不同。
