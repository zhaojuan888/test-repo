# 纺织业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——纺织业》第五篇「重要的审计领域及审计程序」。纺织业审计可参照一般生产型企业的审计策略，收入确认与成本核算是永恒主题；细分领域（纺纱/织布/印染/服装加工/纺机）各有特殊风险。

## 一、行业经营与核算特点
- 劳动密集型、连续化多工序生产；原料（棉、丝、麻、化纤）占生产成本比重大，多为初级农产品、常向农户现金收购，原始单据缺失、单位金额小。
- 资产结构中固定资产比重较大（纺机、进口设备），且易跌价；产品流行期短、价格随季节/时尚波动快、毛利率低、品牌效应渐显。
- 销售以商品销售收入 + 印染加工收入（来料加工）为主，确认一般以满足"商品运抵客户并验收（取得妥收/验收确认）"为标志；织布、服装、纺丝多为订单生产，质量/色样不符易致退货且再售困难。
- 标志性科目：原材料、生产成本/库存商品、固定资产及减值准备、应收账款/坏账准备、预收账款、应交税费（出口退税）。

## 二、关键业务流程
采购（向农户/供应商现金或信用采购原料，请购→订货→验收→入库→付款）→ 生产（多工序连续生产，材料/工薪/制造费用归集分配）→ 销售（接单/定价→发货→开票→收款，印染为来料加工）→ 出口（报关、收汇、出口退税）→ 回款（赊销形成应收，或门市/现金销售）。

## 三、主要审计风险领域

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入截止/提前确认 | 以发货而非验收确认；资产负债表日前后集中发货；退货风险未消除即确认收入 | 高 |
| 现金销售流失/虚计 | 印染、门市现销不开发票、账外循环；业务员操纵销售 | 高 |
| 成本核算不实 | 多工序多品种下在产品保留方法随意、单位成本波动、能耗率异常；成本跨期 | 高 |
| 存货跌价不足 | 棉丝麻等易霉变、织布类滞压品可变现净值低于成本未足额计提 | 中高 |
| 固定资产减值漏提 | 进口设备/闲置设备跌价幅度大，未提或低估减值 | 中高 |
| 出口收入/退税确认 | 出口凭证不全、贴息确认时点不当、毛利率异常 | 中 |
| 采购现金支付舞弊 | 原料向农户现金收购缺乏单据，虚构采购、资金占用 | 中 |
| 受托加工存货混淆 | 服装来料加工未区分自有/受托存货，所有权错报 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入分析程序 | 收入截止/异常 | 纵向与同业对比销售收入；按产品线/生产线做产能分析（机器+人工），销量>产能且无合理解释则扩大测试；监控现金折扣率、销售退回率、毛利率月度趋势 |
| 特殊询证函 | 现金销售流失 | 对印染/现销客户函证当期销售量、销售价、销售总额，评价内控、真实性及管理层诚信 |
| 收入与出库/货运核对 | 提前确认 | 以运单、出库单签收确认收入；核查寄存货（中介代管）所有权仍属企业而不确认收入 |
| 存货监盘（ABC法） | 存货跌价/存在 | 参与盘点计划；贵重/未盘存货亲盘；关注新旧残次编盘盈盘亏表；棉丝麻按体积推算并经验审计人员监盘 |
| 采购合同与应付账款函证 | 采购舞弊/完整性 | 对主要原料供应商详函期末余额+本期采购量/付款/折扣/退回；替代测试以验收单倒推基准日余额 |
| 成本分析程序 | 成本不实 | 收集在产品的保留方法、成品产出率、单位成本、单位能耗率，做年度间/同业对比；生产循环计价测试 |
| 固定资产减值测试 | 减值漏提 | 重点关注闲置/进口设备，结合市价与使用情况重新测算减值准备 |
| 出口销售核对 | 出口确认 | 核对报关单、提单、收汇水单；关注贴息时点与毛利率（出口毛利率通常低于内销但有例外） |

## 五、特殊会计事项
- 收入确认：一般以"运抵并验收妥收"为标志；订单生产（织布/服装）须明确无退货风险方可确认；印染来料加工按加工费确认、当期发生数视同当期成本。
- 成本核算：按工艺流程选择品种法/分步法等，多工序下在产品计价与完工分配是重点；印染加工（来料）工艺简单、周期短。
- 税务：出口退税（出口毛利率通常低于内销但有例外）；增值税、企业所得税适用制造业政策。
- 现金交易：印染、门市部现销比重大，内控评价与特殊函证是关键控制环节。

## 六、监管关注 / 与其他行业差异
- 证监会/注协处罚高发：收入提前确认、现金销售账外循环、成本不实、存货跌价准备不足。
- 与「服装制造业」（指南11）差异：本指南覆盖纺纱/织布/印染/纺机全链条，服装加工仅为其子类；品牌服装加盟连锁的收入确认（加盟费时点、提成核算）需单独关注。
- 与「机械制造」差异：纺机类按机械制造核算（定单生产、完工百分比）；其余纺织类为典型劳动密集生产/加工企业。
