# 出版发行业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——出版发行业（传媒出版业）》第五篇「重要的审计领域及审计程序」。出版发行企业审计三大核心：**委托代销收入确认、图书存货跌价、码洋/实洋差异**。

## 一、行业经营与核算特点
- 主营图书/期刊/音像制品的策划、出版、印刷、发行；盈利驱动为教材教辅（刚需）+一般图书（市场化），受出版行政许可、书号实名申领、选题备案强监管。
- 收入确认以**委托代销为主**：发出商品不确认收入，按代销清单（实洋）确认；自办发行按发货单+退货单确认发生。
- 标志性科目：库存商品（本社/发行科）、委托代销商品（实洋/销售折扣）、主营业务收入、应收账款、存货跌价准备。
- 码洋 vs 实洋：码洋=定价×数量，实洋=实际结算金额；销售折扣在两者间体现。税务上多数出版物享增值税先征后退。

## 二、关键业务流程
选题策划/获批书号 → 组稿编辑 → 印刷装订（委印，形成委托加工物资）→ 入库（库存商品-本社）→ 发运（委托代销出库/自办发行发货）→ 代销清单回收/退货 → 按代销清单确认收入 → 款项结算（折扣/退库冲减）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入虚增/提前确认（委托代销） | 未收到代销清单即确认收入；以发货单代替清单；期末虚构代销清单 | 高 |
| 收入完整性 | 退货/退库单未及时冲减，截留下期收入于本期 | 中高 |
| 图书存货跌价准备计提不足 | 长库龄滞销书不减值；未按分段比例计提（当年0/1年10%/2年20%/3年+30%） | 高 |
| 进销差价率异常波动 | 人为调节销售折扣/成本，操纵毛利率 | 中 |
| 存货收发截止错误 | 期末在途/发出商品未截止，账实不符 | 中 |
| 1年以上应收账款坏账不足 | 书店/经销商回款慢，欠款长期挂账未足额计提 | 中 |
| 委托印刷加工核算不实 | 委印数量/工费归集错误，印数虚报 | 中 |
| 总分社/发行科内部往来不实 | 内部往来未核对抵销，虚增资产或负债 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 代销清单/退库单检查 | 收入虚增/完整 | 索取期末前后代销清单，核对收发货与清单；未回清单不确认收入；截止测试（12.31 前后各 N 笔） |
| 委托代销出库单函证 | 发出商品/收入 | 对主要代销客户（书店/经销商）函证期末委托代销商品余额（实洋） |
| 收入截止测试 | 截止 | 发运单+代销清单双向核对，确认收入归属期间；完整性靠截止测试 |
| 存货计价+进销差价率测算 | 跌价/毛利波动 | 重算进销差价率与历史波动比对（异常追查）；书刊成本差异率测算（差异 1% 内可接受） |
| 存货监盘+账实核对 | 存货存在 | 抽盘仓库图书（按书号/批次），核对库存商品-本社/发行科明细 |
| 跌价准备重算 | 跌价不足 | 按库龄分段（当年0/1年10%/2年20%/3年+30%）重算，以年末库存码洋价为基数 |
| 应收账款坏账重算 | 坏账 | 1年以上账龄分析，重算坏账准备；函证主要客户 |
| 内部往来核对 | 往来不实 | 总分社/发行科内部往来逐笔核对抵销 |

## 五、特殊会计事项
- **委托代销收入**：以代销清单为确认时点，非发货；实务辅以发货单+退货单查发生，完整性靠截止测试。
- **存货跌价准备**：分段强制计提比例（当年不提/1年10%/2年20%/3年及以上30%）。
- **码洋与实洋**：收入按实洋，折扣在进销差价体现；书刊成本差异率控制（1%内可接受）。
- **版权核算**：自有版权 vs 外购版权（无形资产）区分；委托印刷形成委托加工物资。
- **税务**：增值税先征后退（多数出版物），需核对优惠批文。

## 六、监管关注 / 与其他行业差异
- 出版许可、书号实名申领、选题备案为强监管点；无资质或一号多用属违规。
- 与「一般商品流通业」差异：以委托代销为核心、存货跌价按库龄强制分段、码洋/实洋双口径。
