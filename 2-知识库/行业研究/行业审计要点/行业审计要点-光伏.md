# 光伏发电业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——光伏发电业》第五篇「重要的审计领域及审计程序」。光伏电站运营企业审计三大核心领域：**售电收入（含补贴）、在建工程（成本与转固）、固定资产（折旧与减值）**。

## 一、行业经营与核算特点
- 光伏电站投资、建设、运营；收入来自售电（标杆电价+补贴电价），成本以折旧为主（占主营成本 80%+）。
- 收入确认：电力输送至上网电量计量点（风险报酬转移）；按月抄表结算，抄表日与月末差异可暂估。
- 标志性科目：在建工程（电站建造成本）、固定资产（电站，折旧年限一般 20 年、残值 5%）、应收账款（应收补贴电价，回收周期长）、递延收益（政府补助）。

## 二、关键业务流程
立项（备案/投资预算）→ 融资（集团资金拆借/银行借款）→ 建设（组件/逆变器/土建，EPC 总包）→ 并网（逆变器带电→并网验收，转固）→ 运营发电（按月结算上网电量）→ 售电回款（标杆电价及时、补贴电价滞后）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入确认（电量/暂估） | 抄表日与月末发电量暂估方法不一贯；采用上网发电量而非结算发电量确认收入 | 中 |
| 补贴电价确认与收回 | 未进可再生能源补贴名录即确认补贴收入；补贴收回存在重大障碍仍确认 | 高 |
| 在建工程成本不实/少计 | 大额供应商款项未暂估，少计转固；红字应付账款未重分类 | 高 |
| 借款利息资本化不当 | 集团内部借款利率超银行同期贷款部分仍资本化（合并层应冲回）；非正常中断>3月仍资本化 | 高 |
| 在建工程转固时点操纵 | 为抢装补贴提前并网但项目未完工即转固；或延迟转固减折旧 | 高 |
| 固定资产减值（限电等） | 限电政策/组件积灰/电价下调导致减值迹象未计提 | 高 |
| 政府补助（递延收益） | 补助与资产/收益划分错误；未满足附条件确认 | 中 |
| 运维成本完整性 | 外包运维费未全额确认或完整性不足 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入确认+电量核对 | 收入/暂估 | 核实售电量取数来源（结算发电量）；关注抄表日与月末暂估一贯性 |
| 补贴电价核查 | 补贴确认 | 查上网电价批复、是否入可再生能源补贴名录；评估收回可能性 |
| 应付账款分析（红字/暂估） | 成本少计 | 大额红字重分类至在建工程或成本费用；暂估余额结合期后到票复核 |
| 供应商背景+函证 | 成本/关联 | 比对供应商注册地/经营范围与项目地合理性；关联方排查；大额供应商函证/走访 |
| 在建工程实地查看+访谈 | 转固/存在 | 新并网电站及时实地查装机容量/并网；访谈项目负责人 |
| 借款利息资本化重算 | 资本化 | 判断非正常中断>3月；内部借款利率公允性；单体 vs 合并层抵消超标准利息 |
| 转固金额完整性+时点 | 转固操纵 | 分供应商合同台账；未结算大额款合理暂估；以国家电网并网通知单为转固时点 |
| 固定资产监盘+折旧复核 | 减值/折旧 | 全盘/抽盘装机容量；查组件积灰/设备故障；折旧年限 20 年残值 5% 复核 |
| 固定资产减值判断 | 减值 | 结合限电政策/实地检查，预测未来现金流量现值测减值 |
| 政府补助审计 | 递延收益 | 查补助文件附条件；划分资产/收益相关；递延摊销复核 |

## 五、特殊会计事项
- 售电收入：标杆电价（按合同/脱硫燃煤标杆）无大疑；补贴电价需入名录方可确认，可再生能源电价附加补助资金由申报审核进入目录。
- 借款费用：集团内部借款利息，单体可资本化，合并层超过银行同期贷款利率部分须冲回。
- 场地租赁费/植被恢复/青苗补偿：金额重大可资本化（参考借款费用），否则长期待摊或费用。
- 政府补助：与资产相关的计入递延收益分期损益，与收益相关的直接损益；注意附条件（如装机规模/投资强度）。

## 六、监管关注 / 与其他行业差异
- 监管高发：补贴电价确认（是否入名录）、在建工程成本完整性、利息资本化、转固时点（抢装潮）、电站减值（限电）。
- 与"光伏制造（组件/硅片）"差异：电站运营业重资产（电站）与折旧、售电收入；制造业重存货与成本，二者审计重点截然不同。
