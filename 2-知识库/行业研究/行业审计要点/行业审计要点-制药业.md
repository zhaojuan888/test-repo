# 制药业（化学制药） 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——制药业（2025年修订）》第三篇「重要审计领域」。化学制药（原料药/制剂）受NMPA、GMP、集采与两票制强监管，六大核心风险领域：**收入确认、应收账款减值、在建工程转固及减值、存货减值、市场推广费、研发支出资本化**。

## 一、行业经营与核算特点
- 业务模式多元：自主研发生产、CDMO、授权引进、仿制药；产研销一体，研发周期长（10-15年）、投入高、成功率低。
- 收入确认采用控制权转移（签收/报关）时点；受"两票制"影响普遍开具红字发票；经销商常含退货权与价格保护条款。
- 标志性科目：营业收入/应收账款、存货（原料药/制剂，近效期管理）、固定资产/在建工程（GMP绑定）、开发支出/无形资产（研发资本化）、销售费用（市场推广费）。

## 二、关键业务流程
销售与收款（销售计划→信用管理→定价→订单→发货→开票→记账收款，退货/返利/红字发票）→ 采购与付款（存货、市场推广费、研发费用）→ 生产与仓储（GMP下生产、仓储与效期管理）→ 研发（研究阶段费用化、开发阶段符合条件资本化）。

## 三、主要审计风险领域（风险点）

| 风险领域 | 风险描述 | 常见舞弊/错报情形 |
|---|---|---|
| 收入确认（退货/可变对价/截止） | 期末过度发货、返利预估不足、提前/推迟确认 | 期末向经销商压货虚增收入；低估销售退回准备致毛利虚高 |
| 红字发票 | 两票制下红字冲销行业惯例 | 上年确认虚假收入，次年红字冲回并确认新虚假收入以缩短账龄、少提坏账 |
| 应收账款减值 | 集采压价+医院/经销商回款慢 | 长账龄坏账准备计提不足；渠道压货掩盖虚假交易 |
| 在建工程转固及减值 | 转固时点与GMP符合性检查绑定 | 提前/推迟转固操纵折旧与利润；集采/技术迭代致资产减值 |
| 存货减值 | 保管不善、集采降价、合格率/产能不足、产能过剩 | 近效期/过期存货未提足跌价；集采中标价低于可变现净值 |
| 市场推广费 | 占收入比高，与商业贿赂合规高度关联 | 名目复杂、隐性支出；推广服务商体外循环、关联交易未披露 |
| 研发支出资本化 | 研究/开发划分与资本化时点高度主观 | 模糊资本化时点、夸大技术可行性、乐观收益预测以操纵利润 |

## 四、关键审计程序

| 审计程序 | 目的 | 关键执行要点 |
|---|---|---|
| 收入截止与退货核查 | 验证收入真实完整 | 检查期前/后签收单、报关单、物流；分析退货率波动；观察退货隔离区；关注前十大客户11-12月及次年1月销售趋势 |
| 红字发票穿透 | 识别虚假销售与账龄操纵 | 追溯原始交易凭证；按客户归集红字冲回与新收入匹配；重算受影响的坏账准备 |
| 应收账款函证与账龄 | 验证可收回性 | 主要客户函证余额与销售额；独立重做账龄；分析经销商库存周转识别积压 |
| 在建工程转固测试 | 验证转固时点与金额 | 从GMP符合性检查通过日追查转固日；监盘生产线；核对竣工决算与暂估；重算利息资本化停止点 |
| 存货监盘与跌价测试 | 验证存货存在与计价 | 关注近效期/长库龄/残次冷背；液态/气态特殊计量、中药材贮存；成本与可变现净值比较；集采品销售费用率合理性 |
| 市场推广费核查 | 验证费用真实合规 | 分产品/地区占比分析；抽查会议/调研支持文件；查推广服务商工商、关联关系与关键人员流水；函证走访 |
| 研发资本化评估 | 验证资本化合理与减值 | 借助专家判断技术可行性；同行业对比资本化政策；检查批文（Ⅲ期临床/BE备案）；资本化率对比；开发支出减值迹象 |

## 五、特殊会计事项
- **研发支出**：研究阶段费用化，开发阶段须同时满足CAS 6条件方可资本化（创新药通常取得Ⅲ期临床批件至获注册批件为开发阶段；仿制药自BE备案至注册批件）。
- **收入（两票制/退货权）**：广泛退货权、价格保护使风险报酬可能未转移；红字发票冲销须追查原始交易。
- **集采联动**：中标降价同时压利润并引发存货/资产减值与渠道库存风险，须联动分析。

## 六、监管关注 / 与其他行业差异
- 监管与问询高发：收入真实性、市场推广费商业贿赂、研发资本化合理性、集采相关减值。
- 与制造业通用差异：研发资本化主观性极高、GMP绑定转固、近效期存货减值、两票制红字发票为行业特有。
