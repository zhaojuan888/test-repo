# 机械制造业 审计风险与关键程序

> 蒸馏自中注协《行业审计指南——机械制造业》第五篇「重要的审计领域及审计程序」。机械制造多走个性化/定制路线，以销定产、订单式生产；产品单件价值高、结构复杂、技术含量高、安装要求高，直销为主，信用销售模式多样。

## 一、行业经营与核算特点
- 以销定产、按订单定量生产，根据生产任务采购；产品单件价值高（机床、锅炉、机组动辄上千万），结构复杂、加工精度高、工艺复杂。
- 销售以直销为主，交货条件多样（工厂交货、最终用户工地交货，含安装、72小时试运行等），致收入确认时点复杂；信用销售含银行按揭、融资租赁、分期付款、以租代售。
- 存货数量多、工序多，原材料/生产成本/制造费用在品种间及完工与在产品间归集分配复杂；固定资产投入大、种类多，部分专用设备易闲置减值。
- 标志性科目：原材料（钢材/铝/铜）、生产成本、库存商品、应收账款（规模大、回收期长）、固定资产/在建工程/融资租赁资产、存货跌价准备。

## 二、关键业务流程
采购（按订单采购，请购→订货→验收→入库→暂估/付款）→ 生产（按生产指令领料，多工序加工，工薪/制造费用归集分配，在产品状态各异）→ 销售（接单/授信/定价→发货或安装→验收/试运行→开票收款）→ 特殊销售（委托代销、分期收款、带安装检验）→ 回款（应收、票据、融资租赁）。

## 三、主要审计风险领域

| 风险领域 | 典型错报/舞弊表现 | 风险等级 |
|---|---|---|
| 收入确认时点错 | 工厂交货/工地交货/安装+72h试运行条件混淆；未满足即确认；年末集中发货 | 高 |
| 特殊销售确认不当 | 分期收款未按现值确认（融资性质）、委托代销提前确认、安装未完成即确认 | 高 |
| 应收账款/坏账 | 规模大、回收期长、宏观低迷回款风险增；坏账估计不足 | 高 |
| 存货成本分配不实 | 多品种/多工序下费用归集分配随意；单位成本异常波动调节利润 | 高 |
| 存货跌价不足 | 某型号滞销连累专用材料/模具减值；残次冷背未提足 | 中高 |
| 存货监盘难度高 | 品种多、环节多、形态异，存在未纳入盘点范围或已售未发疑点 | 中高 |
| 固定资产核算/减值 | 入账成本/折旧方法/年限影响大；融资租赁处理复杂；闲置专用设备减值 | 中高 |
| 关联方交易 | 无商业理由交易做大销售额；关联方非关联化 | 中 |

## 四、关键审计程序

| 程序 | 对应风险 | 执行要点 |
|---|---|---|
| 收入分析程序 | 收入异常 | 本期与上期收入、毛利率、各月波动对比；与同业毛利率对比；前五名客户占比；产能/水电能耗/劳动生产率印证；收入与现金流匹配 |
| 收入确认核查 | 时点错 | 检查确认条件方法是否合规、前后一致；抽取发票/发货单/凭证核对开票记账发货日期；出口查报关单、提单，必要时向海关函证 |
| 截止测试 | 提前确认 | 测试资产负债表日前后大额发货单据与收入/应收明细账双向核对；复核期后销售退回记录；结合应收函证查未取得认可的大额销售 |
| 特殊销售审计 | 确认不当 | 委托代销收到代销清单确认、可向受托方函证/监盘；分期收款按应收合同价款公允价值确认，复核现值/折现率/未实现融资收益；安装检验销售取双方（及监理）安装/72h试运行验收文件 |
| 应收账款函证 | 虚增/坏账 | 对大额、长账龄、异常、关联方函证余额及发生额；保持发函控制；回函不符查差异，未回函替代/期后收款测试；核查客户工商资料排查关联 |
| 存货实质性分析 | 成本不实 | 原材料比价（行业数据库）、用量与预算/标准单耗对比；库存商品单位成本/毛利率/周转率/账龄分析；生产成本各月单位成本、料工费占比对比；水电费按实际消耗量（非金额）配比 |
| 计价测试 | 成本不实 | 原材料/库存商品检查计价方法前后一致、进口材料折算与税费；生产成本抽查成本计算单，核对领料/工时/费用分配表；完工与在产品分配标准合理性 |
| 存货监盘 | 存在/完整 | 尽量盘点日=报表日；未纳入盘点范围存货（已验收未入库、受托代管、已售未发）分别处理；钢板/钢管测量、储罐液体按密度折算、废料称重；抽盘双向（记录→实物、实物→记录）；盘点表即时签字收回 |
| 存货跌价测试 | 减值不足 | 存货与订单/期后销售/下年预测比对；按持有目的确定可变现净值；结合监盘查残次冷背；关注专用材料/模具随型号滞销减值 |
| 固定资产/融资租赁 | 核算/减值 | 检查入账成本、折旧方法与年限；融资租赁按准则处理；闲置设备实地察看并复核减值；与在建工程结转勾稽 |

## 五、特殊会计事项
- 分期收款销售：具有融资性质的，按应收合同价款的公允价值确认收入，差额作为未实现融资收益分期摊销；不能按约定价款确认。
- 委托代销：交付受托方不确认收入，收到代销清单按协议价确认；需核实代销数量真实性（函证/监盘）。
- 需安装和检验的销售：以安装完成、72小时试运行正常等为确认条件，审计取双方/第三方监理验收文件，并关注安装成本是否已计入销售成本。
- 存货计价：不能替代使用的原材料/为特定项目专门采购的零部件通常采用个别计价法。
- 税务：增值税（含出口退税）、企业所得税适用制造业；研发费用资本化/费用化划分。

## 六、监管关注 / 与其他行业差异
- 证监会/注协处罚高发：收入确认时点错（尤其带安装/试运行）、特殊销售不当确认、应收账款及坏账、存货跌价不足、关联方交易。
- 与「金属加工」差异：机械制造单件价值更高、以销定产、确认时点更多样（含安装/72h试运行、融资租赁），无金属市价主导的"加工费"定价与套期保值业务。
- 与「汽车零部件」差异：二者均订单式生产，但汽车零部件配套整车厂、按结算单时点确认且有模具/三包等特有核算；机械制造更偏向整机直销与复杂交货条款。
