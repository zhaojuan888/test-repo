# 2026-立信中联-宁波工投-同一客户两套账-停业半年

> 财政部 8/14 官网公布《财政部行政处罚决定书（财监法〔2026〕193号）》（7/31 出具）：立信中联所因三个审计项目系统性执业缺陷被**警告+暂停经营业务 6 个月+罚没 435.8 万**（没收违法所得 65.3 万+罚款 326.5 万，罚款达 5 倍顶格）。修订后《注册会计师法》2027-01-01 施行、首次将"职业怀疑"写入法律——此案是旧法下最后一批重罚，新法下同样失守代价翻倍。

## 基本案情

| 项目 | 内容 |
|------|------|
| 被处罚对象 | 立信中联会计师事务所（特殊普通合伙） |
| 审计客户 | ①宁波工业投资集团有限公司 ②杭州康韵生物科技股份有限公司 ③莆田农村商业银行股份有限公司 |
| 监管机构 | 财政部（2025 年度执业质量专项检查） |
| 决定书 | 财监法〔2026〕193号 |
| 出具日期 | 2026-07-31（8/14 官网公布） |
| 处罚类型 | 警告 + 暂停经营业务 6 个月 + 没收违法所得 65.3 万 + 罚款 326.5 万（5 倍顶格） |
| 背景 | 不到一个月前大连证监局刚因智云股份案罚立信中联 440 万——监管链条正伸向所内质控环节 |

## 违规事实（三项目）

### 项目一：宁波工投集团 2022-2024 年度审计（最严重）

1. **连续两年出具"同一客户两套账"**：2022、2023 年度每年对同一财务报表出具两份**合并范围不一致、意见类型冲突**的审计报告，所附报表在货币资金、交易性金融资产、其他流动资产、递延所得税资产、其他应付款、资本公积、盈余公积、未分配利润等多项科目数据显著差异，且未指出报表存在重大不实。
2. **未按母公司会计政策调整子公司**：2024 年宁波工投编制合并报表时未按母公司政策调整子公司报表，导致累计**多计投资性房地产 9.40 亿、少计累计折旧 8.10 亿、多计公允价值变动损益 1.34 亿**（其中 2024 年少计折旧 6656.63 万、多计公允变动 108.86 万）——立信中联未充分关注、认可了企业处理。
3. **代销按总额法确认收入**：子公司宁波市石化进出口有限公司在不承担货权转移风险的前提下，货物由上游直接转移给下游客户，未按代销实质确认收入，**2024 年多计收入 1.795 亿**——立信中联未充分关注、认可了企业处理。

### 项目二：康韵生物 2024 年度审计

康韵生物通过"在建工程"科目核算拱墅区矩阵国际中心 7 处房产装修支出 415.23 万，同时通过"投资性房地产"科目核算上述房产增值 429.98 万——**多计在建工程、多计利润 415.23 万**。立信中联未保持职业怀疑、未获取充分适当审计证据、未发现重大错报。

### 项目三：莆田农商行 2024 年度审计

对贷款及信用卡资产五级分类审计程序执行不到位，仅对少量借款人的工商登记信息进行核查，未对信贷资产分类的真实性、准确性获取充分适当审计证据。

## 审计/税务启示

| 教训 | 应对措施 |
|------|---------|
| **同一客户、同一年度、两套账 = 底线问题** | 合并范围一致性逐户勾稽（纳入/剔除要有依据），报告出具前合并范围变更复核留痕 |
| 母子公司**会计政策不统一**必须调整（CAS 33/合并报表） | 开底稿先做"母公司 vs 子公司会计政策核对表"（折旧年限/公允价值模式/收入确认方法） |
| **代销/贸易业务总额法误判**（CAS 14） | 不承担货权转移主要风险 → 净额法；逐笔看物流、风险、定价权（详见 [[CAS-14-总额法vs净额法]]） |
| 装修支出/增值挂错科目 → 利润虚增（CAS 3） | 装修是费用不是资产；投资性房地产增值走公允模式才有，且需评估支持（详见 [[CAS-3-投资性房地产]]） |
| 金融资产**五级分类**程序走过场 | 抽样要有方法记录、核查贷款风险分类依据（不是只查工商信息） |
| 停业半年=事务所层面最重罚，质控失守连锁反应 | 承接新业务/续任前做"近两年处罚回顾"，质控复核人对项目质量负连带责任 |
