# 2025-中审众环-庚星股份-穿行测试形式化

## 基本案情

| 项目 | 内容 |
|------|------|
| 被处罚对象 | 中审众环会计师事务所 |
| 审计客户 | 庚星股份 |
| 监管机构 | 福建证监局 |
| 处罚日期 | 2026 年初 |
| 罚没金额 | 没收 33 万 + 罚款 66 万 = 共约 99 万 |
| 签字 CPA | 林东、江旺生 |

## 违规事实

### 核心问题：穿行测试形式化

**采购付款循环**：庚星股份在燃料油采购中未指定专人验收、未编写验收报告。但中审众环在**未取得验收资料的情况下**，即在审计底稿中认定"相关内部控制已得到执行"。

**销售收款循环**：庚星股份燃料油销售中不存在仓储部门的货物出库单及仓储保管账。中审众环在**未取得出库单和保管账**的情况下，认定内控有效。

### 新增业务风险评估错误

庚星股份 2018 年新增燃料油业务。中审众环认定"经营模式与经营煤炭相似，新增部分不会明显增加经营风险"。但实际上燃料油业务的经营模式、对财务指标的影响与煤炭**并不相似**。

## 审计/税务启示

| 教训 | 应对措施 |
|------|---------|
| **穿行测试不可形式化**——无证据=未执行 | 每个控制环节必须取得实际运行证据 |
| 新增业务必须独立评估风险 | 不可类比旧业务，必须逐项分析 |
| 验收报告缺失是重要的内控缺陷 | 穿透至业务流程底层证据 |
