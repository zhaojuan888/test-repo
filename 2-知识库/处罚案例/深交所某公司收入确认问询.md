# 深交所某软件公司 IPO 首轮问询 — 收入确认

## 案例背景

| 项目 | 内容 |
|------|------|
| 板块 | 深交所创业板 |
| 行业 | 企业级 SaaS 软件 |
| 收入模式 | 订阅制（1-3 年）+ 实施服务 + 定制开发 |
| 报告期 | 2023-2025 |
| 收入规模 | 2025 年 4.2 亿元，复合增长率 58% |
| 问询轮次 | 首轮问询 + 二轮追问 |
| 关键争议 | 多年期合同签约时一次性确认全部收入 |

## 问询要点

### 问题一：收入确认政策的合理性

**交易所问询原文大意**：

> 发行人将多年期 SaaS 订阅合同的全部合同金额在签约时一次性确认收入，请说明是否符合 CAS 14 的规定。请保荐机构和申报会计师核查并发表明确意见。

**被问询方回复的核心说辞**：

1. SaaS 平台已部署完毕，客户签约即获得访问权限 → 履约义务已完成
2. 历史数据显示退订率低于 2% → 可变对价估计可靠
3. 可比公司 X、Y 也采用类似方法

**监管追问（第二轮）**：

> 发行人 SaaS 服务为持续交付的在线服务，客户在企业履约的同时取得并消耗经济利益，符合 CAS 14 第 11 条第（一）款"某一时段"的条件。签约时一次性确认收入与准则要求不符。请重新回答，并补充：
> 1. 按某一时段法确认收入对报告期内收入、净利润、毛利率的影响
> 2. 发行人与可比公司 X、Y 的收入确认政策具体条款逐项对比

## 准则分析

### 为什么签约时不能一次性确认

| 准则条款 | 分析 |
|---------|------|
| CAS 14 第 4 条（合同） | 合同存在 ✓ |
| CAS 14 第 11 条第（一）款 | "客户在企业履约的同时取得并消耗企业履约所提供的利益"——SaaS 是持续服务，客户按月消耗，**属于时段义务** |
| CAS 14 第 12 条 | 对于某一时段履行的履约义务，**应按履约进度确认收入**，不得在某一时点一次性确认 |
| CAS 14 第 13 条 | 履约进度 = 时间比例法——按月均匀分期确认 |

**结论**：发行人签约时一次性确认的做法违反第 11-13 条。

### 正确的会计处理

```
合同：3 年期 SaaS 订阅，合同金额 36 万元

错误做法（发行人）：
  签约时 → 借：应收账款 36 万  贷：营业收入 36 万

正确做法（时段法，时间比例）：
  第 1 年 → 确认收入 12 万元
  第 2 年 → 确认收入 12 万元
  第 3 年 → 确认收入 12 万元
```

### 对财务报表的影响（假设发行人 2025 年新增合同 2.8 亿元）

| 项目 | 发行人申报数 | 时段法调整后 | 影响 |
|------|:------:|:------:|:------:|
| 营业收入 | 4.20 亿 | 2.45 亿 | **-1.75 亿（-42%）** |
| 净利润 | 0.85 亿 | 0.32 亿 | -0.53 亿 |
| 毛利率 | 68% | 52% | -16pp（实施/开发成本前置） |
| 合同负债 | 0.3 亿 | 2.05 亿 | +1.75 亿 |

> ⚠️ 调整后净利润降幅超 60%，可能触发上市条件变化。

## 可比公司对比

| 公司 | SaaS 收入确认政策 | 与发行人是否可比 |
|------|---------|:---:|
| 用友网络 | 服务期内按时间比例直线确认 | ✓ |
| 金蝶国际 | 订阅期内按月分期确认 | ✓ |
| 广联达 | 云服务按期分摊，实施费按完工进度 | ✓ |
| 明源云 | 订阅期内按时间比例分摊 | ✓ |
| 可比公司 X（发行人引用） | 永久许可一次性确认 + SaaS 按期分摊 | **不可比**（X 主要收入为许可，非 SaaS） |
| 可比公司 Y（发行人引用） | 签约确认，理由为"历史退订率低" | **不可比**（Y 曾因此收到交易所监管函） |

**结论**：发行人引用的"可比公司"不具备可比性，A 股主要 SaaS 同行均采用时段法按期确认。

## 交易所最终意见

1. **要求更正**：按某一时段法重新确认收入，追溯调整报告期
2. **披露影响**：补充披露收入确认政策变更对各期财务数据的影响
3. **风险提示**：在招股说明书重大事项提示中补充"收入确认政策调整导致业绩大幅下降的风险"

## 审计启示

| 要点 | 说明 |
|------|------|
| **履约义务是时点还是时段** | SaaS/云服务几乎都是时段义务——客户持续消耗，不可签约即确认 |
| **可变对价不是借口** | "退订率低"不代表履约义务已完成，履约义务的类型判断在前 |
| **可比公司要真可比** | 收入结构相似、商业模式相同才算可比，不能选对自己有利的个例 |
| **时段法下的履约进度** | SaaS 通常按时间比例（投入法），工程施工需复核监理报告（产出法） |
