# 2025-利安达-江平生物-存货审计失败

## 基本案情

| 项目 | 内容 |
|------|------|
| 被处罚对象 | 利安达会计师事务所（特殊普通合伙） |
| 监管机构 | 厦门证监局 |
| 处罚日期 | 2025-12-30 |
| 罚没金额 | 没收 32.5 万 + 罚款 60 万 = 共约 91 万 |
| 涉及准则 | [[CAS-1311-存货审计]] |

## 违规事实

### 违规点 1：未核查盘点日至资产负债表日存货变动

江平生物子公司西藏江雅账面存货较上期增长 **246%**，收入仅增长 9.26%。

利安达未对资产负债表日至盘点日之间的大额存货变动获取充分审计证据——仅抽取少量销售合同，未检查期间出入库单或物流运输单据。

### 违规点 2：未关注内控异常

部分存货出入库单的**制单人和复核人为同一人**，利安达未关注此异常。

## 审计/税务启示

| 教训 | 应对措施 |
|------|---------|
| 存货增长率远超收入增长率是重大异常信号 | 将存货增长率与收入增长率进行比率分析 |
| 盘点日 ≠ 资产负债表日时必须核查期间变动 | 双向测试：获取期间所有出入库单+物流单据 |
| 制单人=复核人提示内控缺陷 | 穿行测试必须检查职责分离的实质执行 |
