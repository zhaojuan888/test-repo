# 2026-铟靶新材(京蓝科技)-重大诉讼公告金额单位万倍笔误

> 铟靶新材（哈尔滨）股份有限公司（证券简称：京蓝科技，000711，2026 年更名）9/1 披露《重大诉讼公告》将涉案金额 **85,893,796.80 元**误写为 **85,893,796.80 万元**（≈8,589 亿元，放大 1 万倍），9/2 披露更正公告并收到深交所公司部监管函〔2026〕第116号，认定违反《股票上市规则(2026年修订)》第 1.4 条、第 2.1.1 条第一款。

## 一、事件经过

| 时间 | 事件 |
|------|------|
| 2026-08-31 | 撤销其他风险警示（摘帽）；同日披露重大诉讼公告（编号 2026-081）：就中科鼎实业绩补偿款纠纷向西城区法院起诉殷晓东等 37 名业绩补偿义务人，涉案金额 85,893,796.80 元（特别提示 3 **误写为"万元"**） |
| 2026-09-01 | 公告见报当日股价"10cm"涨停报 6.48 元/股（年内累计涨幅近 279%） |
| 2026-09-02 | 披露更正公告（2026-083，金额改为"元"）；深交所下发公司部监管函〔2026〕第116号 |

- 错误性质："元"被加"万元"尾缀 → 金额放大 **10,000 倍**（8,589.38 万元 → 约 8,589 亿元，"万亿级笔误"）。

## 二、案件背后的审计业务链（业绩补偿专项审核）

本案是"**财务造假处罚 → 追溯调整 → 业绩承诺未达标 → 专项审核 → 诉讼追偿**"完整链条的样板：

1. **2018 年**：京蓝科技收购中科鼎实，业绩承诺 2018-2020 三年扣非净利累计≥4 亿（各年≥9000 万）+经营现金流累计≥1.5 亿。
2. **2025-08-15**：黑龙江证监局《行政处罚决定书》确认**中科鼎实 2020 年度虚增营业收入 1.63 亿、虚增利润总额 6636.37 万**。
3. 公司追溯调整后，中科鼎实 2020 年净利实为 1.17 亿，三年累计 3.71 亿，**未达业绩承诺**。
4. **2025-09-26**：中兴财光华会计师事务所出具《专项审核报告》，确认应履行业绩补偿合计 **8,589.38 万元**（现金补偿 1649.35 万+应补偿股份 1164.43 万股）。
5. 2025-11 催告未果 → 2026-03 立案诉讼 → 2026-09 公告起诉（金额单位出错）。

## 三、对审计/复核工作的落地启示 ⭐

1. **金额单位+数字位数 = 公告与报告复核第一道闸**：本类"元/万元/亿元"与数字位数错误会直接诱发股价异动并触发监管函；复核 SOP 首条应为"金额单位与位数一致性检查"（可联动本机 audit-report-checker 技能做演练）。
2. **披露低级错误案例组**：与 [[2026-福星股份-年报数据错误-通报批评]]（年报 36 处错误被通报批评）并读——"错误本身即可触发处分"，上市公司客户披露预检是可选增值服务（参照变现点子 #51）。
3. **业绩承诺实现情况专项审核是常见衍生业务**：IPO/并购中"业绩承诺期届满核查+补偿测算专项审核"需求常态化，可沉淀承接模板（程序：承诺口径核对→经审计实际数→补偿公式复算→专项报告）。
