# 某客户 — 收入跨期

## 背景

| 项目 | 内容 |
|------|------|
| 客户 | 某客户（匿名化处理） |
| 行业 | 制造业 |
| 报告期 | 2025 年度 |
| 发现日期 | 2025-12 年末审计 |

## 发现过程

截止测试（资产负债表日前后各 10 天双向测试）：

**账簿 → 凭证（发生认定）**：
- 2025-12-28，记账凭证 JZ-1523，确认收入 580 万元
- 对应销售合同编号 S-2025-0891

**凭证 → 账簿（完整性认定）**：
- 发货单日期 2026-01-03，客户签收日期 2026-01-05
- 物流记录显示 2025-12-31 货物仍在运输途中

## 问题定性

| 要素 | 内容 |
|------|------|
| 问题类型 | 提前确认收入（截止性错误） |
| 准则依据 | [[CAS-14]] 第 11 条——控制权转移时点判断 |
| 风险等级 | **高**（影响发生认定） |
| 金额 | 580 万元 |
| 对净利润影响 | 约 493 万元（按 15% 所得税率） |

## 根因分析

合同条款约定 FOB 发货地交货（风险报酬在装运时转移），但实际执行的交易模式为客户验收后才确认收货。

**矛盾点**：
- 合同写 FOB → 发货即转移控制权 → 应 2025-12-28 确认
- 实际执行 → 客户 2026-01-05 才签收 → 控制权 2026-01-05 才转移
- 需要判断以合同条款还是实际交易模式为准

## 调整分录

```
借：营业收入          580 万
    贷：应收账款        580 万
（冲回 2025 年跨期收入）

借：应收账款          580 万
    贷：营业收入        580 万
（记录至 2026 年）
```

## 对报表的影响

| 报表项目      |   调整前   |   调整后   |  影响  |
| --------- | :-----: | :-----: | :--: |
| 2025 年收入  | X + 580 |    X    | -580 |
| 2025 年净利润 |    —    |    —    | -493 |
| 2026 年收入  |    Y    | Y + 580 | +580 |

## 审计应对

1. 扩大截止测试范围至全部年末最后一周交易
2. 逐笔核对发货单日期、签收单日期、物流记录
3. 检查是否有类似"合同条款与实际执行不一致"的情况
4. 了解管理层收入确认政策是否已更新
