# 2026-大信所-同辉信息-审计失败

> 北京证监局 9/8 披露行政处罚决定书：大信所为同辉佳视（北京）信息技术股份有限公司（同辉信息）**2018-2021 年度财务报表审计及发行股票相关财务信息鉴证服务**未勤勉尽责，出具文件存在虚假记载，且**未完整留存相关审计证据**。大信所被**罚没合计 981.13 万元**（没收 245.28 万 + 罚款 735.85 万），李华、刘明、朱劲松、刘忠霞 4 名签字注会合计被罚 **170 万元**。

## 一、案件结构

| 事项 | 内容 |
|------|------|
| 被审计方 | 同辉佳视（北京）信息技术股份有限公司（同辉信息）——2018-2021 年报审计 + **向不特定合格投资者公开发行股票（精选层/北交所链）**相关财务信息鉴证 |
| 被审计方违规（另案查明） | 2018-2021 年通过**虚构业务合同、提前或延后确认收入**等方式虚增收入、利润 → 2018/2019/2020/2021 年报及引用 2018-2020 年报数据的《向不特定合格投资者公开发行股票说明书》存在虚假记载 |
| 大信所行为 | 对 2018-2021 年报均出具**标准无保留意见**审计报告（存在虚假记载）；发行股票鉴证出具《会计师事务所声明》确认无异议 |
| 签字注会 | 2018 年报：朱劲松、刘明；2019-2020 年报：李华、刘明；2021 年报：李华、刘忠霞 |
| 程序缺陷 | **未保持职业怀疑、对异常情况未执行进一步审计程序**；**未完整留存相关审计证据**（独立认定的责任点） |

## 二、处罚结果

- **大信所**：责令改正，没收审计业务收入 245.28 万元 + 罚款 735.85 万元（合计罚没 981.13 万元）。
- **签字注会**：李华警告+罚 60 万（2019-2021 连签三年）；刘明警告+罚 55 万（2018-2020 连签三年，申辩部分采纳）；朱劲松警告+罚 35 万（2018 签）；刘忠霞警告+罚 20 万（2021 签）。

## 四、对审计/尽调工作的落地启示 ⭐

1. **"未完整留存审计证据"独立成责**：处罚不止列"未勤勉尽责"，单列证据留存缺陷——与 [[2026-大华所-东方集团-农产品融资性贸易审计失败]]"调整底稿未归档"同主线：**底稿归档=程序闭环的证据链**，调整、沟通、异常跟进必须有痕。
2. **虚构合同 + 提前/延后确认收入跨 4 年未被识破**：收入截止性测试（出库/验收/开票/回款四节点）、大客户合同与工商/物流交叉、期后大额退回抽查不可省；异常毛利率、偶发大额合同是红旗。
3. **北交所/精选层 IPO 财务信息鉴证=责任扩大面**：年报+《公开发行股票说明书》引用数据+《会计师事务所声明》三处担责（呼应朗泰通"撤回不免责"，此处是"已申报仍追责"），对照 [[2026-容诚所-路桥信息-审计失败-北交所通报批评]]。
4. **同一所连环被罚的承接含义**：一次处罚后监管对其余项目回溯概率上升；承接其存量客户/接任项目时把"更换审计机构原因+前任底稿沟通函+风险提示"做成标准动作。
