# 2026-天津富通信息-无商业实质贸易-资金占用-行政处罚

## 一、案件概要

- **处罚对象**：天津富通信息科技股份有限公司（下称富通信息，退市公司）+ 间接控股股东富通集团有限公司 + 8 名责任人（肖玮/周胜炎/吕军/徐东/徐煜波/华文等）
- **文号/日期**：天津证监局决定书，2026-08-21 发布（退市公司公告编号 2026-026，全国股转系统网站转载）
- **合计处罚**：公司罚 750 万、富通集团罚 750 万；总经理肖玮罚 700 万+**终身市场禁入**、富通集团副总裁周胜炎罚 450 万、财务总监吕军罚 350 万+**十年市场禁入**、董事长徐东罚 300 万、监事徐煜波/董事华文各罚 150 万

## 二、违规事实

### 1. 未披露关联方非经营性资金占用（2021-2023）

- 富通集团协调 5 家供应商与富通信息及子公司签署**无商业实质的贸易合同**，供应商收到预付款后未供货，款项提供给富通集团及其子公司使用
- 占用发生额：9806.76 万 / 47,679.94 万 / 22,622.80 万（占当期净资产 **7.13% / 35.53% / 20.56%**）
- 年末余额：2556.76 万 / 33,343.28 万 / 52,606.07 万（占净资产 **1.86% / 24.85% / 47.81%**）

### 2. 定期报告虚假记载（2021 年报、2022 年报、2023 半年报）

- 富通集团协调 7 家客户与富通信息签署无商业实质贸易合同
- 虚增营业收入：30,410.78 万 / 35,388.35 万 / 23,749.40 万（占披露营收 **21.27% / 26.60% / 49.24%**）
- 虚增利润：10,977.72 万 / 5,981.15 万 / 5,097.31 万（占当期利润总额绝对值 **652.17% / 277.98% / 177.87%**）

## 三、审计启示（关键价值）

1. **"无商业实质贸易合同"是资金占用+收入造假的复合工具**：同一套合同模板两种用途——供应商端"收款不供货"=资金流出形成占用；客户端"签合同不收货"=收入利润虚增。核查必须**供应商端+客户端双向穿透**
2. **资金占用是证监会处罚最高频事项之一**，识别要点：
   - 预付账款长期挂账不结转、供应商收款后短期内资金回流关联方
   - 贸易业务量大但无实际物流/验收单据、毛利率异常、合同金额与业务规模不匹配
   - 关联方识别要穿透到"间接控股股东协调"层面（本案由集团层面统一组织签约）
3. 虚增利润占利润总额绝对值 652%/278%/178%——**连续多年大幅虚增、占比持续 >100%** 是"持续造假维持业绩"的最强信号，与 ST南新（157%）同型
4. 实务落点：
   - 用 [[贸易真实性与融资性贸易/贸易真实性与供应链税务-交叉核查]] 的"四流合一"核查法，先穿透合同实质（货物流向/风险承担/定价机制），再做 CAS 14 总额法/净额法判断
   - 做"资金占用穿透核查清单"（预付账款挂账+供应商资金流向+客户签合同不收货+回函不符），写进货币资金/预付/贸易类底稿模板
   - 与长兴新农都粮食/肉类/蛋类贸易合同核查同源：先问"交易是否真实发生"，再谈方法选择
