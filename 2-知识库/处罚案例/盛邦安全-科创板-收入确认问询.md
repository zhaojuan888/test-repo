# 盛邦安全 — 科创板 IPO 上市委意见落实函（2023）

## 背景

| 项目 | 内容 |
|------|------|
| 公司 | 远江盛邦(北京)网络安全科技股份有限公司 |
| 板块 | 科创板 |
| 保荐机构 | 国泰君安 |
| 问询日期 | 2022.12.27 上市委会议意见落实函 |
| 核心争议 | 网络安全产品的收入确认时点——硬件交付 vs 客户验收 |

## 问询要点

上市委在审议后提出，要求进一步说明：

1. 硬件类产品收入确认的具体时点——是发货签收还是客户验收通过？
2. 软件开发及技术服务收入能否采用时段法确认？
3. 是否存在通过控制验收时间来调节收入确认的情况？

## 公司回复要点

### 硬件产品
- 标准硬件产品（如防火墙、入侵检测设备）：以客户签收作为收入确认时点
- 定制化系统集成项目：以客户验收通过作为收入确认时点
- 说明标准产品的签收即代表控制权转移，后续安装调试不影响核心功能

### 软件及服务
- 标准化软件许可：交付 License Key 时一次性确认
- 年度安全运维服务：服务期内按时间比例直线确认（时段法）
- 定制开发：投入法确认履约进度（需客户阶段性确认）

## 审计核查程序

保荐机构及会计师的核查重点：

1. 逐笔核查报告期内前二十大客户合同，核对收入确认时点与合同条款的一致性
2. 对签收单进行走访核实（抽查比例不低于 60%）
3. 检查资产负债表日前后各 15 天的收入确认情况，执行截止测试
4. 获取售后维护记录，验证签收后是否存在重大未完成义务
5. 对比同行业收入确认政策（奇安信、深信服、启明星辰）

## 启示

| 要点 | 说明 |
|------|------|
| 硬件 vs 软件区分 | 不同产品线的收入确认政策必须分别披露，不能混为一谈 |
| 签收 vs 验收 | 标准产品签收即可，定制化必须验收——关键是合同条款 |
| 截止测试 | 科创板审核对期末突击确认极为敏感 |
| 可比公司对比 | 必须选同类型产品线的公司，不能跨行业 |
