# 2026-中审华-广道数字-六年连续虚增收入

## 基本案情

| 项目 | 内容 |
|------|------|
| 被处罚对象 | 中审华会计师事务所 |
| 审计客户 | 广道数字（上市公司） |
| 监管机构 | 深圳证监局 |
| 处罚日期 | 2026-05-28 |
| 罚没金额 | 没收 217 万 + 罚款 1085 万 = 共约 1302 万 |
| 特别处罚 | **暂停从事证券服务业务 6 个月** + 两名 CPA 市场禁入 |

## 违规事实

广道数字通过制作**虚假购销合同、发票、银行回单、发货通知单及入库单**等方式虚构销售和采购业务，**2018-2023 连续六年**虚增营业收入：

| 年份 | 虚增收入（亿元） | 占披露收入比例 |
|------|---------------|-------------|
| 2018 | 1.43 | 87.34% |
| 2019 | 1.92 | 95.39% |
| 2020 | 2.23 | 98.96% |
| 2021 | 2.49 | 85.87% |
| 2022 | 3.04 | 99.39% |
| 2023 | 2.83 | 98.14% |

中审华**连续六年出具标准无保留意见**，未发现这些虚构交易。

## 审计/税务启示

| 教训 | 应对措施 |
|------|---------|
| 收入占比 87-99% 是虚构的——极端异常但未被发现 | 收入与行业均值、历史趋势严重偏离时必须深度核查 |
| 六年间无人质疑——独立性和职业怀疑的系统性缺失 | 定期轮换审计团队、强化项目质量复核 |
| 全链条伪造（合同+发票+回单+出入库单） | 函证必须全程控制、物流单据必须与第三方验证 |
