# 税务审计四专题交叉核查

> 把「研发费用加计扣除 / 特别纳税调整 / 供应链税务传导 / 贸易真实性与供应链税务」四个税务专题，按审计程序交叉串联，形成统一核查矩阵。避免单点核查遗漏跨专题勾稽。

## 一、统一核查矩阵

| 专题 | 核心税务风险 | 最易交叉的专题 | 交叉点的审计程序 |
|---|---|---|---|
| 研发费用加计扣除 | 加计基数不实、委外 / 共用工时错 | 特别纳税调整 | 委托 / 合作研发付关联方：既按 80% 归集加计，又属转让定价审查 → 同期资料与辅助账双向核对 |
| 研发费用加计扣除 | 研发耗材进项异常 | 供应链税务传导 | 研发领用材料对应采购发票若被认定异常凭证 → 进项转出，反噬研发加计基数 → 供应商准入 + 发票链核验 |
| 特别纳税调整 | 关联交易定价偏离 | 供应链税务传导 / 贸易真实性 | 关联方购销定价须独立交易原则；同一交易同时验证"四流一致"与"利润归属合理" |
| 供应链税务传导 | 上游虚开牵连下游补税 | 贸易真实性 | 四流不一致既是税务异常凭证诱因，也是虚假贸易信号 → 同源核查 |
| 贸易真实性与供应链税务 | 无货开票 / 空转走单 | 收入确认(总额净额) / 特别纳税 | 代理按总额法 = 财务造假且涉虚开；关联方空转 = 转让定价 + 虚开双线 |

## 二、跨专题"红旗"清单（任一出现即升级核查）

- 委托研发同时是关联方大额支付，但无同期资料 / 定价无可比分析。
- 研发耗材供应商为新增、低信用、短期内集中开票。
- 关联交易"高买低卖 / 零毛利"，利润与功能风险不匹配（疑似利润转移 + 空转）。
- 四流任一缺失或仅"自制单据"无第三方外部凭证。
- 进项品名与销项不匹配、进销项背离（金税四期直接预警）。

## 三、取数路径（从账面到税务）

1. **研发加计**：研发支出辅助账 → A107012 → 三口径差异调节表（见 [[企业财务规范/IPO会计科目口径/研发相关-IPO会计科目口径]]）。
2. **特别纳税**：关联申报表 → 同期资料 → 功能风险分析。
3. **供应链税务**：供应商主数据 → 发票链（进销项） → 异常凭证清单。
4. **贸易真实性**：合同 / 资金 / 物流 / 发票四流 → 总额净额判断。
