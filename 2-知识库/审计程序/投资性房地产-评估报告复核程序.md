# 投资性房地产 — 评估报告复核程序

> 以财务报告为目的的公允价值评估复核要点。长兴新农都尽调实际案例：天源评报字〔2026〕第0136号。

## 复核第一步：读取评估报告关键要素

| 要素 | 内容（本例） |
|------|-------------|
| 报告名称 | 投资性房地产资产评估报告（公允价值模式） |
| 文号 | 天源评报字〔2026〕第0136号 |
| 评估机构 | 天源资产评估有限公司 |
| 基准日 | 2025-12-31 |
| 评估方法 | 收益法、市场法 |
| 价值类型 | 公允价值 |
| 评估范围 | 1,061项 / 156,635.64㎡ |
| 账面价值 | 73,051.28万元 |
| 评估结论 | 73,233.95万元（增值182.67万，+0.25%） |
| 报告日 | 2026-03-20 |

## 评估方法适用性判断

| 方法 | 适用场景 | 本项目 |
|------|---------|--------|
| **收益法** | 出租型商业房产（租赁市场活跃、有可比租金） | ✅ 副食品市场/沿街商铺/冷库/冻品市场等 |
| **市场法** | 拟售住宅（有类似交易案例） | ✅ 三期住宅等 |
| 成本法 | 一般不适用（难反映商业房产公允价值） | 报告已说明不采用 |

## 复核检查清单（8项核心程序）

### 1. 勾稽验证（必做）
- [ ] 评估报告汇总表 = 评估明细表合计 = 账面数？**差异应为0**
- [ ] 明细项数是否与申报范围一致？序号是否连续、有无重复
- [ ] 明细表内部：原始入账价值 = 成本单价 × 面积（抽查）

### 2. 方法选择合理性
- [ ] 各业态采用的方法是否与其租赁/交易活跃度匹配
- [ ] 报告是否说明为何不适用其他方法

### 3. 关键参数复核（需索取技术说明/底稿）
- [ ] **折现率**：安全利率取值（哪期国债收益率）+ 风险调整值构成 → 各业态折现率数值
- [ ] **收益年限**：土地剩余年限 vs 建筑物剩余经济寿命孰短
- [ ] **市场法修正**：三宗可比实例的坐落/成交价/成交时间/修正系数
- [ ] **租约影响**：已出租部分按合同租金or市场租金？空置率假设？

### 4. 与账面勾稽
- [ ] 评估值 vs 账面值差异率（评估增减值方向、金额）
- [ ] 增值率显著异常的项目逐项核查（增值/减值 TOP10）

### 5. 披露事项核对
- [ ] 无产权证房产（评估为零或需声明权属）
- [ ] 抵押事项与借款/抵押合同交叉核对
- [ ] 租约披露（在租/空置业态清单）
- [ ] 评估结论是否含增值税

### 6. 跨期变动分析
- [ ] 与上期评估值对比：本期增减幅度、项数变化原因（处置/转出/结转）
- [ ] 关注处置、转自用、转存货等变动业务的会计处理

### 7. 评估机构资质
- [ ] 评估师签字、资格证号
- [ ] 中评协备案编码可查

### 8. 底稿留痕
- [ ] 在《投资性房地产公允价值复核表》填列：参考单价来源、期末公允价值、差异及原因
- [ ] 记录"与上期计价方法一致"结论

## 常见发现（本项目实际）

| # | 发现 | 处理 |
|---|------|------|
| 1 | 报告正文"采用资产基础法、收益法"与摘要"收益法、市场法"不一致 | 笔误，要求评估机构更正/说明 |
| 2 | 折现率/收益年限/市场法修正系数仅披露方法框架，未披露数值 | 索取工作底稿验证 |
| 3 | 评估值普遍较账面低 2-10%（97%房产），少数大宗资产增值 | 关注减值对报表影响 |
| 4 | 16项无产权配套设施评估为零（面积2,536㎡） | 已披露，关注报表附注 |
