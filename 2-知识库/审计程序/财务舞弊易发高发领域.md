# 财务舞弊易发高发领域及重点应对

> 来源：证监会《财务舞弊易发高发领域及重点应对措施》+ 2025-2026 处罚案例

## 十大舞弊高发领域

### 1. 收入舞弊（最高发）

| 手法 | 红旗标志 | 应对程序 |
|------|---------|---------|
| 虚构交易 | 新增客户大额销售 + 无物流单据 + 期后退回 | 客户工商信息核查、物流单据第三方验证 |
| 提前确认 | 资产负债表日前密集发货 | 截止测试、PO 条款 vs 实际验收日期比对 |
| 总额法错用 | 贸易/供应链类业务无控制权 | 逐笔判断主要责任人 vs 代理人 |
| 资金循环 | 回款后短期内等额转出 | 银行流水双向核对、资金穿透至最终收款方 |
| 跨期调节 | 资产负债表日前后收入异常波动 | 期后大额销售退回追溯 |

### 2. 货币资金舞弊

| 手法 | 红旗标志 | 应对程序 |
|------|---------|---------|
| 虚增货币资金 | 大额存款 + 营运资金紧张 + 高负债率 | 银行函证全覆盖（含零余额/已注销账户） |
| 资金占用 | 大额关联往来长期挂账 | 信用报告查询、归集协议审查 |
| 虚构回款 | 销售回款后即转出 | 银行流水双向大额测试 |

### 3. 关联交易舞弊

- 隐性关联方识别：同一注册地址/电话/人员
- 交易定价公允性：与市场独立第三方价格比较
- 资金占用筛查：其他应收款大额长期挂账穿透

### 4. 资产减值操纵

- 应收款项预期信用损失率随意调整
- 商誉减值测试时点不当（避免减值）
- 存货跌价准备计提不足

### 5. 费用舞弊

- 虚列咨询费/服务费（医药行业高发）
- 研发费用与生产成本混同
- 跨期费用调节
