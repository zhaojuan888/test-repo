# 各类专项审计思路 — 课程提炼

## 一、经济责任审计（11 项程序）

### 课程结构
```
1. 课程脉络 → 2. 审计流程 → 3. 报告模板（标准版+拆解+复习）
  → 4. 审计计划/人员分工 → 5. 招标文件 → 6. 资料清单
  → 7. 11 项程序详细讲解 + 小金库专项检查
  → 8. 取证单模板 → 9. 访谈提纲
```

### 11 项程序清单
1. 审前调查
2. 编制审计实施方案
3. 下达审计通知书
4. 进点会
5. 内部控制测试
6. 实质性测试（财务收支审计）
7. **小金库专项检查**
8. 审计取证
9. 审计报告征求意见
10. 出具审计报告
11. 审计整改跟踪

### 小金库常见形式
- 隐匿收入设立小金库
- 虚列支出设立小金库
- 转移资产设立小金库
- 以假发票等非法票据套取资金

## 二、财务尽职调查（FDD）

### 课程结构
```
1. 尽调框架梳理 → 2. 报告模板（讲解版+参考样式+估值版+编制指引）
  → 3. 资料清单（尽调版+IPO版）
  → 4. 尽调可能发现的问题 → 5. 财务指标分析方法
```

### 核心框架
1. 公司基本情况（历史沿革/股权结构/组织架构）
2. 行业与业务（行业地位/业务模式/核心竞争力）
3. 财务状况（盈利/资产/负债/现金流）
4. 税务状况（历史合规/潜在敞口）
5. 关联交易（关联方+定价公允性+资金占用）
6. 法律合规（诉讼/担保/行政处罚）
7. 盈利预测（合理性+关键假设）

### 财务指标分析方法
- 盈利能力：毛利率/净利率/ROE/EBITDA 率
- 偿债能力：资产负债率/流动比率/利息保障倍数
- 营运能力：周转率/周转天数
- 成长能力：收入/净利润 CAGR
- 现金流：经营现金流/净利润

## 三、验资审计

### 课程结构
```
1. 课程框架 → 2. 验资讲义 → 3. 资料清单（设立+变更+通用）
  → 4. 询证函模板 → 5. CSA 1602 准则+应用指南
```

### 两种验资类型
| 类型 | 核心程序 |
|------|---------|
| 设立验资 | 审验注册资本实收情况 → 银行询证函 |
| 变更验资 | 审验注册资本增减变动 → 增减资决议+银行回单 |

### 关键准则
- CSA 1602 验资（2006 年发布）
- 验资报告基本内容：范围段+意见段+说明段

## 四、清产核资审计

### 课程结构
```
总体框架 → 重点检查内容 → 审计报告模板
  → 参考资料 → 破产清算审计参考
```

### 核心检查范围
1. 货币资金——盘点+函证
2. 应收款项——函证+可收回性
3. 存货——盘点+跌价
4. 固定资产——盘点+权属+减值
5. 无形资产——权属+摊销
6. 负债完整性——函证+未入账检查
7. 所有者权益——实收资本+留存收益

## 五、所得税汇算清缴

### 核心内容
- 所得税调整过程（财报审计版本 .xlsm）
- 会计利润 → 应税所得：逐项调整

### 纳税调整项目
| 类型 | 常见项目 |
|------|---------|
| 调增 | 业务招待费超标、罚款/滞纳金、未经核定准备金、超标利息 |
| 调减 | 免税收入（国债利息/居民企业间股息）、加计扣除、加速折旧 |
| 暂时性差异 | 资产减值准备、折旧差异、预提费用、可抵扣亏损 |

## 六、贸易公司专项审计（融资性贸易）

### 核心概念
**融资性贸易** = 以贸易为名，实为借贷。无真实货物流转，仅资金流转。

### 识别特征
- 上下游均由同一方指定
- 贸易毛利率极低（< 2%）
- 无仓储/物流记录
- 资金"快进快出"
- 合同无实质商业条款

## 七、专项核查事项（7 大专题）

| 专题 | 核心内容 |
|------|---------|
| **收入体外循环** | 私户收款→体外资金回流→隐匿收入 |
| **现金业务** | 大额现金收付→资金流向追踪 |
| **直销/经销/代理** | 三种模式收入确认时点差异 |
| **第三方回款** | 非客户方回款→代付协议真实性核查 |
| **资金池业务** | 归集资金→实质控制判断 |
| **银行流水检查** | 双向比对+大额穿透+关联方识别 |
| **房地产行业核算** | 收入确认+成本分摊+土增税 |
