# 存货与生产循环 · IPO 审核关注要点与审计应对

> 整理自 IMA「IPO知识库」→ 内控相关 → 存货与生产循环（35 个行业分行业控制活动）。本笔记为跨行业综合提炼。

## 一、循环定位

存货与生产是"材料领用 → 生产/加工 → 成本归集 → 半成品/产成品 → 发出商品 → 销售结转"的主线，直接决定**存货存在性、成本完整性与毛利率真实性**，是 IPO 财务核查的高风险循环。

## 二、跨行业通用关键控制点

- **生产计划与 BOM**：物料需求计划、标准成本/BOM 准确性；以销定产与备货平衡。
- **材料领用**：领料审批、生产订单与配料单匹配、边角料/废料管理。
- **成本归集**：料工费按订单/产品分摊，直接材料+直接人工+制造费用分摊基础合理；研发领料与生产领料区分。
- **在产品和发出商品**：生产进度跟踪、发出商品台账（已发货未验收）、第三方/VMI 仓管理。
- **存货盘点**：定期全盘/循环盘点、账实差异处理；异地/寄售存货的盘点或函证。
- **委外加工**：发料—加工—回收闭环，加工费计入存货成本。

## 三、IPO 审核共性关注重点

1. **存货存在性与权属**：寄售/VMI、客供料、第三方仓存货的盘点或函证；发出商品是否仍由公司控制。
2. **成本归集与分摊**：料工费分摊方法一贯性、停工损失处理、制造费用分配率；与收入配比。
3. **毛利率真实性**：单位成本波动、投入产出比（化工）、料工费结构异常。
4. **存货跌价准备**：可变现净值测算、长库龄/滞销存货计提充分性。
5. **生物资产（农林牧渔）**：生长周期、自然增值、死亡率对存货价值影响，计量方法。
6. **合同履约成本（软件/工程）**：未完工项目成本资本化 vs 费用化，进度真实性。

## 四、典型行业特殊关注（节选）

| 行业 | 特殊关注点 |
|------|------------|
| Fabless/电子 | 委外加工物资+第三方仓、晶圆/封测在途管理 |
| 汽车制造 | JIT/VMI 寄售仓、以销定产、零库存模式 |
| 医药制造 | GMP、多品种小批量、委外加工 |
| 食品制造 | 易腐、保质期、食品安全、周转快 |
| 农林牧渔 | 生物资产（种猪/鱼苗）、生长周期、分散养殖 |
| 有色金属 | 贵金属混同管理、边角料/废渣回收 |
| 建筑业 | 已完工未结算资产（合同履约成本）、项目成本归集 |
| 软件/IT | 合同履约成本（未完工项目成本）、进度反映 |

## 五、审计应对程序

- **存货监盘**：现场盘点（含异地/寄售仓函证或监盘）、发出商品函证、第三方仓核对。
- **成本测试**：料工费归集与分摊抽样、BOM 与标准成本核对、投入产出比分析。
- **分析程序**：毛利率横向/纵向对比、单位成本波动、存货周转与跌价测试。
- **生物资产/合同履约成本**：专业计量或估值复核、项目进度函证/验收核对。
