# 资产管理循环 · IPO 审核关注要点与审计应对

> 整理自 IMA「IPO知识库」→ 内控相关 → 资产管理循环（分行业控制活动；完整行业清单见 IMA 库对应循环 INDEX）。本笔记为跨行业综合提炼，行业差异以简表点出。

## 一、循环定位

资产管理是"资产取得 → 验收/构建 → 入账 → 折旧摊销 → 使用维护 → 盘点 → 减值/处置/转固"的主线，直接决定**资产存在性、权属完整性、折旧摊销准确性与减值充分性**，是重资产及房地产行业 IPO 的高风险循环。覆盖：固定资产、在建工程、无形资产、投资性房地产、长期待摊费用、使用权资产（租赁）。

## 二、跨行业通用关键控制点

- **资产台账与卡片**：一物一卡，财务账、资产台账、实物标签三账一致；新增/调拨/处置实时更新。
- **验收与转固**：在建工程达到预定可使用状态即转固；竣工验收、试生产、投产记录形成闭环，杜绝"已用未转固"。
- **折旧与摊销**：政策（年限/方法/残值）经审批并一贯执行；新增资产次月计提、处置当月停提。
- **权属管理**：房产证、土地使用权证、车辆登记证等权属证明齐备，证载权利人与公司一致。
- **盘点与维护保养**：定期全面盘点，异地/代管资产函证或现场盘点；大额维修与改良支出区分资本化与费用化。
- **减值与处置**：减值迹象识别、可收回金额测算；处置经审批，损益入账完整。

## 三、IPO 审核共性关注重点

1. **资产权属完整性**：房产证/土地证瑕疵（无证、证载不符、抵押受限未披露）、划拨地转出让、集体建设用地合规性。
2. **转固时点与利息资本化**：已完工投入使用但仍挂在建工程；借款利息资本化起止点、资本化率与专门借款/一般借款界定。
3. **折旧摊销政策一贯**：折旧年限显著长于同行、残值率异常、方法随意变更。
4. **减值充分性**：长闲置/技术淘汰资产、烂尾在建工程、商誉及长期资产减值测试假设合理性。
5. **投资性房地产计量模式**：公允价值模式公允性（估值报告、同类可比交易）、成本模式与公允模式转换限制。
6. **关联交易购入资产**：向关联方购买资产的定价公允性、评估值与账面差异。

## 四、典型行业特殊关注（节选）

| 行业 | 特殊关注点 |
|------|------------|
| 制造业（重资产） | 大额设备折旧、产能利用率与闲置资产减值、技改后续支出资本化 |
| 房地产开发 | 投资性房地产（出租物业）计量模式、存货/投资性房地产划分 |
| 软件/信息技术 | 无形资产（软件著作权/外购技术）、研发形成无形资产摊销 |
| 租赁密集行业 | 使用权资产与租赁负债初始计量、低价值资产豁免 |
| 矿业/能源 | 储量估值、环境恢复（弃置）义务、油气资产计量 |
| 医药/化工 | GMP 厂房专用性、环保设施资本化、安全合规改造支出 |

## 五、审计应对程序

- **权属核查**：查验权属证书原件、抵押登记查询、受限资产披露核对。
- **资产监盘**：现场抽盘（含异地/代管资产函证）、账实差异分析。
- **折旧/摊销测试**：复核政策一贯性、重新计算折旧额、新增/处置时点检查。
- **转固测试**：抽取在建工程转固凭证，核验收/投产证据、利息资本化计算。
- **减值测试**：评估减值迹象、复核可收回金额测算假设、比对同行。
