# 研发循环 · IPO 审核关注要点与审计应对

> 整理自 IMA「IPO知识库」→ 内控相关 → 研发循环（覆盖行业最广的内控循环，行业清单见 IMA 库对应循环 INDEX）。本笔记为跨行业综合提炼，重点放在研发费用"三口径"差异与资本化判断。

## 一、循环定位

研发循环是"立项 → 人员投入 → 材料领用 → 试制/中试 → 阶段判定（费用化/资本化）→ 量产/形成无形资产"的主线，直接决定**研发费用真实性、资本化合规性、科创属性认定**。在科创板/创业板 IPO 中是审核最密集的循环之一，且与高新认定、税收优惠深度绑定。

## 二、跨行业通用关键控制点

- **立项与预算**：研发项目立项书、阶段里程碑、预算与工时系统。
- **人员管理**：研发人员工时填报与审批，研发与生产/管理人员区分；避免非研发人员计入。
- **材料领用**：研发领料单与项目挂钩，与生产领料物理/系统隔离，废料回收处理。
- **外包与协作**：委托研发合同、成果归属、费用真实性与关联交易定价。
- **资本化节点**：研究阶段/开发阶段划分证据（可行性论证、立项评审、样机/中试成功）。

## 三、IPO 审核共性关注重点

1. **研发费用归集准确性**：人员（工时/薪酬分摊）、材料、动力、折旧、摊销、设计费、其他费用是否真实且专属研发。
2. **"三口径"差异**：会计口径（CAS）、高新技术企业认定口径、加计扣除口径三者归集范围与金额差异及合理性说明。
3. **资本化时点**：开发阶段"技术可行性+意图+能力+有用性+支出可靠计量"五条件是否充分论证；资本化过早或不当。
4. **研发人员认定**：生产/工艺/质保人员混同计入研发，虚增研发投入以凑科创属性指标。
5. **委托研发真实性与关联**：关联方受托研发、无成果交付的"假外包"、研发费用回流。
6. **研发投入与营收匹配**：研发投入率与同行业可比、研发费用率波动合理性、形成无形资产的摊销。

## 四、典型行业特殊关注（节选）

| 行业 | 特殊关注点 |
|------|------------|
| 医药/医疗器械 | 临床试验阶段资本化、CRO 费用、注册申报进度 |
| 软件/信息技术 | 开发支出（CAS 6）、云/订阅产品研发、人员工时 |
| 半导体/电子 | 流片费用、IP 授权、晶圆研发 |
| 高端装备/制造 | 样机/中试、工艺改进研发、工装模具 |
| 化工/材料 | 配方研发、中试放大、小试到量产 |

## 五、审计应对程序

- **研发人员/工时核查**：抽查工时记录、社保/薪酬分摊、现场观察研发活动，剔除非研发人员。
- **材料领用抽样**：研发领料单→项目→废料处理，核对与生产领料隔离。
- **资本化节点证据**：立项书、可行性报告、专家评审、中试/样机验收，验证五条件。
- **委托研发核验**：合同、发票、成果交付、关联方核查、费用支付流水。
- **三口径差异表**：编制会计/高新/加计差异调节表，说明差异原因与纳税影响。
