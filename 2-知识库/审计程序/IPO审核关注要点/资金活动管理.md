# 资金活动管理循环 · IPO 审核关注要点与审计应对

> 整理自 IMA「IPO知识库」→ 内控相关 → 资金活动管理循环（分行业控制活动；完整行业清单见 IMA 库对应循环 INDEX）。本笔记为跨行业综合提炼。

## 一、循环定位

资金活动是"筹资 → 投资 → 营运资金收付 → 账户与票据管理 → 资金集中/归集"的主线，是**防范资金占用、体外循环、票据违规**的核心循环。覆盖：货币资金、借款、应付债券、长期股权投资、交易性金融资产/理财、应收应付票据。资金活动循环与销售、采购、资产循环高度交织，是 IPO 财务核查的"资金流水穿透"基础。

## 二、跨行业通用关键控制点

- **账户与印章管理**：银行账户开立/注销审批；网银 U 盾、财务章、法人章分人保管；不允许个人账户收公司款。
- **付款审批**：分级授权审批、付款与记账职责分离；大额支付多重复核。
- **资金计划**：资金预算/滚动预测、投融资节奏匹配，避免短贷长投。
- **票据管理**：票据收取、背书、贴现、质押台账；严禁无真实交易背景票据。
- **理财与闲置资金**：理财额度审批、产品风险等级、收益入账完整。

## 三、IPO 审核共性关注重点

1. **资金流水核查**：控股股东、实控人、董监高及关键岗位人员个人卡与公司资金往来；体外循环、账外账。
2. **关联方资金占用**：报告期各期资金拆出/拆入、计息与否、清理进度；IPO 申报前须彻底整改。
3. **大额资金往来商业实质**：与客户/供应商的大额非经营性往来、资金池归集、受托支付。
4. **票据合规**：无真实交易背景的银行/商业承兑汇票、票据池表外风险、贴现息处理。
5. **受限资金披露**：货币资金中的保证金、冻结、定期存款质押等受限部分是否充分披露。
6. **外币与汇兑损益**：跨境收支、套期有效性、汇兑损益计算与现金流量分类。
7. **第三方回款/代付**：已在销售循环关注，此处关注资金流水的对应勾稽。

## 四、典型行业特殊关注（节选）

| 行业 | 特殊关注点 |
|------|------------|
| 大宗商品贸易 | 票据池/信用证、托盘融资、保证金规模 |
| 房地产开发 | 预售资金监管账户、受限资金大 |
| 跨境/出口 | 外汇收支、离岸账户、汇兑损益波动 |
| 集团企业 | 资金池/归集、内部结算中心、关联方资金往来 |
| 制造业 | 票据结算占比、供应链金融 |

## 五、审计应对程序

- **银行函证**：全部银行账户（含已注销、保证金、定期存款质押）函证，亲函或独立控制。
- **资金流水双向核查**：抽取大额收支，追至合同/发票/单据；个人卡流水取得并核查。
- **关联方资金占用测试**：往来余额与流水双向核对、计息测算、整改证据。
- **票据盘点**：票据台账与实物/网银核对、贴现与背书查验。
- **受限资金核对**：银行函证+企业信用报告+定期存款协议，验证披露完整性。
