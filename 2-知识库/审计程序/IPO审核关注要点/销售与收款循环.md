# 销售与收款循环 · IPO 审核关注要点与审计应对

> 整理自 IMA「IPO知识库」→ 内控相关 → 销售与收款循环（25 个行业分行业控制活动）。该库聚焦三大交易所重点审核问题，分行业、分科目整理审核关注重点与审计应对。本笔记为跨行业综合提炼，行业差异以简表点出。

## 一、循环定位

销售与收款是企业"收入形成 → 债权形成 → 资金回笼"的主线，是 IPO 财务核查的**第一重点循环**。覆盖环节：客户开发与信用管理 → 订单 → 发货/履约 → 开票 → 收入确认 → 应收账款 → 回款 → 坏账计提。

## 二、跨行业通用关键控制点（基于 25 行业共性）

- **订单与合同**：系统化管理，审批与执行职责分离；区分定制化/标准化、时点法/时段法履约义务。
- **发货与验收**：出库单、客户签收/验收单、物流单据形成闭环；寄售/代销/代管需设独立台账，定期对账。
- **收入确认**：以"控制权转移"为确认时点（CAS 14）；贸易商/经销商销售需穿透至最终销售实现，而非仅以买断出库确认。
- **开票与入账**：发票、出库、账面收入三方一致；关注提前/滞后开票与收入确认的差异。
- **应收与回款**：信用政策、账龄分析、坏账计提政策一贯；第三方回款须说明商业合理性并核查代付协议与资金流水。

## 三、IPO 审核共性关注重点

1. **收入确认方法**：总额法 vs 净额法（贸易、平台、代理模式）；时段法 vs 时点法（定制、服务、长期合同）。
2. **经销/贸易商模式**：终端销售实现（穿透核查、走访、进销存）、期后压货、突击收入、退换货政策与会计影响。
3. **第三方回款**：自然人/关联方代付的商业实质、内控措施、占比及变动趋势。
4. **突击收入与期后退货**：资产负债表日前后截止性、销售退回对收入完整性与准确性的影响。
5. **客户集中度与关联交易**：大客户依赖、关联交易非关联化、潜在利益输送。
6. **函证与替代程序**：应收账款/预收款项函证回函差异、未回函的替代审计程序。

## 四、典型行业特殊关注（节选）

| 行业 | 特殊关注点 |
|------|------------|
| 计算机/通信设备制造 | 客户集中、寄售/代销、境外销售、经销商最终销售实现 |
| 软件/信息技术 | SaaS/系统集成、验收周期长、履约进度（时段法）确认 |
| 化工原料 | 大宗价格波动、VMI/包线结算、先款后货、危险化学品管理 |
| 医药制造 | 多层级经销、两票制、终端流向管理、推广费合规性 |
| 食品制造 | 直营+加盟、预收款/会员卡、第三方回款 |
| 公用事业（水电气） | 特许经营、政府为主要客户、回款审批周期长 |
| 连锁餐饮 | 门店多、现金/第三方支付占比大、系统收款完整性 |

> 完整 25 行业清单见 IMA 库 INDEX（另含农林木渔、建筑、文体娱乐、居民服务、教育、科研技术服务、金融、租赁商务等）。

## 五、审计应对程序

- **了解与测试内控**：穿行测试覆盖订单至回款全流程；关注 ERP/收银等系统控制、职责分离。
- **实质性程序**：收入细节测试（抽样核对 合同→出库→签收→发票→回款）、截止测试、函证（应收+预收）、分析程序（毛利率、月度波动、退换货率）。
- **经销/贸易商穿透**：走访/函证、进销存核对、终端销售核查。
- **第三方回款**：代付协议、资金流水双向核查、占比与变动分析。
