# 采购与付款循环 · IPO 审核关注要点与审计应对

> 整理自 IMA「IPO知识库」→ 内控相关 → 采购与付款循环（19 个行业分行业控制活动）。本笔记为跨行业综合提炼。

## 一、循环定位

采购与付款是"供应商开发 → 采购申请 → 审批 → 订单 → 收货验收 → 入库 → 应付账款 → 付款"的主线，同时是**存货与生产的材料流入端**。覆盖：供应商管理、采购价格、收货质检、应付/预付核算、资金支付。

## 二、跨行业通用关键控制点

- **供应商准入与评估**：供应商主数据管理、资质审查（医药 GMP、医疗器械注册等）、定期评估与淘汰。
- **采购申请与审批**：需求部门提报、独立审批、与预算/订单匹配；职责分离（申请≠审批≠执行）。
- **价格管理**：大宗原材料框架协议/一单一议；价格波动行业的定价审批与锁价机制。
- **收货与验收**：到货质检（数量、等级、规格）、入库单与采购订单匹配；非标品（农产品）的计量与质检控制。
- **委外加工管理**：发料、加工费、回收入库的全流程跟踪（电子 Fabless、装备制造的封测/机加外协）。
- **付款与核算**：付款审批权限、应付暂估完整性、预付性质（警惕关联方资金占用）、现金/个人供应商的特殊管控。

## 三、IPO 审核共性关注重点

1. **供应商真实性**：是否存在关联方非关联化、空壳供应商、虚假采购；供应商集中度与依赖。
2. **采购价格公允性**：与可比市场价/第三方比对的差异；关联采购的定价公允。
3. **委外加工（Fabless/电子等）**：加工物资存在性、加工费合理性、第三方仓库盘点。
4. **现金/个人供应商交易**：农林牧渔等行业向自然人、个体户采购的现金交易合规性、资金流水核查。
5. **采购截止性**：期末存货/应付暂估的完整性，跨期采购。
6. **预付款项性质**：大额预付是否实质为关联方资金占用或融资性安排。

## 四、典型行业特殊关注（节选）

| 行业 | 特殊关注点 |
|------|------------|
| 计算机/电子设备 | 委外加工（封测/测试）、芯片采购周期长、供应链安全 |
| 化工 | 大宗价格波动、贸易商/个体户供应商、危险化学品采购 |
| 农林牧渔 | 自然人/合作社供应商、现金交易、非标品计量 |
| 医药制造 | 供应商资质（GMP/GSP）、原料质量合规 |
| 连锁餐饮 | 中央厨房统一采购、食材安全与成本 |
| 采矿业 | 外包劳务、大宗物资、能源采购 |
| 公用事业 | 重资产长周期设备/工程采购，合同金额大 |

## 五、审计应对程序

- **供应商核查**：走访/函证主要供应商、工商信息比对（关联方排查）、资质文件检查。
- **采购细节测试**：抽样核对 订单→收货→入库→发票→付款；价格与合同/市场比对。
- **委外加工**：发料与回收核对、加工费分析、期末在加工物资盘点/函证。
- **现金交易**：资金流水双向核查、个人供应商身份与交易真实性。
- **截止与完整性**：应付暂估测试、存货采购截止、预付性质分析。
