# IT 审计 — 两套系统检测

> 天健所普利制药案核心教训：客户同时使用两套软件系统，数据存在重大差异，但未被识别。

## 什么是"两套系统"

被审计单位同时运行两套（或多套）记录财务和业务数据的软件系统，数据之间**不一致**：
- 一套用于实际经营
- 一套用于对外报告/税务申报
- 或者：业务系统 vs 财务系统数据不连通

## 检测方法

| 方法 | 执行 |
|------|------|
| 系统清单调查 | 访谈 IT 部门——列出所有在用的业务/财务系统 |
| 数据导出比对 | 从各系统导出同一期间数据→比对差异 |
| 系统日志分析 | 检查是否存在人为修改日期/删除记录的操作 |
| 接口测试 | 业务系统→财务系统的数据传输是否完整、及时 |
| 权限检查 | 不同系统间是否有同一人有超级管理员权限 |

## 红旗标志

- 审计底稿已记载某软件系统的存在，但未进一步核查
- 财务数据与业务数据（如发货量）不一致
- 系统日志存在大量后台修改记录
- IT 人员同时兼任财务系统管理员
