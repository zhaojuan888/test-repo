# 科创板 IPO 收入核查 — 核心程序与监管红线

> 科创板以信息披露为核心，收入真实性是 IPO 审核的"一票否决项"。
> 2026 年天健所普利制药案、2025 年公证天业华道生物案均因收入核查不到位被罚。

## 科创板收入核查的独特要求

| 维度 | 科创板特殊要求 | 与其他板块差异 |
|------|-------------|-------------|
| 核查比例 | 原则上不低于收入的 **60%** | 主板一般 50%，科创板更严格 |
| 客户走访 | 覆盖**各类业务模式**的代表性客户 | 交易所问询常要求"逐类逐模式"回复 |
| 境外收入 | 海关数据 + 中信保 + 境外实地走访 | 无境外实地走访可能被要求补充 |
| 新增客户 | 报告期内新增重大客户**必查** | 这是问询高频问题 |
| 穿透核查 | 经销商模式需穿透至**终端** | 不能仅核查经销商 |

## 一、收入核查六大程序

### 1. 合同检查（最基本）

| 步骤 | 要点 |
|------|------|
| 抽样原则 | 覆盖各类产品+各类业务模式；检查比例不低于 60% |
| 重点客户 | 报告期新增客户、新增业务模式客户优先 |
| 验收条款 | 逐条核对收入确认时点与合同约定是否一致 |
| 非寄售模式 | 关注验收条件、初验 vs 终验 |
| 寄售/VMI 模式 | 核查客户实际领用记录，不可按发货确认 |

### 2. 函证程序

| 风险点 | 应对 |
|--------|------|
| 函证全过程控制 | 发函地址核实（工商地址+实际经营地址）、不得由被审计单位代发 |
| 回函不符 | 逐笔调查差异原因，编制调节表 |
| 未回函替代程序 | 检查合同+出库单+物流单+验收单+回款记录，缺一不可 |
| 境外函证 | 使用国际快递可控路线，考虑当地语言的函证模板 |

### 3. 实地走访

| 步骤 | 要点 |
|------|------|
| 走访前 | 了解客户工商信息、股权结构、与发行人的关联关系 |
| 走访中 | 查看经营场所、访谈关键人员、核实交易真实性 |
| 走访记录 | 拍照留痕、访谈纪要签字、名片收集 |
| 异常信号 | 注册地址与经营地址不符、无实际经营人员、与发行人存在隐性关联 |

### 4. 穿行测试（严禁形式化）

> 引用案例：中审众环庚星股份案——无验收资料即认定内控有效→被罚

对每个主要客户的收入循环，追踪一笔交易从**合同签署→发货→验收→开票→回款**的全过程：
- 必须取得每一环节的实际运行证据
- 无验收报告≠内控有效
- 制单人=复核人→内控缺陷

### 5. 截止测试

| 方向 | 测试内容 |
|------|---------|
| 正向 | 资产负债表日前 N 天发货 → 是否在正确期间确认 |
| 反向 | 资产负债表日后 N 天发货 → 是否被提前确认 |
| 期后退回 | 期后大额销售退回 → 追查是否应在当期冲减 |

### 6. 毛利率分析与可比公司对标

| 分析维度 | 红旗标志 |
|---------|---------|
| 分产品毛利率 | 某产品毛利率显著高于同行业 |
| 分客户毛利率 | 关联方客户毛利率异常 |
| 月度毛利率波动 | 年末毛利率突然大幅上升 |

## 二、科创板 IPO 审核高频问询

| 问询方向 | 典型问题 | 审计应对 |
|---------|---------|---------|
| 收入确认政策 | "结合合同条款说明收入确认时点的合理性" | 逐条比对合同+同行业惯例 |
| 经销商模式 | "经销商是否实现最终销售" | 穿透至终端，获取经销商进销存数据 |
| 境外收入 | "境外销售真实性如何验证" | 海关数据比对+中信保+境外走访 |
| 第四季度集中 | "Q4 收入占比高的原因" | 截止测试+期后退回分析+同行业季度分布对比 |
| 主要客户依赖 | "对xx客户收入占比超 50%是否可持续" | 客户关系稳定性分析+在手订单 |
| 验收周期异常 | "验收周期明显长于同行业的原因" | 逐笔分析验收延期的合理性 |

## 三、IT 审计辅助收入核查

> 引用案例：天健所普利制药案——未发现客户使用两套系统→被罚

- ERP 系统与业务系统的数据一致性比对
- 发货系统出库时间 vs 财务系统收入确认时间
- 是否存在人为修改系统日期的记录
- 系统日志完整性——是否有删除/修改痕迹
