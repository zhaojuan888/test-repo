# 存货 — 盘点程序关键要点

> 利安达案核心教训：盘点日≠资产负债表日时，必须核查期间变动。

## 监盘程序

1. **制定盘点计划**：双向抽盘（账→物 + 物→账）
2. **实地监盘**：审计师必须到场，不可仅依赖企业自盘
3. **盘点日≠资产负债表日**：**必须核查期间出入库变动**（利安达案核心）

## 盘点日至资产负债表日变动核查

| 核查内容 | 方法 |
|---------|------|
| 入库变动 | 获取期间全部入库单+采购合同+付款记录 |
| 出库变动 | 获取期间全部出库单+销售合同+回款记录 |
| 物流运输 | 第三方物流单据（独立验证） |
| 大额/异常变动 | 逐笔追查原因，不可仅抽样 |

## 比率分析预警

| 红旗指标 | 阈值 |
|---------|------|
| 存货增速远超收入增速 | 差异 > 20% → 追加程序 |
| 存货周转天数大幅上升 | 同比变化 > 30% → 跌价风险 |
| 存货跌价准备率异常 | 与同行业对比 |

## 内控检查

- 出入库单**制单人≠复核人**
- 制单人=复核人 → 内控缺陷（利安达案具体发现）
