# 处罚案例×科目审计——正确处理 + 审计程序 + 关键证据

> 从 2025-2026 年真实处罚案例反推：每个科目"应该怎么做"。
> 每条包含：案例 → 错误行为 → 正确处理 → 审计程序 → 关键证据清单。

---

## 一、收入确认

### 案例
- [[2026-天健所-普利制药-审计失败]] — 两套系统+总额法错用
- [[2026-中审华-广道数字-六年虚增收入]] — 六年虚增 87-99%
- 北京亚泰·紫天科技 — 总额法虚增 18.7 亿
- 公证天业·华道生物 — IPO 虚开发票+更换客户异常
- 中审众环·庚星股份 — 无验收资料即认定内控有效

| 要素 | 内容 |
|------|------|
| **涉及准则** | [[CAS-14-总额法vs净额法\|CAS 14 收入]] |
| **正确处理** | ① 判断主要责任人/代理人 → 总额法/净额法；② 识别履约义务+交易价格+分摊；③ 时点履约（验收/签收/提单日）vs 时段履约（产出法/投入法）；④ 净额法下仅确认佣金/手续费 |
| **审计程序** | ① 逐笔检查主要客户合同——控制权转移条款、验收条件；② 收入截止测试——资产负债表日前后各 N 天发货记录与收入确认日期比对；③ 毛利率分析——分产品/分客户/分月度；④ 函证——金额+交易条款双函证；⑤ 穿透核查经销商终端销售 |
| **关键证据** | ① 客户合同/订单（含验收条款）；② 出库单/发货单+物流单号；③ 客户验收单/签收单（原件）；④ 银行回单（比对回款方与客户名称一致性）；⑤ 海关报关单（境外收入）；⑥ 经销商进销存数据（穿透至终端） |
| **处罚启示** | 总额法/净额法判断错误是审计失败第一高频；两套系统是红旗——必须用 IT 审计工具比对；六年连续虚增→函证全过程控制不容妥协 |

## 二、存货

### 案例
- [[2025-利安达-江平生物-存货审计失败]] — 存货+246% vs 收入+9%，出入库单制单人=复核人

| 要素 | 内容 |
|------|------|
| **涉及准则** | CAS 1 存货、[[CAS 8 资产减值\|CAS 8]]（跌价） |
| **正确处理** | ① 按成本与可变现净值孰低计量；② NRV = 估计售价 - 至完工估计成本 - 销售费用；③ 跌价准备按单项/类别计提 |
| **审计程序** | ① 监盘——双向抽盘（账→物、物→账）；② **盘点日至资产负债表日变动核查**（利安达案核心教训）——获取期间出入库单+物流单据；③ 库龄分析——识别呆滞品；④ NRV 测试——参考期后售价/近期市场价；⑤ 出入库单内控检查——制单人≠复核人 |
| **关键证据** | ① 盘点表（签字版）；② 盘点日至资产负债表日全部出入库单；③ 物流运输单据（第三方）；④ 期后销售发票（验证 NRV 售价）；⑤ 存货库龄明细表；⑥ 存货跌价准备测算底稿 |
| **处罚启示** | 存货增速远超收入增速→必须追加程序；制单=复核→内控缺陷直接证据 |

## 三、货币资金

### 案例
- 中兴财光华·东旭系 — 虚增货币资金+资金占用 → 罚没 2.52 亿
- [[2026-中审华-广道数字-六年虚增收入]] — 伪造银行回单

| 要素 | 内容 |
|------|------|
| **涉及准则** | CAS 30 财务报表列报、CAS 22 金融工具 |
| **正确处理** | ① 货币资金按实际持有金额列报；② 受限资金（保证金/冻结/质押）必须单独披露；③ 资金归集（资金池）需判断实质控制权 |
| **审计程序** | ① **银行函证全覆盖**——所有账户（含当期注销+零余额）；② 银行流水双向核对——企业日记账↔银行对账单，大额双向测试；③ 企业信用报告查询——识别未披露的担保/质押/归集协议；④ 大额资金"快进快出"穿透——追查至最终收款方 |
| **关键证据** | ① 银行询证函回函（原件、全过程控制）；② 全部银行账户对账单（含注销账户）；③ 企业信用报告；④ 银行账户归集协议/资金池协议；⑤ 大额资金进出凭证+审批单 |
| **处罚启示** | 函证不覆盖零余额/已注销账户→致命漏洞；伪造银行回单→银行对账单必须直接从银行获取 |

## 四、应收账款 / 预期信用损失

### 案例
- 河南守正创新 — 预期信用损失率变更复核不到位 → 暂停 3 个月

| 要素 | 内容 |
|------|------|
| **涉及准则** | [[CAS-22-金融工具\|CAS 22]]（ECL 模型） |
| **正确处理** | ① 按预期信用损失模型计提——迁徙率/滚动率法或单项评估；② 前瞻性调整必须有合理依据；③ 信用损失率变更需充分论证 |
| **审计程序** | ① 账龄分析——重新计算迁徙率；② 单项计提——逐笔评估债务人信用状况；③ 期后回款测试——验证可收回性；④ 函证——余额+账龄双函证；⑤ 前瞻性参数——核查管理层使用的宏观预测数据来源 |
| **关键证据** | ① 应收账款账龄明细表；② 历史回款数据（至少 3 年）；③ 迁徙率/滚动率计算底稿；④ 期后回款银行单据；⑤ 单项计提的债务人财务数据/信用报告 |
| **处罚启示** | 信用损失率变更无充分论证→被罚；迁徙率不能直接用上年数据 |

## 五、商誉 / 长期资产减值

### 案例
- 河南守正创新 — 并购评估增值部分折旧摊销未复核
- 豪能股份 — 航空板块商誉减值 0.98 亿

| 要素 | 内容 |
|------|------|
| **涉及准则** | [[CAS 8 资产减值\|CAS 8]] |
| **正确处理** | ① 每年至少一次减值测试（商誉必须每年测）；② CGU 划分合理；③ 可收回金额 = max（公允价值-处置费用，预计未来现金流量现值）；④ 减值损失先冲商誉，再按比例分摊 |
| **审计程序** | ① CGU 划分合理性评估；② WACC/增长率等关键参数独立测算+敏感性分析；③ 并购评估增值部分折旧摊销复核（守正创新案教训）；④ 在建工程——是否存在延迟转固、利息资本化停止时点 |
| **关键证据** | ① 减值测试模型（含公式链接）；② 关键参数来源（WACC/增长率/折现率）及依据；③ 资产评估报告（如有）；④ 在建工程进度报告+验收文件；⑤ 利息资本化计算表 |
| **处罚启示** | PPA 评估增值的折旧摊销必须独立复核；不能仅依赖管理层预测 |

## 六、合并财务报表

### 案例
- 北京亚泰·紫天科技 — 未发现合并抵销错报 1.22 亿

| 要素 | 内容 |
|------|------|
| **涉及准则** | CAS 33 合并财务报表 |
| **正确处理** | ① 控制三要素判断；② 内部交易全额抵销（收入/成本/往来/现金流）；③ 内部未实现利润抵销（存货/固定资产）；④ 合并层面递延所得税重新计算 |
| **审计程序** | ① 合并范围完整性检查——结构化主体/VIE 是否纳入；② 内部交易对账——母子/子子之间交易金额核对；③ 内部未实现利润计算——按毛利率×期末未对外出售存货；④ 合并层面递延所得税重新计算 |
| **关键证据** | ① 合并范围判断底稿（含控制三要素分析）；② 内部交易对账单（双方签字确认）；③ 内部未实现利润计算表；④ 合并抵销分录汇总；⑤ 复杂股权结构图 |
| **处罚启示** | 1.22 亿抵销错报未被发现→合并抵销必须独立重算 |

## 七、研发费用

### 案例
- [[金税四期-重点稽查领域\|拉萨慧业医药]] — 外购技术伪装委托研发 → 补税+罚款 1716 万

| 要素 | 内容 |
|------|------|
| **涉及准则** | CAS 6 无形资产（资本化条件）、财税〔2015〕119 号（加计扣除） |
| **正确处理** | ① 研究阶段→费用化，开发阶段→满足 5 条件方可资本化；② 研发费用归集按项目核算；③ 共用费用按合理标准分摊（工时/面积/用量）；④ 四口径数据（会计/高新/加计扣除/IPO）需保持一致性 |
| **审计程序** | ① 研发立项文件检查——董事会/技术委员会书面决议；② 资本化时点判断——是否取得临床试验批件/技术可行性论证；③ 研发人员工时记录追溯——与生产人员是否混同；④ 委外研发——合同内容+商业合理性+CRO 关联关系；⑤ 四口径差异逐项调节 |
| **关键证据** | ① 研发项目立项书+董事会决议；② 资本化时点判断的技术文档（临床试验批件/技术评估报告）；③ 研发人员工时记录（原始）；④ 委外研发合同+成果交付记录；⑤ 四口径差异调节表 |
| **处罚启示** | 已将费用化支出红字冲销转资本化→追溯调整禁止；外购伪装委外→实质重于形式 |

## 八、关联方交易 / 资金占用

### 案例
- 中兴财光华·东旭系 — 未识别资金占用
- 蓝帆医疗 — 关联交易特别纳税调整 1.96 亿

| 要素 | 内容 |
|------|------|
| **涉及准则** | CAS 36 关联方披露、CAS 1323 关联方 |
| **正确处理** | ① 关联方关系完整披露（含隐性关联方）；② 关联交易定价符合独立交易原则；③ 资金占用必须归还+披露 |
| **审计程序** | ① 关联方清单完整性——股权穿透+企查查+关键人员亲属关系；② 隐性关联方——同一注册地址/电话/人员；③ 大额其他应收款穿透——追查资金最终流向；④ 关联交易定价公允性——与非关联方价格对比 |
| **关键证据** | ① 关联方关系图谱（含股权穿透）；② 企查查工商信息查询记录；③ 关联交易合同+定价依据；④ 资金流水（关联方往来）；⑤ 独立交易原则分析底稿 |
| **处罚启示** | 资金占用是最常见的未识别重大错报之一；隐匿关联方需要工商数据交叉比对 |

## 九、函证（跨科目通用）

### 案例
- 河南守正创新 — 函证程序不到位
- [[2026-中审华-广道数字-六年虚增收入]] — 六年函证均失效

| 要素 | 内容 |
|------|------|
| **涉及准则** | CAS 1312 函证 |
| **正确处理** | ① 函证全过程由审计师控制；② 发函地址核实（工商地址+实际经营地址）；③ 回函不符逐笔调查；④ 未回函执行充分替代程序 |
| **审计程序** | ① 发函前——核对被询证者名称+地址+金额；② 发函中——审计师亲自寄发/跟函；③ 回函——核对回函地址+签章+快递单号；④ 不符事项——编制调节表、追查原因；⑤ 替代程序——合同+出库单+物流单+验收单+回款记录，五证齐全 |
| **关键证据** | ① 询证函（发函联+回函联）；② 发函地址核实记录（工商信息截图）；③ 快递单（发函+回函）；④ 回函不符调节表；⑤ 替代程序底稿（含五证） |
| **处罚启示** | 函证由被审计单位代发→无效；回函全一致无差异→反而可疑 |

## 十、穿行测试 / 内控（跨科目通用）

### 案例
- 中审众环·庚星股份 — 无验收资料即认定"内控已得到执行"

| 要素 | 内容 |
|------|------|
| **涉及准则** | CAS 1211 了解被审计单位及其环境、COSO 框架 |
| **正确处理** | ① 穿行测试必须追踪一笔交易从发生到记录的全过程；② **必须取得每一环节的实际运行证据**——不可仅凭"描述"认定有效；③ 发现例外→评估是否为控制缺陷 |
| **审计程序** | ① 选择 1-2 笔代表性交易；② 从原始凭证追踪至财务报表——合同→发货→验收→开票→记账→报表；③ 每个环节检查：审批签字/系统日志/实物单据；④ 制单人≠复核人检查 |
| **关键证据** | ① 穿行测试记录表（含每个环节的证据清单）；② 各环节取得的原始凭证复印件；③ 系统截图/日志记录；④ 例外事项记录+评估结论 |
| **处罚启示** | 无验收报告即认定"内控有效"→2025 年被罚的典型案例；形式化穿行测试=未执行 |
