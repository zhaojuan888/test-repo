# 应付账款-款项性质识别

## 风险点

应付账款明细账中混杂不同性质的款项：
- 工程款 / 设备采购款 / 材料款 / 劳务服务款（影响披露分类）
- 无商业实质的往来款（关联方资金占用嫌疑）

## 识别方法

1. 拉取应付账款明细账，按**摘要关键词**初分类：
   - 工程款：工程/施工/进度款/结算
   - 设备款：设备/机器/采购
   - 材料款：材料/原料/货物
   - 劳务款：劳务/服务/咨询
2. 对照供应商营业执照经营范围
3. 大额异常款项逐笔核查合同

## 审计程序

1. **明细分类**：按款项性质重分类汇总
2. **合同核对**：大额供应商采购合同条款
3. **函证**：对主要供应商发函
4. **账龄分析**：长期挂账款项的性质合理性

## 关键证据

- 应付账款明细账（含摘要）
- 采购合同/工程合同
- 供应商函证回函
- 账龄分析表
