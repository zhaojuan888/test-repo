# 穿行测试 — 严禁形式化（执业警示）

> 中审众环庚星股份案：无验收资料即认定"内控已得到执行"→被罚。

## 核心原则

**穿行测试 = 取证，不是描述。**
必须追踪一笔交易从发生到记录的**全过程**，取得**每个环节的实际运行证据**。

## 标准流程（每一环节必须取证）

| 环节 | 必须取得的证据 |
|------|--------------|
| 合同签署 | 合同审批单 + 签字页 + 系统审批日志 |
| 发货/履约 | 出库单 + 物流单 + 客户签收记录 |
| **验收** | **验收报告 / 验收单**（庚星股份案缺失项） |
| 开票 | 发票 + 发票审批记录 |
| 记账 | 会计凭证 + 系统记账日志 |
| 回款 | 银行回单 + 回款与客户名称一致性核对 |

## 常见形式化错误

| 错误 | 正确做法 |
|------|---------|
| "询问了相关人员，确认控制有效" | 取得原始凭证，不依赖口头描述 |
| "查看了系统截图" | 导出系统日志，验证不可篡改性 |
| 未取得验收资料即认定"控制已得到执行" | 无验收 = 控制缺失 |
