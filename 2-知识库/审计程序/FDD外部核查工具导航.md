# FDD外部核查工具导航

> 来源：投行之声 尽调工具导航（https://www.iposeek.com/duediligence/external-nav）
> 用途：尽调 / 年报审计中**独立于被审计单位提供的资料**之外的外部证据源。按核查场景分类，标注审计用途。
> 原则：**外部可获取的信息不要只问企业要**——凡涉及主体资格、资质、诉讼、知识产权、抵押等，均应外部独立核验并留痕。

## 九、落地建议（对照本所项目）

- [ ] 做**标准核查包**：每个项目固定跑「工商 + 执行信息 + 裁判文书 + 信用中国 + 知识产权质押 + 高新资质 + 排污许可」7 项，留截图与查询日期。
- [ ] **长兴新农都**：土地市场网（土地权属）+ 建筑市场监管平台（在建工程）+ 投资项目在线审批（项目合规）。
- [ ] **武耀安全玻璃 / 蚌埠高新合资**：专利检索（专利许可权属）+ 商标网 + 增值电信/业务资质。
- [ ] **行业分析**：优先用行业协会 + 券商研报交叉验证，不要直接采信企业提供的市场份额数据。
