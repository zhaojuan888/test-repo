## 一、货币资金审计（01）

### 审计逻辑链
1. 获取全部银行账户清单 → 函证全覆盖（含零余额/已注销）
2. 银行流水双向核对：企业账 ↔ 银行对账单
3. 大额异常资金"快进快出"穿透 → 追查至最终收款方
4. 受限资金识别：保证金/冻结/质押 → 单独披露

## 二、存货审计（04）

### 风险分析框架（制造业前提）

| 场景 | 信号 | 审计关注 |
|------|------|---------|
| 收入下降 + 存货上升 | 存货周转率 ↓ | 呆滞/滞销 → **跌价准备完整性** |
| 收入上升 + 存货下降 | 周转率 ↑ | **收入提前确认**？→ 截止测试 |
| 周转率持平 | — | 仍需验证 NRV |

### 核心程序
- 工期越长 → 关注是否采用时段履约（完工百分比法 → CAS 14 判断）
- 库龄分析 → 识别呆滞 → 逐项 NRV 测试

## 三、固定资产审计（05）

### 审计逻辑链

```
内部控制了解
  → 产能利用率（访谈）：30%/70%/100%/120%
    → 产能利用率低 → 减值迹象（CAS 8 第5条）
  → 资产购置合理性
    → 市场预期 vs 实际销售 → 在手订单验证
  → 供应商选择（招标投标）
  → 合同签署 → 验收转固时点
```

### 关键判断
- 成本构成中折旧占比持续增长 → 关注产能利用率和减值
- 例：A 产品想扩建，实际产能利用率 100%；B 产品无计划，利用率 50% → **B 产品相关资产是否存在减值？**

## 四、预付账款审计（08）

### 审计逻辑链

```
预付账款主表（两期对比）
  → 明细表：关联方识别 + 款项性质 + 账龄
  → 账龄明细表
  → 函证
  → 合同检查（付款条款 vs 实际预付比例）
  → 抽凭
```

### 关键风险
- **资金提前支出**：合同约定 vs 实际预付是否一致
- **关联方资金占用**：大额预付 → 期后是否实际收到货物/服务
- **长期挂账**：账龄 > 1 年 → 是否存在无法收回风险

## 五、收入审计（12）

### 收入确认政策比较（智能家电行业示例）

| 模式 | 确认时点 | 审计要点 |
|------|---------|---------|
| 线上直销 | 消费者确认收货/系统默认 | 10 天自动确认 → 核查系统日志 |
| 电商平台入仓 | 收到平台对账清单 | 核对平台数据 vs 企业数据 |
| 线上经销 | 签收/交付物流 | 物流单号验证 |
| 线下经销 | 客户签收确认 | 签收单原件 |
| 代销 | 收到代销清单 | 清单真实性验证 |
| 境外 FOB | 装船取得提单 | 报关单+提单日期 vs 收入确认日 |

### 建造合同收入（新收入准则后）

| 旧准则 | 新准则（CAS 14 2017） |
|--------|---------------------|
| 完工百分比法（成本法/工作量法） | 时段履约 → 产出法/投入法 |
| 结果能可靠估计时确认 | 客户能控制在建资产 → 时段履约 |

### 医疗行业收入确认模式

| 收入类型 | 确认时点 |
|---------|---------|
| 挂号收入 | 缴费时确认 |
| 门诊检查治疗 | **服务完成时**确认 |
| 手术及住院 | 办理出院结清时确认 |
| 药品销售（门诊） | 药品提供后确认 |
| 药品销售（住院） | 出院结清时确认 |
| 视光收入 | 验光服务+镜片提供后确认 |

## 六、研发费用审计（15）

### 审计程序清单
1. 各期研发费用变动分析（三年一期）
2. 按项目 + 核算内容逐项分析 → 研发费用明细表
3. 研发人员学历、胜任能力抽样检查
4. 材料抽样检查
5. 外协服务协议检查 → 委外研发的真实性
6. 审计调整 → 人工成本重新计算

### 底稿结构
```
研发费用披露表（合并报表）
  核算项目 × 年度（2022/2023/2024）
    → 未审数 | 调整数 | 审定数
```

## 七、所得税费用审计（16）

### 底稿结构（林铖模板）

| 索引号 | 底稿 | 内容 |
|--------|------|------|
| 6600 | 导引表 | 当期 + 递延汇总 |
| 6600-0 | 程序表 | 六大审计目标（发生/完整/准确/截止/分类/列报） |
| 6600-1 | 当期费用计算表 | 会计利润 → 应税所得调节 |
| 6600-1-1 | 纳税调整增加检查表 | 逐项调整 |
| 6600-2 | 递延所得税 | 暂时性差异识别+税率 |

### 关键公式
```
所得税费用 = 当期所得税费用 + 递延所得税费用
递延所得税 = (期末暂时性差异 - 期初暂时性差异) × 适用税率
```
