# 收入 — 总额法 vs 净额法判断

> 审计失败第一高频领域。紫天科技 18.7 亿、天健所普利制药案均源于此。

## 判断流程图

```
是否在向客户转让商品前拥有对该商品的控制权？
    ├── 是 → 主要责任人 → 【总额法】
    └── 否 → 代理人 → 【净额法】
```

## 三项关键指标逐一判断

### 1. 首要责任
- 谁对商品或服务的履约承担首要责任？
- 证据：合同条款中的责任条款 + 实际履约记录

### 2. 存货风险
- 转让商品前，谁承担存货的毁损灭失风险？
- 证据：入库单 + 运输单据 + 保险合同

### 3. 定价权
- 谁有权自主决定商品的交易价格？
- 证据：定价政策文件 + 实际销售价格 vs 采购价格对比

## 审计程序

1. 逐笔检查主要客户合同——控制权转移条款
2. 核对物流单据——入库/出库/运输方
3. 检查定价机制——是否有自主定价权
4. 追踪资金流——客户回款是否直接到公司账户
5. 对照同类交易的市场惯例
