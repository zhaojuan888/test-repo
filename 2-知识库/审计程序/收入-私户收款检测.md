# 收入 — 私户收款检测

> 2026 年金税四期全面上线后，私户收款是税务稽查最高发领域。
> 2026 年 5 月税务部门集中曝光 8 起私户收款偷税案：罚没最高 3.69 亿。

## 什么是私户收款

企业通过**个人银行账户**（法人/高管/财务人员/出纳/亲属/员工）收取经营款项，不入公司对公账户、不开发票、不在账簿记载，从而**隐匿收入、逃避增值税和企业所得税**。

## 金税四期如何检测

| 监控点 | 原理 |
|--------|------|
| 四流合一比对 | 合同流 → 发票流 → 货物流 → 资金流，四维交叉比对 |
| 个人卡大额流水预警 | 银行→税务数据共享，单笔 > 5 万或全年累计大额自动预警 |
| 未开票收入占比异常 | 长期远低于同行业→系统自动标记 |
| 增值税税负率偏低 | 金税四期与同行业自动对标，偏离度 > 阈值→稽查 |
| 进销项品类背离 | 进货是原材料，开票却是服务费→异常 |

## 审计检测程序

### Step 1：获取个人卡流水

| 对象 | 范围 | 方法 |
|------|------|------|
| 法人/实际控制人 | 全部个人卡 | 要求提供银行流水 + 签署完整性声明 |
| 财务负责人/出纳 | 全部个人卡 | 同上 |
| 销售负责人 | 重点关注 | 大额异常进账追查来源 |
| 法人/高管亲属 | 如存在异常资金往来 | 扩大范围 |

### Step 2：比对分析

| 比对维度 | 方法 | 红旗标志 |
|---------|------|---------|
| **对公 vs 对私** | 销售收入 vs 对公账户回款 vs 个人卡进账 | 个人卡有客户名称的进账→疑似隐匿销售 |
| **未开票收入占比** | 未开票收入 ÷ 总收入，与同行业对比 | 低于行业均值 50%→异常 |
| **增值税税负率** | 应交增值税 ÷ 营业收入，与同行业对比 | 低于行业均值→可能存在无票收入 |
| **进销项匹配** | 进项品类 vs 开票品类 | 进原材料、出服务费→异常 |
| **收款人 vs 打款人** | 个人卡收款方 vs 客户名称 | 匹配直接隐匿 |

### Step 3：穿透追查

| 方法 | 执行 |
|------|------|
| 大额整数进账 | 追溯打款人身份 + 与公司业务关系 |
| 频繁相同金额 | 可能为分期收款→核查客户订单 |
| 收款后转出 | 是否经个人卡转回对公账户（部分入账、部分隐匿） |
| 定期存款/理财 | 大额定期是否对应未入账的销售回款 |

## 关键证据清单

| 证据 | 获取方式 |
|------|---------|
| 法人/高管/财务人员全部个人卡银行流水 | 要求提供原件或现场登录网银导出 |
| 个人卡完整性声明（签字） | 审计师起草，当事人签署 |
| 企业信用报告 | 人民银行征信中心查询 |
| 金税四期申报数据导出 | 税务局网站下载 |
| 客户回款记录（按客户+按日期） | 财务系统导出 |
| 货物流单据（出库单/物流单） | 仓库系统+物流公司 |

## 处罚案例

| 案例 | 手法 | 罚没 |
|------|------|------|
| 内蒙古伊东集团 | 通过员工及亲属私户收款，少计收入 | 补税+罚款 **3.69 亿** |
| 青岛瑞安转角服装店 | 网络平台店铺+控制人私户收款 | 追缴 **840 万** |
| 大柴旦和信科技 | 员工及亲属私户+虚列研发工资 | 追缴 **456 万** |
| 湖南婴商营养食品 | 实控人亲属私户收款隐匿收入 | 追缴 — |

## 法规依据

| 法规 | 条款 |
|------|------|
| 《税收征收管理法》第 63 条 | 账簿不列/少列收入→偷税，罚 50%-5 倍 |
| 税总征科发〔2025〕32 号 | 个人经营收款码→交易数据同步税务系统 |
| 《增值税法》(2026) 第 20 条 | 销售额明显偏低无正当理由→税务机关核定 |
| 《增值税法》(2026) 第 35 条 | 税务与银行/海关/市监信息共享机制 |
