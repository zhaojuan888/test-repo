# 2025年度准则实施问题 × 科目对照清单

> 来源：财政部《2025年度企业会计准则实施情况分析报告》（2026-08-03 发布，50 页 PDF 已存 `5-参考资料/`）
> 用途：2026 年报审计逐科目对照勾查，发现同类问题纳入风险应对。财政部明确要求会计师事务所将本报告问题**列入审计工作关注重点**。

## 一、长期资产（固定资产 / 无形资产 / 投资性房地产）

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 固定资产-折旧 | 同类固定资产损耗差异明显仍按相同年限折旧；更新改造延长寿命后仍按原寿命折旧 | 按实际使用情况分别确定折旧年限；资本化后续支出转入在建工程→转固后按重新确定的使用寿命/残值/方法折旧 |
| 固定资产-弃置费用 | 弃置义务减少（复垦成本降/时点延后/折现率升）直接全额冲减营业成本 | 以固定资产账面价值为限扣减成本，超出部分才计入当期损益 |
| 无形资产-研发支出 | 非研发人员薪酬、施工材料、共用设备折旧全额计入研发支出 | 仅归集与研发直接相关支出；共用设备按实际使用分摊 |
| 无形资产-资本化时点 | 不区分研究/开发阶段，全部费用化或全部资本化 | 研究阶段费用化；开发阶段逐项判断五条件 |
| 无形资产-外购在研 | 直接认定已进入开发阶段并资本化购买价款+后续支出 | 结合项目实际阶段、技术可行性、预期经济利益综合判断 |
| 无形资产-数据资源 | 无证据证明经济利益流入仍确认；硬件设备成本计入数据资源 | 需证明经济利益很可能流入；硬件确认固定资产 |
| 投资性房地产-自用/出租 | 整体办公楼（部分自用）全作投资性房地产 | 自用/出租能单独计量出售则分别确认；否则整体按固定资产 |

## 二、非金融资产减值（存货 / 固定资产 / 长投 / 商誉）

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 存货-跌价准备 | 未扣销售费用；按库龄固定比例计提；呆滞残次存货用良品售价 | 可变现净值=售价-完工成本-销售费用-税费；区分呆滞/残损单独测算 |
| 存货-跌价转回 | 售价持续低迷仍转回跌价准备 | 减记因素消失才能转回，且在原计提金额内 |
| 固定资产-减值 | 减值迹象明显不测试；跨年延后/拆分项目选择性计提 | 有减值迹象即测试；全部有迹象资产都要测 |
| 长期股权投资-减值 | 子公司连年巨亏不减值测试 | 账面价值>享有净资产份额等迹象出现即测试 |
| 资产减值损失 | 无形资产减值后转回 | 资产减值损失一经确认不得转回 |
| 资产组认定 | 配套在建工程以"未完工"为由排除出资产组 | 以能否独立产生现金流为核心，协同资产纳入同一资产组 |
| 商誉-资产组 | 子公司临时停工即剔除资产组组合 | 除非报告结构改变（重组），否则不得随意变更资产组 |
| 商誉-口径一致 | 账面价值口径与可收回金额口径不一致（用股权交易价格替代） | 可收回金额=公允减处置费用净额 与 未来现金流现值 孰高 |
| 商誉-关键假设 | 折现率压低/增长率虚高/市盈率随意上调 | 折现率反映特定风险；增长率有依据；参数客观公允 |

## 三、职工薪酬

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 应付职工薪酬-范围 | 住房补助直接计管理费用；已故遗属赡养费计营业外支出；外包人员薪酬误作职工薪酬 | 异地住房补助、遗属赡养费均属职工薪酬；外包服务不受企业计划控制的不算 |
| 应付职工薪酬-时点 | 销售提成在实际回款时才计提 | 完成业绩、义务可可靠估计时即确认（比照短期利润分享计划） |
| 职工薪酬-类型 | 累积未使用带薪年假折算补偿误作辞退福利 | 带薪年假折算属短期薪酬（累积带薪缺勤），辞退福利仅指解除劳动关系补偿 |

## 四、股份支付

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 授予日 | 用董事会审议日；方案未定价/未定对象即用股东会日 | 授予日=协议条款条件达成一致+股东会批准 |
| 自愿退出 | 视作未满足可行权条件冲回费用 | 属于取消，作加速行权，剩余等待期金额立即计入当期损益 |
| 公允价值 | 用往期估值；用大盘指数波动率替代个股波动率 | 按授予日公允价值；波动率优先参考自身股价历史波动率 |

## 五、金融工具

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 金融资产分类 | 含转股权优先股分类为FVOCI；双目标债券分类为摊余成本 | 按合同现金流特征+业务模式分类；不满足SPPI的归FVTPL |
| 金融工具计量 | 摊余成本负债交易费计当期损益；非上市股权直接按成本计量 | 交易费计入初始确认金额；非上市股权基于所有可得信息估值 |
| 已发生信用减值 | 未用经信用调整实际利率算利息收入 | 用经信用调整的实际利率 |
| ECL-范围 | 租赁应收款、合同资产、表外贷款承诺/财务担保未计提 | 全部纳入ECL减值范围 |
| ECL-方法 | 子公司直接套用母公司损失率；随意调整损失率 | 结合自身客户类型/行业/历史回款测算 |
| 信用风险评估 | 人为调整五级分类；已破产仍仅以未逾期认定未显著增加 | 考虑所有合理有依据信息，不依赖逾期信息 |
| 合并层面股债区分 | 结构化主体份额、可回售工具直接列权益 | 合并报表按集团整体承担义务判断，通常分类金融负债 |

## 六、长期股权投资 / 企业合并 / 合并报表

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 权益法长投 | 被投资方宣告股利确认投资收益 | 确认应收股利同时冲减长投账面价值 |
| 超额亏损 | 长投账面价值冲成负数未披露 | 以长投+其他长期权益减记至零为限，负余额转预计负债 |
| 合并范围 | 受托表决权叠加过半即并表；穿透持股平台55%即并表 | 按控制三要素（权力/可变回报/影响回报能力）实质判断 |
| 同一控制合并 | 直接采用被合并方自身账面价值 | 以最终控制方合并报表层面账面价值（含商誉）为基础 |
| 内部交易抵销 | 识别不全、顺逆流不分、期末存货未抵销未实现损益 | 全口径抵销；顺流全额归母公司、逆流按比例分摊少数股东 |
| 购买日 | 股权质押未过户仅凭管理层交接认定控制权转移 | 实质重于形式，财产权交接+付款过半+实际控制 |
| 是否构成业务 | 收购资产载体（无运营投入）按企业合并 | 无投入/加工/产出能力的组合不构成业务，不确认商誉 |

## 七、收入

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 时段法/时点法 | 定制软件仅因周期长按时段法 | 三条时段法条件（消耗/控制/不可替代+有权收款）逐条判断 |
| 可变对价 | 质量折扣退款全额确认收入、退款计营业外支出 | 合理估计可变对价，按极可能不重大转回金额确认收入 |
| 履约义务 | 系统集成硬件签收即确认收入 | 硬件+软件+调试高度关联=一项履约义务，验收合格才确认 |
| 运输费用 | 控制权转移前运输费计销售费用 | 不构成单项履约义务的运输费作合同履约成本计营业成本 |
| 总额/净额 | 代理/代建/受托加工无商品控制权仍用总额法 | 以转让前是否控制商品为核心判断，代理人按净额 |
| 合同负债 | 沿用"预收账款"科目；推迟结转收入 | 用"合同负债"科目，履行履约义务时结转收入 |
| 额外购买选择权 | 实物返利重大权利未分摊 | 作为单项履约义务分摊交易价格 |

## 八、租赁

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 使用权资产确认 | 合租/租赁选择权不明不确认使用权资产 | 符合租赁定义且非短期/低价值即确认 |
| 折现率 | 直接套贷款基准利率/集团统一利率 | 用租赁内含利率，无法确定用增量借款利率 |
| 初始直接费用 | 佣金印花税一次性计当期损益 | 纳入使用权资产初始计量 |
| 折旧期间 | 用资产剩余使用寿命折旧 | 租赁期与剩余使用寿命孰短 |
| 售后租回 | 转让价款与账面价值差额全额计当期损益 | 仅就转让至出租人权利确认损益，租回部分确认使用权资产 |

## 九、其他（预计负债 / 所得税 / 前期差错 / 列报披露）

| 科目 | 典型错误 | 正确做法 |
|------|---------|---------|
| 预计负债 | 保证类质保、采矿弃置义务不确认 | 现时义务+很可能流出+可计量即确认预计负债 |
| 递延所得税资产 | 亏损仍全额确认；可抵扣亏损不确认；不再满足条件不减记 | 以未来很可能取得应纳税所得额为限确认，期末复核 |
| 股份支付-所得税 | 税法扣除额超会计成本部分计入当期所得税费用 | 超出部分所得税影响直接计入所有者权益 |
| 前期差错 | 固定资产盘盈计当期损益 | 重要前期差错追溯重述，通过以前年度损益调整 |
| 列报披露 | 公允价值/减值参数仅定性披露；使用权资产列无形资产；关联方借款列经营现金流 | 披露量化参数；正确列示；筹资性借款列筹资活动现金流 |

1. **2026 年报审计**：按上表逐科目对照，识别客户是否存在同类问题
