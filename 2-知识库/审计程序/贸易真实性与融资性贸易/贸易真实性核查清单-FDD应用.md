# 贸易真实性核查清单（FDD 应用 — 长兴新农都粮食/肉类/蛋类贸易）

> 综合依据：[[上海大宗商品贸易真实性规则指引(试行)-
解读]]（四流合一+三有三无）、[[北京注协-融资性贸易空转走单舞弊风险识别与审计应对]]（风险迹象+审计程序）、[[上海二中院-涉融资性贸易案件审判白皮书2020-2024]]（穿透式审查四维度）。
> 适用：长兴新农都单体贸易合同（粮食/肉类/蛋类）核查，CAS 14 总额/净额法判断，重点复核合同实质（货物流、风险、定价）而非仅看合同主体形式。

## 一、四流合一核验（核心证据链）

| 流 | 核查要点（穿透而非形式） | 红旗 |
|----|------------------------|------|
| 合同流 | 标的、数量、质量、价格、**交付/货权转移时点**、**风险承担**、结算方式、违约责任是否明确；上下游是否经最终客户确认后才由新农都名义签订；是否背靠背同时签署 | 条款高度相似、同日签多份、风险全由下游承担 |
| 货权流（最关键） | 仓单/提单真实完整；仓储方确认的货权变更记录、出入库/运输/交付单证；新农都是否实质控制货物（非仅持凭证） | 出库单发货人=收货人、物流信息空白；货物由关联方实质控制；"走单不走货" |
| 资金流 | 对公结算；**收款方/付款方与合同签订方/开票方/受票方"四一致"**；资金流向/规模/周期与货权转移匹配；追踪重大交易资金是否回流/第三方回款 | 对下游全额预付+对上游长账期（变相垫资）；短时间频繁进出形成闭环 |
| 发票流 | 开票时限、品名/规格/数量/金额与合同、货权凭证一致；增值税票真伪查询 | 发票品类/数量与货物流不符；无合理商业目的对开/环开 |
| 账税流 | 收入成本确认及时准确；按规定申报缴纳 | 毛利异常（平买平卖/高买低卖/固定价差=利息） |

## 二、商业合理性（上海指引第五条 / 二中院"意思表示虚假性"）

- [ ] 是否有真实供需关系，价格是否符合市场规律（非平买平卖/固定价差/由操盘方统一定价）；
- [ ] 新农都是否有自主定价权、承担价格波动风险（非纯通道过票）；
- [ ] 交易前期是否就货物数量/质量等关键要素真实磋商（聊天记录/邮件佐证）；
- [ ] 上下游是否为新农都真实客户/供应商，而非专为交易设立（首次交易时间与成立时间重合需警惕）；
- [ ] 新农都的业务人员/场地/费用是否与贸易规模匹配（非"小团队、大营收"）。

## 三、主体与关系排查（北京注协 / 二中院"交易主体异常性"）

- [ ] 上下游工商登记（国家企业信用/天眼查）：投资人、人员、地址、电话、邮箱是否重合；是否存在同一实控人/母子公司/兄弟公司/利益共同体；
- [ ] 上下游是否原本就有密切业务往来（战略伙伴、特约经销商），经后续安排资金流入；
- [ ] 下游是否为最终使用方；上下游是否为不知名民企/贸易类公司；
- [ ] 是否存在"人为增设无效中间环节"——新农都作为中间方分别与已有长期合作关系的上下游新签合同。

## 四、总额法 vs 净额法判断（CAS 14，实质性重于形式）

- [ ] 新农都是**主要责任人**（自己买卖赚差价→总额法）还是**代理人**（提供代理服务赚佣金→净额法）？
- [ ] 是否有权自主决定交易价格、规格、数量等核心要素；
- [ ] 是否承担存货风险（价格波动、毁损、滞销）、信用风险、退换货责任；
- [ ] 是否实质控制货物（实物流转/货权转移，非仅单据）；
- [ ] 定价是否为固定利差（利息性质）→ 提示融资性贸易风险。

> 长兴新农都粮食/肉类/蛋类贸易：重点看合同实质——货物流向、风险承担、定价权，避免只看合同主体形式误判总额/净额。

## 五、特殊风险红线（一票否决/立即上报）

- ⛔ 虚构贸易背景、伪造合同/仓单/提单 → 刑事（合同诈骗、虚开专票）；
- ⛔ "三无"红线：无合理商业价值的循环套利 / 资金短期闭环回流（名为贸易实为借贷）/ 人为增设无效中间环节；
- ⛔ 无真实货权控制的空转、走单；
- ⛔ 国企（若涉及）作为资金提供方/通道方参与闭环交易 → 744号文"十不准"全面禁止，合同效力司法趋于否定。

## 六、审计程序落地（对应北京注协应对程序）

1. **穿行测试**：抽取重大贸易合同，从合同→收发货→物流→资金→发票→入账全链条追查。
2. **访谈/实地**：主要供应商、客户访谈；第三方仓库实地查看+函证；承运方访谈。
3. **分析程序**：毛利率同行业/同客户/同商品比对；运输费/仓储费与交易规模配比；期后冲回/期前售出本期购回。
4. **函证全程控制**：关注回函地址/联系人是否同一链条（潜在关联）。
5. **资金流向追踪**：重大交易追踪至最终收款方，警惕对销售客户付款/第三方回款。
6. **海关/电子口岸**（进出口）：核对进出口数据与账面，测试出口退税钩稽。
7. **发现后**：要求管理层自查识别所有类似交易→按国资委要求上报→评价 CAS 处理（总额/净额）→考虑审计意见影响。
