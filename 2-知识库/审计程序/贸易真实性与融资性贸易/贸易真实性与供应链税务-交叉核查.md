# 贸易真实性与供应链税务（交叉核查）

> 本笔记补 [[贸易真实性核查清单-FDD应用]] 等司法 / 空转视角所缺的"供应链税务传导"维度：四流一致既是贸易真实性证据，也是发票合规与下游风险隔离的硬门槛。

## 一、四流合一作为税务合规硬门槛

- 2026-04 国家税务总局《纳税人合规开具发票正负面清单》列 **28 种违规开票情形**：融资性贸易、虚假贸易、四流不一致、无合理商业目的对开 / 环开、空转走单等。
- 银行信贷同步升级：大宗商品贸易融资从"看发票流"转向严查"货物流"（合同 / 资金 / 发票 / 货物流四流一致成硬门槛）。
- 四流：合同流、资金流、货物流(或服务流)、发票流。缺货物流的"开票经济"经不起税收与信贷追问。

## 二、7 类一碰即违规的贸易（税务稽查直接定性虚开）

1. **融资性贸易**：固定收益、不担货价风险、上下游由用款方指定、合同现"垫资本金利息"。
2. **空转走单**：货不经手、上下游直接交割、只有合同发票资金无真实物流。
3. **无商业实质循环贸易**：A→B→C→A 闭环、初始卖方 = 最终买方。
4. **伪造单据虚构贸易背景**：伪造运输 / 仓储 / 收发货单、硬塞中间通道。
5. **三流不齐备**：货物流 / 票据流 / 资金流对不上、无第三方外部单据、不实地盘点。
6. **代理业务按总额法确认收入**：无控制权却按全额计收 → 财务造假。
7. **无货开票 / 票货不符**：行政虚开无条件成立。

## 四、长兴新农都应用

- 粮食 / 肉类 / 蛋类贸易合同：先过"四流一致 + 总额净额"再谈计税；农产品收购发票 / 销售发票链条是进项与成本基础，上游农户 / 合作社异常将沿链传导至本公司进项转出风险 → **供应商准入尽调前置**。
