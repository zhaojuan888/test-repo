# 汽车制造业 — 企业财务规范（审计镜像）

> 视角：作为汽车制造企业的财务 / 会计主管，应如何**事前**把账做对、把内控建好，使审计风险点"不发生"。下表将 `[[汽车制造业-会计核算与审计风险]]` 的 9 个审计风险点翻转为企业应建立的规范。

## 双向对照表（审计风险 → 企业规范）

| # | 审计关注点（现有笔记） | 企业应建立的财务规范 |
|---|------------------------|----------------------|
| 1 | 研发支出资本化滥用（研究阶段即资本化 / 失败不转销） | 会计政策手册明确**研究 / 开发阶段分界 + 五条件判定标准**；SOP 节点（量产启动）证据留痕；建立失败 / 暂缓项目**及时转销 + 减值测试**机制；资本化借款费用期间规则书面化 |
| 2 | 收入三模式时点 / 总额净额错判 | 销售政策固化**经销 / 代理 / 直营**控制权转移约定；明确运输是否单项履约义务；主要责任人 / 代理人判定标准写入合同模板与收入确认 SOP |
| 3 | 可变对价（返利 / 退货）估计不足 | 建立**返利 / 退货率估计模型**（历史数据驱动）+ 期末重估机制；预计负债计提与调整须经复核审批 |
| 4 | 应付客户对价未冲减收入 | 制定市场补贴 / 广告 / 形象店费用**性质判定清单**（是否取得可明确区分商品）；冲减收入 SOP 与凭证附件要求 |
| 5 | 质保预计负债计提 / 转回不当 | 单车预提标准（历史概率 × 金额）书面化；流动 / 非流动列报规则；到期余额**转回 / 补提**复核流程 |
| 6 | 积分 / 服务类质保重大权利未分摊 | 交易价格分摊政策 + 合同负债**递延 / 转回**机制；延保 / 积分作为单项履约义务的判定树 |
| 7 | 新业务履约义务拆分 / 时段时点误判 | 车联网 / 辅助驾驶**软硬区分判定标准** + 是否依赖服务器运行的时段 / 时点法判定树，嵌入收入确认手册 |
| 8 | 供应商返利跨期 / 误计 | 返利条款**台账管理** + 实现销售状态判定；明确计入存货成本 / 主营业务成本的规则与凭证链 |
| 9 | 存货减值不充分 | 建立**库龄分析 + NRV 测算模型** + 月度 / 季度复核机制；跌价准备计提审批与改款换代车型专项排查 |

## 企业应沉淀的"制度化产物"（落地交付物）
1. **会计政策手册（汽车制造专版）**：覆盖上述 #1/#2/#4/#5/#6/#7 的政策选择与判定标准。
2. **关键估计模型**：返利 / 退货率（#3）、质保预提（#5）、存货 NRV（#9）——均有公式、历史数据来源、期末复核痕迹。
3. **销售合同模板库**：三模式条款 + 运输 / 返利 / 质保的表述范式（#2/#3/#4/#6）。
4. **供应商返利管理台账**：条款—实现状态—计入科目闭环（#8）。
