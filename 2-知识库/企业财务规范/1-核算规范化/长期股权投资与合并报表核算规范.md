# 长期股权投资与合并报表 — 企业核算规范

> **视角说明**：本笔记从**企业财务自身**角度，回答"我作为企业财务应如何把长投与合并报表做对"，与审计笔记（"合并范围错报 / 抵消不完整"等风险）互为镜像。

## 一、为什么要规范（动因）

- **合规动因**：CAS 2 / 33 / 20 对分类、计量、合并抵消有明确要求，合并范围与抵消是报表列报的硬性规定。
- **风险动因**：长投与合并是重大错报高发区——合并范围错报（应纳入未纳入 / 不应纳入误纳入）、权益法 / 成本法错用、内部交易抵消不完整、关联交易未抵销、丧失控制权未转公允价值。
- **效率动因**：建立"股权投资台账 + 合并范围清单 + 内部交易对账"三件套，月结年结可复用，减少返工。

## 二、核算规范（编制者角度的准则落地）

### 2.1 长期股权投资分类（CAS 2）

| 情形 | 核算方法 | 判断标准 |
|------|----------|----------|
| 控制（子公司） | 成本法 | 控制三要素：权力 + 可变回报 + 权力影响回报（CAS 33） |
| 共同控制（合营安排） | 权益法 | 仅当合营方组合集体控制且唯一可行使 |
| 重大影响（联营） | 权益法 | 一般 20%–50% 股权 / 董事会席位等 |
| 无控制 / 共同控制 / 重大影响，且公允价值不可靠 | 金融资产 | 按 CAS 22 以公允价值计量（FVTPL / FVTOCI） |

- **控制三要素**须书面记录判断依据（股东会 / 董事会权力、派出董事、关键管理人员任免、关联交易依赖度等），作为合并范围清单的支撑。
- **结构化主体**（基金、SPV、信托）是否纳入合并，须单独评估控制（表决权之外的影响力、可变回报敞口）。

### 2.2 合并报表关键处理（CAS 33）

- 统一母子公司会计政策与会计期间；不一致须调整。
- 抵消：长期股权投资与子公司所有者权益、内部债权债务、内部交易（存货 / 固定资产 / 无形资产未实现损益）。
- **顺流 / 逆流交易**：未实现损益按持股比例抵销；逆流交易需考虑少数股东权益（全额抵销损益后，少数股东承担部分调整少数股东权益）。计算公式、三向配对与抵销台账字段见 [[内部交易抵销-计算与统计方法]]。
- 特殊交易：购买少数股权（权益性交易，差额调资本公积）、不丧失控制权处置（差额调资本公积）、**丧失控制权**（剩余股权转公允价值，差额确认投资收益，原其他综合收益 / 权益变动结转）。

### 2.3 企业应建立的"制度化产物"

1. **股权投资台账**：被投资单位、持股比例、核算方法、表决权、是否合并、减值迹象。
2. **合并范围清单**：年度复核、记录控制判断依据，经财务负责人审批。
3. **内部交易对账机制**：母子公司按月对账，未实现损益自动计算底稿。

## 三、内控与流程标准化

- 股权投资取得 / 处置须经投资委员会 / 董事会审批（权限见 [[内控框架与权限矩阵]]）。
- 合并报表编制责任到人：合并抵消底稿、内部交易对账底稿留痕。
- 会计政策变更（如核算方法转换）走 [[会计政策手册模板]] 的变更流程。

## 四、与审计关注点的双向对照

| 审计关注点 | 企业应建立的规范 |
|------------|------------------|
| 合并范围错报（结构化主体漏并 / 误并） | 控制三要素书面判断 + 年度复核清单 |
| 权益法 / 成本法错用 | 分类标准写入会计政策手册，初始及年度复核 |
| 内部交易抵消不完整（未实现损益遗漏） | 内部交易按月对账 + 自动抵销底稿 |
| 丧失控制权未转公允价值 / 其他综合收益未结转 | 特殊交易 SOP + 处置节点复核 |

## 五、落地清单 / 自查

- [ ] 合并范围清单是否每年复核并有控制判断依据
- [ ] 股权投资台账是否覆盖全部被投资单位及核算方法
- [ ] 内部交易对账是否在结账前完成
- [ ] 特殊交易（购买 / 处置少数股权、丧失控制权）是否有 SOP
