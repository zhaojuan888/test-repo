# 租赁 — 企业核算规范

> **视角说明**：本笔记从**承租人 / 出租人**双角度，回答"如何把租赁识别、计量、列报做对"，与审计笔记（"隐性租赁漏识别 / 折现率错误 / 售后租回"等风险）互为镜像。售后包租、返租在长兴新农都 FDD 中为高频场景。

## 一、为什么要规范（动因）

- **合规动因**：CAS 21（2018 修订）对承租人采用单一模型（使用权资产 + 租赁负债），分类与计量要求明确。
- **风险动因**：租赁识别不完整（服务合同伪装租赁 / 隐性租赁）、折现率与租赁期判断错误、使用权资产折旧与租赁负债利息错配、售后租回处理不当。
- **效率动因**：建立"租赁合同台账 + 折现率政策"，月结自动计提，减少手工差错。

## 二、核算规范（编制者角度的准则落地）

### 2.1 租赁识别与租赁期

- **租赁识别**：客户在规定期间控制已识别资产的使用（获得几乎全部经济利益 + 主导使用），且该资产供应方的替换权不成立。隐性租赁（含服务成分合同中的租赁部分）须分拆。
- **租赁期**：不可撤销期间 + 合理确定将行使的续租选择权期间 − 合理确定将放弃的终止选择权期间。
- **折现率**：承租人优先使用租赁内含利率；无法取得时采用**增量借款利率（IBOR）**，须书面确定政策（同币种、相似抵押、相似期间）。

### 2.2 承租人会计处理（CAS 21）

- 除短期租赁（≤12 个月）和低价值资产租赁（单项资产全新价值较低）可豁免外，一律确认**使用权资产**与**租赁负债**。
- 租赁负债：按租赁付款额现值初始计量，后续按实际利率法计提利息 + 支付租金减少账面。
- 使用权资产：初始含租赁负债现值 + 初始直接费用 + 复原义务现值；后续按合理方法折旧（一般直线法，与租赁期一致）。
- **租赁变更**：部分终止或范围变更，按修订后折现重新计量；不取决于指数 / 比率的可变租赁付款额不计入租赁负债。

### 2.3 出租人与售后租回

- 出租人分**经营租赁 / 融资租赁**（风险报酬几乎全部转移）。
- **售后租回**：按 CAS 14 收入准则判断控制权是否转移；若形成销售，按公允价值计量并确认资产转让损益，租赁部分按承租 / 出租处理；若未形成销售（如存在回购 / 售后代管），不终止确认资产，收款作为金融负债。

## 三、内控与流程标准化

- 租赁合同须经法务 + 财务双审（识别租赁成分、确定租赁期与折现率）。
- 建立**租赁合同台账**：起止、付款额、折现率、使用权资产原值 / 累计折旧、租赁负债余额。
- 月结自动计提折旧与利息（衔接 [[月结年结清单]]）。

## 四、与审计关注点的双向对照

| 审计关注点 | 企业应建立的规范 |
|------------|------------------|
| 隐性租赁 / 服务合同漏识别 | 合同双审清单（识别租赁成分）+ 台账 |
| 折现率 / 租赁期判断错误 | IBR 政策书面化 + 续租 / 终止选择权评估记录 |
| 使用权资产折旧与租赁负债利息错配 | 月结自动计提 SOP |
| 售后租回错误分类（销售 vs 融资） | 控制权转移判定树 + 法务复核 |

## 五、落地清单 / 自查

- [ ] 租赁合同台账是否覆盖全部租入 / 租出资产
- [ ] IBR 折现率政策是否书面化并可复核
- [ ] 售后租回是否按控制权转移正确分类
- [ ] 短期 / 低价值豁免是否恰当、有无滥用
