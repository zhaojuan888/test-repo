# 内部交易抵销 — 计算与统计方法

> **一句话**：抵销不是"收入减成本"一步完事，而是**两层**——先抵内部交易本身，再抵资产中残留的未实现损益。第二层漏掉，就是 5,371 万量级的利润虚增。

## 一、先分清两层抵销（最高频的混淆）

| 层次 | 抵什么 | 判断依据 | 漏掉的后果 |
|------|--------|----------|-----------|
| **第一层：内部交易本身** | 内部营业收入 ↔ 营业成本；内部应收 ↔ 应付；内部投资收益 ↔ 利息费用 | 交易发生在合并范围内主体之间 | 收入成本双向虚增（利润总额不受影响） |
| **第二层：未实现内部销售损益** | 期末资产（存货/固定资产/无形资产/在建工程）中**仍含的卖方毛利** | 该批资产**期末是否已对集团外实现** | **资产虚增 + 成本少计 + 利润总额虚增**（本案 5,371.07 万即此类） |

- 第一层是"对账"问题，第二层是"判断"问题。**只做第一层是实务最高频的漏抵类型**，尤其在存货周转慢、内部毛利率高的行业（软件/系统集成、定制设备、工程项目、贸易）。
- 注意区分对象：**母子公司（合并抵销，全额）** vs **联营合营（权益法，按持股比例抵销归属于投资方的部分）**，后者依据 CAS 2 及财政部会计司问答，顺流调投资收益、逆流调长投账面价值；**属于所转让资产减值损失的未实现损失不予抵销**。

## 二、未实现内部销售损益怎么算

**核心公式**

```
未实现内部销售损益 = 内部毛利率 × 期末存货中的内部采购余额
内部毛利率 =（内部不含税售价 − 卖方账面成本）÷ 内部不含税售价
期末内部存货 = 期初内部存货 + 本期内部采购 − 本期对外销售（结转）
```

**抵销分录（当期）** — 以售价 P、卖方成本 C、期末未对外销售比例 r 为例：

```
借：营业收入            P
  贷：营业成本          P − (P−C)×r
  贷：存货              (P−C)×r
```

> 示例（P=1,000、C=800、r=60%）：未实现损益 = 200×60% = 120 → 借 营业收入 1,000；贷 营业成本 880；贷 存货 120。

**顺流 / 逆流的分摊（CAS 33 第 36 条）**

| 方向 | 未实现损益原在谁的利润表 | 合并层如何分摊 |
|------|--------------------------|----------------|
| 顺流（母 → 子） | 母公司 | **全额**冲减"归属于母公司所有者的净利润" |
| 逆流（子 → 母） | 子公司 | 按母公司持股比例，在"归母净利润"与"**少数股东损益**"之间**分摊** |

**两种取数方法的选择**

| 方法 | 适用 | 要点 |
|------|------|------|
| 逐笔（SKU/批号）法 | 内部存货可追溯到卖方单据、品种少、金额大 | 最准，可直接支撑抵销底稿 |
| 加权毛利率法 | 内部存货无法逐笔追溯、SKU 多、交易高频 | 用期内内部销售加权平均毛利率；须检验毛利率稳定性 |

## 三、怎么准确统计：三向配对 + 差异池清零 + 抵销台账

### 3.1 三向配对

1. **交易配对**：内部销售收入 ↔ 买方营业成本（同口径、同期间）
2. **存货配对**：期末存货逐项标注**来源（内部采购 / 外部采购）**，内部采购部分回追卖方批次与成本
3. **资金配对**：内部应收 ↔ 应付、票据、预收 ↔ 预付、内部资金拆借与利息

### 3.2 差异池——差异不会消失，只能定位

| 差异类型 | 表现 | 处理 |
|----------|------|------|
| 在途 / 未达账 | 卖方已确认收入、买方未入库 | 按合同与物流凭证判断归属期，调整或列"在途物资" |
| 含税 / 不含税口径 | 一方含税、一方不含税 | 统一到不含税口径后重算 |
| 代垫运费、费用 | 双方计入不同科目 | 归集到对应科目后再配对 |
| 退货未同步 | 一方冲红、一方未冲 | 按退货单日期对齐 |
| 跨期确认 | 截止日差异 | 做截止测试，按控制权转移时点归属 |
| 年末返利 / 定价修正 | 只在年末调价 | 双方追溯调整 |

### 3.3 内部交易抵销台账（建议字段）

| 字段 | 说明 |
|------|------|
| 交易双方 | 卖方 / 买方（须均在合并范围内） |
| 交易类型 | 存货 / 固定资产 / 无形资产 / 服务 / 资金 |
| 单据号 | 发票号 + 出库单/验收单号（**配对主键**） |
| 不含税金额 | 统一不含税口径 |
| 卖方账面成本 | 该批货物的集团原始成本 |
| 内部毛利率 | (不含税售价 − 卖方成本) ÷ 不含税售价 |
| 期末内部存货余额 | 买方期末存货中来源于内部采购的部分 |
| 未实现损益 | 内部毛利率 × 期末内部存货余额 |
| 本期实现（转回） | 期初内部存货本期对外销售部分对应的毛利 |
| 抵销科目/金额 | 对应合并抵销分录行 |
| 备注 | 在途、退货、代垫费用等例外事项 |

> 工具化：数据量大时用**单据号做键**做双向匹配（Excel 用 XLOOKUP/SUMIFS 双向核对，或用 Python `merge(indicator=True)` 一次跑出 left_only / right_only / both 三态）。关键是**让"对不上的"显式暴露**，而不是取一个总额去乘毛利率。

## 四、跨期连续编制（最容易出错的地方）

- **本期实现转回**：上年期末内部存货在本年对外销售 → 上年抵销的未实现损益本年"实现"：

```
借：未分配利润—年初        上年未实现损益
  贷：营业成本             上年未实现损益
```

- **连续编制原则**：合并抵销分录每期重新编制，**上期抵销的影响必须在本期先冲回**。常见错误是"只抵当年新增、不转回上年"，会造成跨期累计偏差。
- **存货跌价准备也要抵销**：内部销售形成的存货若已计提跌价，站在集团角度应按**集团成本**重新计算可变现净值，集团成本低于可变现净值的部分不应有跌价。
- **所得税影响**：抵销未实现损益产生可抵扣暂时性差异，应确认递延所得税资产（注意与卖方已确认的所得税费用对应）。

## 五、固定资产 / 无形资产的内部交易（分期实现）

未实现损益通过**多提的折旧/摊销**分期实现，抵销分录跨期持续：

```
借：营业收入                        售价
  贷：营业成本                      成本
  贷：固定资产—原价                 未实现损益
借：固定资产—累计折旧              未实现损益 ÷ 剩余年限 × 已过期间
  贷：管理费用/营业成本             同左
```

## 六、审计视角：五步落地

1. **看懂业务**：谁卖给谁、卖的是什么、期末**有没有卖给集团外**——这决定了抵销的层次。
2. **拆出风险**：存货/固定资产的存在与计价、营业成本的准确性、利润总额的准确性、截止（跨期转回）。
3. **找到异常**：见下方信号清单。
4. **形成证据**：内部购销明细双向核对表；期末存货**来源标注**（抽大额回溯卖方单据）；独立重算未实现损益并与企业测算表比对；抵销分录**重新计算**；跨期转回检查；少数股东分摊复核；存货监盘时关注内部采购件。
5. **做出判断**：未抵销额是否重大（对利润总额/净资产的影响比例）、是否要求调整、是否提内控与管理建议、抵销底稿是否留痕（呼应"职业判断错误"定性）。

**异常信号清单（露馅点）**

- 未实现内部损益占期末存货比例畸高（**本案 85.2%** 为极端样本）
- **集团合并毛利率 > 各单体毛利率的加权平均**
- 存货周转率骤降，而收入正常增长；内部存货余额逐期累积
- 内部购销双方对账差异长期挂账不清
- 内部应收应付与内部收入成本三者不勾稽
- 抵销分录只抵当年新增、不转回上年
- 期末存货**无法逐项标注来源**（无批号、无内部编码）→ 本身就是内控缺陷

## 七、企业侧制度化产物（与审计互为镜像）

1. **内部交易对账机制**：母子公司按月对账，差异当月清零，结账前完成。
2. **内部交易抵销台账**：按第三节字段建表，公式驱动，避免手工汇总。
3. **存货来源标注**：ERP 中内部采购单独编码/批次，使"期末内部存货"可直接取数。
4. **抵销底稿留痕**：抵销分录复核表 + 未实现损益测算表 + 抵销逻辑说明归档。
