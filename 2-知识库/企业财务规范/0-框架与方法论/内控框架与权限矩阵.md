# 内控框架与权限矩阵（企业据实填充）

> 定位：企业财务规范的「控制骨架」。覆盖《企业内控与税控流程手册》十一大循环，每个循环给出「风险—控制目标—关键控制—职责分离」四件套。
> 审计师拿它做穿行测试与关键控制测试的底稿锚点。

## 1. 内控五要素映射（COSO）
| 要素 | 企业落地要求 |
|---|---|
| 控制环境 | 治理结构、组织架构、人力资源政策、诚信价值观 |
| 风险评估 | 目标设定、风险识别（含舞弊风险）、风险应对 |
| 控制活动 | 下列十一循环的具体控制 + 不相容职责分离 |
| 信息与沟通 | 会计系统、反舞弊举报、信息披露 |
| 监督 | 内审职能、内控自评、缺陷整改闭环 |

## 2. 十一大业务循环控制矩阵（模板）

> 每个循环填：关键风险 / 控制目标 / 关键控制活动 / 不相容职责（必须分离项）。

| 循环 | 关键风险 | 控制目标 | 关键控制活动 | 不相容职责分离 |
|---|---|---|---|---|
| 资金 | 挪用、白条抵库、账户私设 | 资金安全、收支合规 | 授权审批、银行账户核对、定期盘点库存现金 | 出纳≠会计；保管≠对账 |
| 采购 | 虚假供应商、价格虚高、验收不严 | 采购真实、价格合理、入库准确 | 请购预算控制、招标/比价、验收单、三单匹配 | 请购≠审批≠验收≠付款 |
| 销售 | 虚增收入、信用失控、坏账 | 收入真实、回款及时 | 信用额度审批、合同评审、发货单、对账函证 | 开票≠收款≠记账 |
| 存货 | 盘亏、减值、挪用 | 账实相符、计价准确 | 出入库单据、定期盘点、跌价测试 | 保管≠记账；盘点独立于保管 |
| 成本 | 归集错配、少转多转成本 | 成本完整准确 | 工时/用料记录、费用分配标准、标准成本差异分析 | 生产≠核算 |
| 固定资产 | 账外资产、闲置、折旧错 | 资产完整、折旧准确 | 台账、标签、盘点、处置审批 | 使用≠保管≠记账 |
| 投资 | 盲目投资、利益输送 | 投资决策审慎、收益真实 | 可行性论证、授权、投后跟踪 | 决策≠执行≠记账 |
| 筹资 | 违规担保、资金链风险 | 筹资合规、成本可控 | 授信审批、用途监控、还款计划 | 融资决策≠资金支付 |
| 预算 | 预算形同虚设 | 资源合理配置 | 滚动预算、执行分析、考核挂钩 | 编制≠审批≠执行 |
| 人力资源 | 虚列人员、薪酬超标 | 薪酬真实、合规 | 花名册、工时、个税社保计提 | 录用≠薪酬核算≠发放 |
| 税务 | 漏税、虚开、滞纳金 | 税负合规、风险可控 | 发票真伪校验、税负测算、纳税申报复核 | 开票≠认证≠申报 |

## 3. 权限矩阵模板（按金额阈值分级）
| 事项 | 经办 | 部门负责人 | 财务负责人 | 总经理 | 董事会 |
|---|---|---|---|---|---|
| 单笔付款 ≤X 万 | ✓ | 审批 | 复核 | | |
| X–Y 万 | ✓ | ✓ | 审批 | 复核 | |
| ≥Y 万 / 重大投资 | ✓ | ✓ | ✓ | 提案 | 审批 |

> 审计要点：权限矩阵必须「书面化+系统固化」。仅有制度无系统控制的，穿行测试易失效。

## 4. 税控流程要点
- 增值税发票全生命周期管理（领购/开具/认证/红冲）
- 进销项匹配与税负率监控
- 税收优惠备案与留存备查资料
- 纳税申报复核（主表与附表、税务与会计差异台账）

## 反向对照（审计视角）
审计师做内控审计时，直接拿本矩阵做：「企业声称的控制」是否在操作系统/审批流中真实落地（而非纸面），是核心结论来源。
