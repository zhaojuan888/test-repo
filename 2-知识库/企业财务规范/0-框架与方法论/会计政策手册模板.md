# 会计政策手册模板（企业据实填充）

> 定位：企业财务规范的「总纲」。审计师拿它对照，能快速判断企业会计制度是否健全、政策选择是否一贯。
> 这是模板——表格里是「要写什么」，不是「标准答案」。企业按自身业态填，审计师按此检查完整性。

## 0. 手册基本信息

| 项目 | 内容 |
|---|---|
| 适用主体 | （单体 / 集团，合并范围说明） |
| 会计年度 | 公历 1.1–12.31 |
| 记账本位币 | 人民币；境外经营折算准则（CAS 19） |
| 生效日期 / 版本 | v1.0 / 202X-X-X |
| 审批 | 董事会 / 总办会决议文号 |

## 2. 主要会计估计（最易出审计差异）

| 估计项目 | 企业采用方法 | 关键参数 | 复核频率 | 审批 |
|---|---|---|---|---|
| 金融工具减值（预期信用损失） | 迁徙率/账龄组合 | 历史违约率、前瞻性 | 季度 | 财务负责人 |
| 存货跌价 | 可变现净值测算 | 售价、至完工成本、销售费用 | 年末+减值迹象 |
| 固定资产折旧 | 年限/残值/方法 | 各类资产政策表 | 年度复核 |
| 无形资产摊销 | 使用寿命判断 | 合同/法规/经济寿命 | 年度复核 |
| 收入履约进度（时段法） | 投入法/产出法 | 完工百分比依据 | 项目层面 |
| 预计负债 | 最佳估计数 | 退换货率、质保费率 | 期末 |

> 审计要点：估计方法一经确定不得随意变更；变更需附注说明并影响数。模板要求企业把「关键参数来源」写清，审计师重点验证参数是否拍脑袋。

## 3. 会计科目与核算体系
- 科目表层级（一级→明细），与准则报表项目映射
- 辅助核算设置（客户/供应商/项目/部门/存货批次）
- 凭证摘要规范、制单-审核-记账分离

## 4. 会计政策/估计变更流程
1. 提出（财务部）→ 2. 影响测算 → 3. 合规复核（准则+税务）→ 4. 审批（权限见 [[内控框架与权限矩阵]]）→ 5. 披露（附注+董事会说明）

## 5. 财务报告编制与披露
- 月报/季报/年报时间表（衔接 [[月结年结清单]]）
- 合并抵消底稿责任
- 关联交易披露完整性
- 附注政策与数字一致性（审计师勾稽重点）

## 反向对照（审计视角）
审计师查「会计政策手册」时，重点不是看它写没写，而是看：
- 实际账务处理是否与手册一致（抽凭核对）
- 估计参数是否有支撑文件（非口头）
- 变更是否走了 4. 的流程并有迹可溯
