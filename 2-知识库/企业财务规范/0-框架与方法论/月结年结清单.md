# 月结 / 年结清单（跨行业底盘）

> 定位：企业财务规范的「节奏控制器」。每月/每年必须跑完这张清单，才能出合规报表。
> 审计师用于：①验证截止性（收入成本是否计入正确期间）；②盘点监盘安排；③期后事项核查锚点。

## 1. 月度结账清单（每月末，建议 T+5 内完成）

### 1.1 账务核对（账账相符）
- [ ] 银行对账单 vs 银行存款日记账，编制余额调节表，未达账项跟踪
- [ ] 往来科目（应收/应付/其他）与明细账、客商对账函一致
- [ ] 存货/固定资产/无形资产明细账与总账一致
- [ ] 应交税费各税种计提 vs 申报表

### 1.2 计提与摊销
- [ ] 工资社保、折旧摊销、利息、租金按政策计提
- [ ] 金融资产减值（预期信用损失）按模型计提
- [ ] 存货跌价测试（有迹象时）

### 1.3 截止性
- [ ] 收入：发货/验收/开票跨期检查（前后各抽样）
- [ ] 成本：出入库单归属期间核对
- [ ] 费用：报销单据归属期间

### 1.4 报表与复核
- [ ] 试算平衡、报表勾稽（三表、附注）
- [ ] 财务负责人复核签字（权限见 [[内控框架与权限矩阵]]）

## 2. 年度结账清单（12.31，建议次年 4.30 前完成）

### 2.1 资产清查（账实相符）
- [ ] 全面存货盘点（审计师监盘）
- [ ] 固定资产/在建工程盘点
- [ ] 现金盘点、有价证券函证
- [ ] 往来款项函证（审计师控制函证过程）

### 2.2 估计与减值（年度必做）
- [ ] 金融资产、存货、长投、商誉、无形资产减值测试
- [ ] 预计负债（质保、诉讼、退换货）重估

### 2.3 税审与汇算清缴
- [ ] 所得税汇算（暂时性差异台账、递延所得税）
- [ ] 增值税及附加复核
- [ ] 税收优惠适用性与备案

### 2.4 合并与披露
- [ ] 合并范围复核（新设/处置/结构化主体）
- [ ] 关联交易抵销、披露完整性
- [ ] 附注政策与数字一致性
- [ ] 期后事项（资产负债表日至批准报出日）梳理

### 2.5 归档
- [ ] 电子账套备份、纸制凭证装订
- [ ] 审计调整分录台账留存

## 3. 审计师衔接提示
- 月结质量差的企业，年审务必扩大截止性抽样与盘点范围
- 年结清单 2.1–2.4 基本就是年审「关键审计程序」的企业侧镜像
- 企业可据此提前准备审计资料（参见 IMA 各版《年报审计资料清单》）
