# 研发相关 · IPO 会计科目口径与审核关注

> 整理自 IMA「IPO知识库」→ 会计科目口径 → 研发相关。聚焦研发费用归集、资本化与"三口径"差异；2026-08-23 补充加计扣除政策（财务侧归集 + 审计侧核查）。

## 一、准则核心口径

- **科目设置**："研发支出"下设"费用化支出""资本化支出"；费用化期末转入管理费用（研发费用），资本化达到预定用途转无形资产。
- **归集范围**：人员人工、直接投入（材料/燃料/动力）、折旧与长期待摊摊销、设计费、装备调试费、无形资产摊销、其他费用（限额）。
- **资本化条件**（开发阶段五条件）：技术可行+意图开发+有能力使用/出售+有用性+支出可靠计量；研究阶段全部费用化。
- **形成无形资产**：按成本计量，使用寿命有限的无形资产系统摊销（一般不低于 10 年或合同/受益期）。
- **委托研发（会计口径）**：委托外部机构/个人研发，按实际发生的研发支出全额计入；成果归属约定清晰。

## 二、三口径差异（重点）

> 研发费用有三个独立口径：**会计口径（CAS 6）**、**高企认定口径（国科发火〔2016〕195号）**、**加计扣除口径（财税〔2015〕119号等）**。三者目的不同、归集规则不同，**不得互相替代**；IPO 问询必查"研发投入与加计扣除差异"并解释合理性。

| 维度 | 会计口径（CAS 6） | 高企认定口径 | 加计扣除口径 |
|------|------------------|-------------|-------------|
| **目的** | 按经济实质准确核算，反映财务状况与经营成果 | 判断研发投入强度是否达高企认定标准 | 细化可加计扣除范围，引导核心研发 |
| **归集方式** | 按准则实质判断（研究/开发/存货/成本分别处理） | 8 类正面归集（人员人工、直接投入、折旧与长摊、无形资产摊销、设计、装备调试与试验、委托外部研发、其他费用） | **正列举**六大类（见下节），未列举不得加计 |
| **人员费用** | 按实际投入合理分摊 | 科技人员工资薪金+五险一金+外聘科技人员劳务费；累计实际工作 183 天以上 | 直接从事研发人员工资薪金+五险一金+外聘研发人员劳务费；**按实际工时占比分配，未分配不得加计** |
| **共用设备/人员** | 按合理标准分摊 | 按实际使用情况分配 | **必须按实际工时占比**分配 |
| **委托境内研发** | 全额计入研发支出 | 按实际发生额 **80%** 计入 | 按实际发生额 **80%** 计入（受托方不得加计） |
| **委托境外研发** | 全额计入 | 按实际发生额 80% 计入 | **80% 且 ≤ 境内符合条件研发费用的 2/3** |
| **其他费用限额** | 据实归集 | 一般 ≤ 研发费用总额的 **20%** | ≤ 可加计扣除研发费用总额的 **10%**（2021年第28号公告起全部项目统一计算） |
| **资本化支出** | 满足五条件资本化，形成无形资产摊销 | 资本化支出**一般不计入**研发费用占比 | 形成无形资产的按成本 **200%** 摊销加计（研究阶段费用化按 100% 加计） |
| **负面清单** | 无 | 支持领域（高新技术领域目录） | **7 类活动 + 6 类行业**不得加计（见下节） |
| **产出/废料处理** | 研发产出的产品或副产品对外销售前按存货等准则确认，销售分别确认收入成本（解释第 15 号），**不以净额冲减研发支出** | 按归集要求处理 | 特殊收入（下脚料/残次品/中间试制品）从已归集费用中**扣减**；研发形成产品对外销售的对应**材料费不得加计** |
| **辅助核算** | 按准则核算即可 | 按项目归集，研发费用辅助账 | **必须设研发支出辅助账**，研发与生产费用分别核算，**划分不清的不得加计** |

**差异成因**：三口径的服务对象不同（报表使用者 vs 高企资质 vs 税收优惠），加计扣除范围采取**正列举**方式——会计上计入研发费用的支出，不一定都能加计扣除，这是税会差异的核心来源。

## 三、加计扣除相关政策 · 财务侧要点

### 3.1 政策文件（截至 2026-08-23 核验有效）

### 3.2 归集六大类（正列举，未列举不得加计）

1. **人员人工费用**：直接从事研发人员工资薪金、五险一金、外聘研发人员劳务费；同时从事非研发活动的按**实际工时占比**分配。
2. **直接投入费用**：材料、燃料、动力费；模具与工艺装备开发制造费；样品样机购置费；试制产品检验费；仪器设备运行维护费；经营租入研发设备租赁费。
3. **折旧费用**：研发仪器设备折旧；共用按实际工时占比分配；加速折旧按税前扣除折旧部分加计。
4. **无形资产摊销**：研发用软件、专利权、非专利技术摊销；共用按使用情况分配。
5. **新产品设计费等**：新产品设计费、新工艺规程制定费、新药临床试验费、勘探开发现场试验费。
6. **其他相关费用**：图书资料、翻译、专家咨询、差旅、会议、福利费、补充养老/医疗、知识产权申请注册代理费等，**合计 ≤ 可加计研发费用总额的 10%**。

**其他费用限额公式**（2021年第28号公告起全部项目统一计算）：
```
其他费用限额 = 全部项目"前五项费用之和" × 10% ÷ (1 - 10%) = 前五项费用之和 ÷ 9
```

### 3.3 负面清单

- **7 类不得加计的活动**：①产品（服务）常规性升级；②对科研成果的直接应用；③商品化后为顾客提供的技术支持；④对现存产品/技术/工艺的重复或简单改变；⑤市场调研、效率调查、管理研究；⑥常规质量控制、测试分析、维修维护；⑦社科、艺术、人文学研究。
- **6 类不得加计的行业**：烟草制造业、住宿餐饮业、批发零售业、房地产业、租赁和商务服务业、娱乐业。判断口径：按**实际主营业务**对应的《国民经济行业分类》，非工商登记行业。

### 3.4 特殊处理

- **特殊收入扣减**：研发过程形成下脚料、残次品、中间试制品等特殊收入，从已归集研发费用中扣减；不足扣减的按零计算。
- **产品材料费冲减**：研发直接形成产品对外销售的，对应材料费不得加计；跨年度在销售当年冲减，不足冲减结转以后年度。
- **政府补助**：会计净额法（冲减研发）且税务未确认应税收入的，按冲减后余额加计；总额法下政府补助应确认收入，以税前扣除的研发费用为基数。
- **失败研发/亏损企业**：失败项目费用可加计；亏损企业可享受（加大亏损结转弥补）。

### 3.5 财务侧核算要求（三大要求，财税119号）

1. 按国家统一会计制度处理研发支出；
2. **设置研发支出辅助账**，按研发项目分别归集，归集不准确的税务机关有权调整；
3. **研发费用与生产费用分别核算**，划分不清的不得加计扣除。

## 四、加计扣除 · 审计侧核查要点

### 4.1 核查程序（从辅助账到申报表）

1. **先查负面清单**：主营业务是否属 6 类行业？研发活动是否含 7 类禁列活动？命中则相关费用全额不得加计。
2. **取数比对**：取得"研发支出辅助账"与"加计扣除鉴定表/年度纳税申报表（**A107012**）"，与账面研发费用（管理费用-研发费用 + 开发支出资本化）比对，差异逐项找原因。
3. **逐项过筛**（重点四项）：
   - **其他费用 10% 限额**：用统一公式（前五项之和÷9）重算，超标部分调减；
   - **委托研发 80% 调减**：境内按实际发生额 80% 计入，全额加计则多计；境外另查境内 2/3 限额；
   - **共用设备/人员工时分摊**：非全时研发人员无工时记录或产研共线未分摊 → 多计加计；
   - **产出产品材料冲减 / 废料收入扣减**：销售年度对应材料费是否已冲减、特殊收入是否已扣减。
4. **编差异调节表**：会计口径 → 高企口径 → 加计扣除口径逐项调节，说明每项差异的规则依据与纳税影响；与 IPO 问询回复"研发投入与加计扣除差异"口径衔接。
5. **资本化项目专项**：资本化项目其他费用限额按四步法（先算全部项目限额→比大小→算可加计比例→分摊到各资本化项目）；资本化支出加计扣除与会计摊销年限（≥10年）勾稽。

### 4.2 税会差异红旗信号

| 差异点 | 会计口径 | 加计扣除口径 | 红旗 |
|--------|---------|-------------|------|
| 负面清单活动/行业 | 计入研发费用 | 不得加计 | 常规升级/质控/市场调研混入 → 全额不得加计 |
| 人员工时 | 按会计估计分摊 | 必须按实际工时占比 | 非全时人员无工时记录 → 加计多计 |
| 材料形成产品 | 销售确认收入成本，不冲减研发 | 对应材料费不得加计 | 销售后仍加计材料费 |
| 正列举未列费用 | 据实计入 | 不得加计 | 会计计了但未列举 → 调减 |
| 其他费用 | 据实归集 | ≤10% | 超标部分不得加计 |
| 委外（境内） | 全额 | 80% | 全额加计未调减 |
| 委外（境外） | 全额 | 80%且≤境内2/3 | 超限未调减 |
| 政府补助（净额法） | 冲减研发 | 按冲减后余额加计 | 口径不一致未调整 |
| 废料/下脚料收入 | 解释第15号按存货/收入准则处理，不机械套用税务扣减 | 特殊收入从可加计费用中扣减 | 把税务扣减当会计处理，或税务未扣减 |

### 4.3 差异合理性结论口径

- 能逐项解释且符合法规 → 差异合理（🟢）
- 差异大且无法解释 → 多计加计扣除风险，影响所得税与 IPO 申报（🟠）
- 红线：**不得把"未提供辅助账"等同"无加计"**，也不得把"账面有研发费用"直接认定"可加计"。

## 五、IPO 常见偏差与调整

1. 研发费用归集混同（生产/工艺/质保人员计入、非研发材料计入）。
2. 资本化过早（不满足五条件即资本化）。
3. 研发人员认定不实（凑研发投入率以达科创属性指标；当期研发工时占比低于50%原则上不计入 IPO 研发人员）。
4. 委托研发无真实交付、关联方代研发回流。
5. 三口径差异大且无合理解释、高新/加计申报与账面不符。
6. 研发投入率波动异常、与营收不匹配。

## 六、审计核查要点（整体）

- 研发人员/工时核查（剔除非研发）、材料领用抽样（研发/生产隔离）。
- 资本化节点证据（立项/可行性/评审/中试）。
- 委托研发合同/发票/成果交付/关联方核查。
- 编制"会计/高新/加计"三口径差异调节表，说明差异与纳税影响。
- 研发投入率与同行可比性分析。
- 加计扣除专项：辅助账完整性、A107012 表勾稽、限额重算（详见第四节）。
