# 企业财务规范（知识地图）

> **视角定位**：本模块从**企业财务自身**出发——回答"我作为企业财务，应如何把账做对、把内控建好、把流程跑顺"，与 `行业研究`（审计视角："怎么查你 / 哪里会出错"）**互为镜像**。
> 核心用法：**审计风险点 ≈ 企业内控 / 核算失效的镜像**。把现有审计笔记翻转，即为企业应建立的财务规范"需求清单"（见 `5-行业财务规范对照` 的双向对照表）。

## 一、模块结构

| 子目录 | 内容 | 与审计侧的关系 |
|--------|------|----------------|
| `0-框架与方法论` | 会计政策手册模板、内控体系框架（COSO + 企业内控基本规范）、权限审批矩阵、月结 / 年结标准动作、财务制度编写规范 | 审计"了解被审计单位内控"的企业侧对应物 |
| `1-核算规范化` | 从编制者角度的准则落地（收入确认政策、资产减值、政府补助、合并、租赁、金融工具） | 对应 `会计准则` 笔记的"企业侧" |
| `2-内控与流程标准化` | 不相容职务分离、采购到付款 / 销售到收款 / 资金 / 资产 / 费用报销 SOP | 审计"穿行测试 / 控制测试"的对象 |
| `3-税务合规规范` | 发票管理、申报日历、优惠合规边界、转让定价基础 | 审计"税务科目 / 递延所得税"的企业侧 |
| `4-业财数字化` | 财务共享、系统选型（ERP / 费控 / 银企直连）、RPA / AI 企业侧应用 | 与审计侧 AI 工具呼应（同一技术，不同立场） |
| `5-行业财务规范对照` | 给现有行业研究补"企业财务规范"反向维度（双向对照表） | 直接翻转 `行业研究` 审计笔记 |
