## ✅ 一、强烈借鉴（思路 / 方法 / 避坑）

### 1.1 审计底稿生成三条技术路线（方法论）
- 路线：模板渲染 / 代码生成 / LLM Agent。**常见组合 = 代码生成做标准科目 + Agent 兜底非标 + 模板做复核呈现层**。
- **关键边界（最重要）**：源数据质量是天花板；AI 初稿仍需执业审计师复核签字，不能当终稿。
- 与你：和"极简、公式驱动、人做判断"取向完全一致。你现用 WorkBuddy / OpenCode + MinerU + Obsidian 即个人版落地。

### 1.2 AI 审计：抽样 → 全量 / 持续审计（范式 + 避坑）
- population-based / continuous testing；ROI 约 18–24 个月。
- **避坑（经验）**：① 数据未清洗 → 误报淹没；② 过度依赖工具 → 丧失职业怀疑。工具越强，审计师越要会**验证 AI 的逻辑**而非只验算结果。

### 1.3 Fieldguide + MCP（集成标准）
- 用 MCP 连接 Claude / Copilot / Gemini + Slack / Drive / Office，自然语言问 engagement 状态。
- 借鉴：把 MCP 作为 Agent 与现有办公 / 数据系统的**集成标准**，而非各自写接口。对你：可把审迹知识库通过 MCP / 向量做 RAG 消幻觉。

### 1.4 AI 财税选型"三大误区"（真实避坑）
1. 重价格轻合规；2. 忽视 ERP 对接导致数据孤岛；3. **把"自动申报"等同"免审"——法律责任仍由企业承担**。
- 适用：若你 / 客户涉及代账、税务场景，这三条是硬红线。

### 1.5 狗哥「一人 + AI = 专业财务审计团队」课（查漏）
- 你已在做其中大半（OpenCode、MinerU 读扫描件、Word 报告 Skill、蒸馏可复用工具）。
- 可补：① Skill Creator 系统化；② **IMA 知识库 MCP 消幻觉**（把你的准则笔记接成 RAG）。

### 1.6 WPS AI 审计"本地化 / 私有化"思路（方向）
- 端到端加密 + 本地化 / 私有化部署，满足《会计师事务所数据安全管理暂行办法》。
- 与你：敏感审计底稿绝不上公有云 OCR——与行业合规方向一致，继续坚持。

## ⚠️ 二、方向参考（仅取模式，删广告）

### 2.1 多智能体协同 / 知识蒸馏模式
- 模式：把资深经验"蒸馏"成可复用知识底座 + 多个专职智能体（风险画像 / 异常识别 / 穿透等）协同。
- 来源：审友 A8（50+ 智能体）、华夏银行「数智员工」（读 / 取 / 析 / 合四大 Agent，基于"5C"框架，关键决策点人工审核）。
- 借鉴点：**Agent 编排 + 关键节点人工把关**的结构；具体产品不可采用。

### 2.2 国际工具（具体可用的两个）
- **DataSnipper**：Excel 内直接抽取 / 核对（发票、合同、银行流水），审计底稿友好——可关注国产平替。
- **MindBridge**：AI 异常检测（全量 population 分析）。其余（Caseware / Intuit / Vic.ai 等）仅作了解，**行动前复核当前版本与可及性**（产品迭代快，易过时）。
