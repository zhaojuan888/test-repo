# 船舶吨税

> 法律依据：《中华人民共和国船舶吨税法》（主席令第六十四号，2018-07-01 施行）。**2026 年无独立新政**，税率随 2026 年关税调整方案统一联动调整；仅外贸港口、航运企业涉及，境外船舶入境港口由海关同步征收，适用行业覆盖面窄，一般企业无需关注。

## 核心要素

| 要素 | 内容 |
|------|------|
| 纳税人 | 应税船舶的**负责人**（船长或船公司） |
| 征税范围 | 自中国**境外港口进入境内港口**的船舶（境内港口间航行不征） |
| 计税依据 | 船舶**净吨位**（拖船按功率每千瓦折合 0.67 吨；无法提供净吨位证明的游艇按 0.05 吨/千瓦；拖船和非机动驳船按同吨位税率 **50%** 计征） |
| 税率结构 | 按净吨位分档（≤2000 / >2000≤10000 / >10000≤50000 / >50000 净吨）× 执照期限（1年 / 90日 / 30日）× **普通税率 / 优惠税率** |
| 优惠税率适用 | ① 中国籍应税船舶；② 船籍国（地区）与我国签订含相互给予船舶税费最惠国待遇条款的条约/协定的应税船舶；其余适用普通税率 |
| 征收机关 | 海关（入境港口同步征收），凭吨税执照放行 |

## 主要优惠

- 优惠税率（中国籍 / 最惠国待遇缔约国船舶）较普通税率低约 30%（如 ≤2000 净吨：普通 1年 12.6 元/净吨、优惠 9.0；30日普通 2.1、优惠 1.5）。
- 拖船、非机动驳船减半征收。
- 无针对一般企业的普遍性减免；**不适用六税两费减半**。

## 审计 / 尽调关注点

- **行业适用性识别**：船舶吨税仅外贸航运/港口企业涉及，一般制造业、房地产、农产品贸易企业（含长兴新农都）**无此税种场景**，尽调中识别"是否经营境外航线船舶"即可排除。
- 若为港口/航运/物流板块延伸尽调，核查：船舶净吨位证明、吨税执照期限与税率档适用、中国籍/最惠国优惠资格、海关完税凭证与账务"应交税费—船舶吨税"匹配。
- 与关税衔接：同属海关征收、随关税方案联动，见 [[关税]]（2026 关税调整方案）。
