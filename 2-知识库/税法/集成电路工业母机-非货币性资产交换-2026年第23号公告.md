# 集成电路/工业母机企业非货币性资产交换企业所得税政策（2026年第23号公告）

> 财政部 税务总局 国家发展改革委 工业和信息化部公告 **2026年第23号**（2026-08-14 发布）：集成电路企业、工业母机企业 2026-01-01 至 2028-12-31 发生非货币性资产交换，交换所得可在**不超过 5 年期限内分期均匀计入应纳税所得额**。与 [[企业重组所得税-2026年第13号公告]]（重组征管）同属"递延纳税+税收优惠"主线。

## 核心规则

| 项目 | 内容 |
|------|------|
| 适用期间 | 2026-01-01 至 2028-12-31 |
| 适用主体 | 集成电路企业、工业母机企业（双方均为两类企业的，双方均可享受） |
| 优惠内容 | 非货币性资产交换所得可在 **≤5 年**内分期均匀计入各年度应纳税所得额 |
| 损失处理 | 交换损失**不得分期确认**（当期全额确认） |
| 交换所得计算 | 换入非货币性资产公允价值 − 换出非货币性资产计税基础 − 相关税费 = 交换所得 |
| 换入资产计税基础 | 公允价值 + 支付的相关税费 |
| 停止条件 | 5 年内**转让换入资产**或**注销**→ 停止分期，未确认所得在转让/注销当年汇算清缴时一次性缴纳 |
| 混合交易 | 一项交易同时含货币性资产部分的，货币性部分不适用分期（按现规确认所得/损失） |

## 与一般企业非货币性资产交换的差异（重点）

一般企业（财税〔2007〕59 号口径）非货币性资产交换原则上**当期确认交换所得**（公允价值与计税基础差额），仅满足条件可适用特殊性税务处理；**23 号公告给集成电路/工业母机企业开了"单独分期"的口子**——不要求"股权支付占比"等特殊性处理条件，直接 5 年分期。

## 判断框架（审计/税务核查用）

1. 企业是否属于集成电路企业/工业母机企业（工信部目录/认定文件）？
2. 交易是否属于非货币性资产交换（货币性资产：现金、存款、应收票据、应收账款、准备持有至到期债券等以外的资产）？
3. 交换所得 = 换入公允 − 换出计税基础 − 税费，是否为正（损失不可分期）？
4. 5 年内是否转让换入资产/注销（触发一次性补缴）？
5. 分期表：每年计入应纳税所得额 = 交换所得 ÷ 5（均匀分摊）
