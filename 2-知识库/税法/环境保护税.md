# 环境保护税

> **法规**：《中华人民共和国环境保护税法》自 **2018 年 1 月 1 日**施行，实现"费改税"（原排污费退出）。

## 核心要素

| 要素 | 内容 |
|------|------|
| 纳税人 | 直接向环境排放**应税污染物**的企事业单位和其他经营者 |
| 征税对象 | 大气污染物 / 水污染物 / 固体废物 / 工业噪声 |
| 计税依据 | 大气、水按**污染当量数**；固体废物按**吨**；噪声按**超标分贝** |
| 不征税 | 向依法设立的污水 / 生活垃圾集中处理场所排放；符合标准的综合利用固体废物 |

## 主要优惠

- **达标减税**：大气 / 水污染物浓度值低于国家和地方标准 30% 的，减按 75% 征收；低于 50% 的，减按 50% 征收；
- 合规贮存或处置的固体废物不征；
- 农业生产（不包括规模化养殖）排放免税。

## 审计 / 尽调关注点

1. **排放量核算方法优先级**：自动监测 > 监测机构出具数据 > 排污系数 / 物料衡算（方法不同税额差异大）；
2. 减税优惠是否满足浓度达标 + 当月全部应税污染物均达标；
3. 是否漏报应税污染物（尤其是无自动监测的噪声、固废）；
4. 污染物监测数据与环保部门联网比对一致性；
5. 涉农 / 制造企业尽调时作为环境合规与成本项核查。
