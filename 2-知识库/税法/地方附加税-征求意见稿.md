# 地方附加税法（征求意见稿）——城建税+教育费附加+地方教育附加"三费合一"

> **文件**：《中华人民共和国地方附加税法（征求意见稿）》，财政部会同税务总局 2026-08-28 发布，向社会公开征求意见（共 13 条）。
> **背景**：党的二十届三中全会提出"研究把城市维护建设税、教育费附加、地方教育附加合并为地方附加税，授权地方在一定幅度内确定具体适用税率"；二十届四中全会提出"完善地方税、直接税体系"。

## 核心内容

| 要素 | 规则 |
|------|------|
| 纳税人 | 在我国境内**缴纳增值税、消费税的单位和个人** |
| 计税依据 | 纳税人**实际缴纳的增值税、消费税税额** |
| 税率 | **11%-13% 幅度税率**，具体由省、自治区、直辖市人民政府提出，报同级人大常委会决定，报全国人大常委会和国务院备案；**取消原城建税按行政区划等级分档税率**（7%/5%/1%）的做法 |
| 不征税情形 | 进口货物、境外单位和个人向境内销售服务/无形资产缴纳的增值税、消费税税额，**不征收**地方附加税 |
| 税负测算 | 2025 年三项收入合计 **9134 亿**（城建税 5170+教育费附加 2382+地方教育附加 1582）；现行三项合计平均税（费）率约 **11.6%**（城建税按收入加权平均约 6.6%+教育费附加 3%+地方教育附加 2%）；11%-13% 中间值与平均税负基本相当——**税制平移、总体稳定** |
| 定位 | 合并后将成为**地方税体系第一大税种**（超 9000 亿稳定税源），落实税收法定原则 |

## 对审计/税务工作的影响（前瞻）

1. **应交税费科目列报**：未来"应交城建税/教育费附加/地方教育附加"将并为"应交地方附加税"单一科目（立法通过后），审计调整与披露需跟进。
2. **税负测算模板**：现行"增值税×（7%/5%/1% + 3% + 2%）"公式将改为"增值税×地方适用税率（11%-13%）"——长兴新农都土增税测算模型、房企税负测算等需预留参数化改造。
3. **各地适用税率差异**：幅度税率+省级定率→**同一集团跨省项目税负出现地区差**，尽调税务分析需按项目所在地适用税率分别测算。
4. **进出口业务**：进口环节增值税消费税不征地方附加税（延续现行口径），跨境服务进项相关判断不变。
5. **征求意见窗口**：可关注财政部官网征求意见渠道，实务界可反馈（如税率幅度、过渡期衔接、小规模纳税人优惠平移等）。

## 怎么学会

- 官方原文：财政部官网 8/28 发布《中华人民共和国地方附加税法（征求意见稿）》全文+说明
- 解读：人民日报 8/29（施正文：税制平移、浮动税率为地方留空间）；央视网 8/29（樊勇：三项合并后超 9000 亿，壮大地方税主体规模）；中国经济网 8/29（李旭红：税制要素延续、稳定预期）
- 小练习：取一家制造业客户 2025 年实际缴纳增值税额，分别按"现行三费公式（7%+3%+2%）"与"地方附加税 11%/12%/13% 三档"测算税负差异，评估立法落地后的影响区间

## 方向建议

- 优先级：**中高**（立法尚在征求意见，但属 2026-2027 重大税制改革主线，审计/税务从业者需提前储备）
- 解决什么：税制改革趋势预判、未来税负测算模板改造、客户财税规划前瞻
- 职业/变现：①做"地方附加税立法进展+各省税率预案"跟踪专题；②给房企/集团客户做"三费合一税负测算对比表"咨询；③公众号政策解读文章引流
