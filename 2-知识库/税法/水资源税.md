# 水资源税

> 由"水资源费"改为"水资源税"，是党的二十届三中全会"落实水资源刚性约束制度、全面推行水资源费改税"的落地税种；属绿色税收/资源税类，从量计征、强化差别税额调节。

## 一、法规依据

- **财税〔2024〕28号《水资源税改革试点实施办法》**（财政部 税务总局 水利部，2024-10-11 印发，**2024-12-01 起全国 31 省份全面实施**）。
- 上位法：《中华人民共和国资源税法》（授权国务院试点征收）、《中华人民共和国水法》。
- **同时废止**：财税〔2016〕55号（暂行办法）、财税〔2016〕130号（河北试点）、财税〔2017〕80号（扩大试点）。
- 历史沿革：2016-07-01 起在河北、北京、天津、山西、内蒙古、山东、河南、四川、陕西、宁夏 10 省（区、市）试点，2024-12-01 推向全国。

## 二、核心要素

| 项目 | 内容 |
|------|------|
| **纳税人** | 直接从江河、湖泊（含水库、引调水工程等水资源配置工程）和**地下**取用水资源的单位和个人；**城镇公共供水企业**为纳税人，水资源税与自来水价格实行**价税分离** |
| **征税对象** | 地表水、地下水（按实际取用水量） |
| **计税方式** | **从量计征**，按实际取用水量 |
| **税额——差别税额** | ① 地下水税额**高于**地表水；② **水资源严重短缺和超载地区**取用水从高；③ **特种行业**（洗车、洗浴、高尔夫球场、滑雪场）从高；④ 各省在"最低平均税额"基础上确定具体适用税额 |
| **最低平均税额（元/立方米）** | 各省不同：北京地表水 1.6 / 地下水 4；浙江、广东、云南、甘肃、新疆、四川等地表水 0.1 / 地下水 0.2；详见办法附件《各省最低平均税额表》 |
| **征管** | 税务机关 + 水行政主管部门协作；强化取水计量设施（器具）监管 |
| **收入归属** | **全部归地方**（原水资源费中央与地方 1:9 分成，改税后全留地方，拓展地方税源） |

## 三、税收优惠

- **免税（五种情形，法定）**：规定限额内的农业生产取用水、抽水蓄能发电取用水等（办法明确免征）。
- **授权地方减免**：超出规定限额的农业生产取用水、农村集中饮水工程取用水，由地方决定减免。
- **减征**：用水效率达到国家用水定额先进值的纳税人，减征水资源税。

## 四、审计/尽调关注

- **取用水企业（高频场景）**：制造业、采矿、火电、水务、规模化农业等直接取用水资源的，应核查①取水许可证与许可水量、②取水计量设施读数（自取 vs 水务供应）、③申报缴纳是否足额（尤其地下取水、超采区从高部分易瞒报）。
- **城镇公共供水企业**：价税分离，终端水价不应含税；关注是否把水资源税混入水价、是否据实申报取水量。
- **特种行业**：洗车、洗浴、高尔夫、滑雪场适用从高税额，核对其是否按高税率申报。
- **长兴新农都（FDD 衔接）**：农贸市场/商铺运营本身一般不直接取用地下水或地表水（除非项目配套自有水井、冷却塔补水等），**通常无直接场景**；更相关的仍是房产税、城镇土地使用税、不动产租赁 5%、土增税（见 [[审计程序/行业审计对照/房地产业-企业财务规范对照|行业审计对照（房地产业）]]）。若现场发现取水设施，再识别并补本方核对，避免误报税务风险。
