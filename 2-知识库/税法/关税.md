# 关税

> **法规**：《中华人民共和国关税法》自 **2024 年 12 月 1 日**施行，《中华人民共和国进出口关税条例》同时废止。税则由国务院关税税则委员会编纂发布。

## 核心要素

| 要素 | 内容 |
|------|------|
| 纳税人 | 进口货物收货人、出口货物发货人、进境物品所有人 |
| 征税对象 | 准许进出境的货物、物品 |
| 税率形式 | 最惠国税率 / 协定税率 / 特惠税率 / 普通税率 / 关税配额税率 / **进口暂定税率** |
| 计税依据 | 海关审定的**完税价格**（进口以 CIF 为基础）|
| 进口环节税 | 关税 + 进口增值税 + 进口消费税（由海关一并征收）|

> **2026 年关税调整方案**（2025-12-29 发布，2026-01-01 实施）：对 **935 项商品**实施低于最惠国税率的进口暂定税率；CEPA 项下香港原产货物继续零关税。

## 主要优惠

- 自由贸易协定优惠税率（RCEP、中韩、中国—东盟等），凭原产地证书享惠；
- 进口暂定税率（低于最惠国税率，年度调整）；
- 特定区域 / 加工贸易保税（不征或缓征）。

## 审计 / 尽调关注点

1. **完税价格审定**：关联交易转移定价、特许权使用费是否计入、运保费分离；
2. **税则归类**：同一种商品归入不同税则号税率差异大，关注归类准确性；
3. **协定原产地享惠资格**：原产地规则（区域价值成分等）与单证完备性；
4. **加工贸易保税**：保税料件内销是否补缴关税及缓税利息；
5. 进口环节增值税与国内增值税进项抵扣的衔接。
