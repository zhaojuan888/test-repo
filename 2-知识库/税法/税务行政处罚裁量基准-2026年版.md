# 税务行政处罚裁量基准（2026 年版）

> 税务总局 2026-07-16 公开征求意见（征求意见稿），**征求意见截止 2026-08-13（已截止）**。
> 截至 2026-08-21 复核：正式稿（带生效日期的发布版本）尚未检索到，当前状态为 **draft（征求意见已截止、正式稿待发布）**，本库暂按征求意见稿收录，`status` 待正式发布后改为 `effective` 并补 `effective_date`。
> 发布后用于统一各地税务处罚执法尺度，压缩自由裁量空间，防止同案不同罚。

## 一、框架结构

- 覆盖 **9 类 66 项**行政处罚事项：税务登记 / 账簿凭证 / 纳税申报 / 税款征收 / 税务检查 / 发票及票证 / 纳税担保 / 涉税专业服务管理 / 涉税信息报送
- 每项列明：法定依据 + 裁量阶次 + 适用条件 + 具体标准
- 裁量阶次总体分 **5 档**：轻微 / 较轻 / 一般 / 较重 / 严重
- 配套附件：《税务行政处罚"轻微不罚"事项清单》

## 二、核心规则示例（偷税，征管法第 63 条）

| 情形 | 罚款倍数（不缴/少缴税款） |
|------|------------------------|
| 5 年内首次被罚 + 配合检查 | 0.5 倍 - 1 倍 |
| 5 年内二次以上被罚 + 配合检查 | 1 倍 - 3 倍 |
| 5 年内首次被罚 + 不配合检查 | 3 倍 - 4 倍 |
| 二次以上 + 不配合，或有其他严重情节（含偷税≥500 万且占应纳税额≥10%） | 4 倍 - 5 倍 |

> 不申报（征管法第 64 条第 2 款）同设四档，界定因素相同：**5 年内次数 + 配合态度**（+偷税情形下金额占比）。

## 三、裁量逻辑总结（三因子）

1. **次数**：5 年内是否首次被处罚
2. **态度**：是否配合税务检查
3. **金额**（偷税类）：偷税数额 ≥500 万 + 占比 ≥10% 触发"严重"

> 设计特点："定额幅度"式设置处罚标准，为个案留裁量空间，防止"一刀切"。

## 四、实务启示

- 涉税处罚金额测算：先看三因子 → 套档位 → 得倍数区间
- 企业应对策略：首次被查 → 主动配合 + 补缴 → 可争取"较轻"档（0.5-1 倍）
- 审计客户涉税风险提示：把裁量基准纳入涉税诉讼/处罚预计负债测算依据
- 8/13 前可向税务总局提交实务意见（在线/信函），专业机构可借此发声
