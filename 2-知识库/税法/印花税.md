# 印花税

> **法规**：《中华人民共和国印花税法》自 **2022 年 7 月 1 日**施行，《印花税暂行条例》同时废止。配套口径见财政部 税务总局公告 2022 年第 22 号、23 号。

## 核心要素

| 要素 | 内容 |
|------|------|
| 纳税人 | 在境内书立应税凭证、进行证券交易的境内单位和个人 |
| 合同税率 | 借款合同 0.005% / 买卖合同 0.03% / 承揽 0.03% / 建设工程 0.03% / 租赁 0.1% / 运输 0.03% / 技术 0.03% / 保管 0.1% / 仓储 0.1% / 财产保险 0.1% |
| 产权转移书据 | 土地使用权 / 房屋等转让书据 0.05%（股权转让书据 0.05%）|
| 营业账簿 | （实收资本 + 资本公积）× 0.025% |
| 证券交易 | 0.1%（出让方）|

## 主要优惠

- **六税两费减半**：2023-01-01 至 **2027-12-31**，对小规模纳税人、小型微利企业、个体工商户减半征收印花税（**不含证券交易印花税**）——sunset 2027-12-31；
- **离岸贸易印花税免征**（财税 2025 年第 10 号）：自 2025-04-01 至 **2027-12-31**，对注册于 7 个自贸片区 + 海南自贸港企业开展离岸转手买卖书立的买卖合同免征；
- 个人销售 / 购买住房涉及的印花税暂免（财税 2008 137 号）；
- 28 种凭证不征（人身保险合同、再保险合同、同业拆借、个人书立动产买卖、管道运输、旅客运输、土地承包经营权转移、抵押 / 质押从合同、保证合同、审计 / 评估业务约定书、劳动合同等）。

## 审计 / 尽调关注点

1. 应税凭证是否**全覆盖**（电子形式签订的应税凭证同样征税）；
2. 税率适用：产权转移书据 0.05% vs 买卖合同 0.03% 易混；
3. 营业账簿增量（资本公积变动）是否申报；
4. 减免资格（小微减半、 offshore 离岸贸易免征区域与业务界定）；
5. 二手房 / 股权交易产权转移书据漏贴风险。
