# 耕地占用税

> 法律依据：《中华人民共和国耕地占用税法》（主席令第十八号，2019-09-01 施行）。占用耕地建设建筑物、构筑物或从事非农业建设的单位和个人为纳税人；占用耕地建设农田水利设施的不征。占用农用地从事非农业建设的，在办理建设用地审批手续前（或 simultaneous）由税务机关征收。

## 核心要素

| 要素 | 内容 |
|------|------|
| 纳税人 | 境内占用耕地建设建筑物/构筑物/从事非农业建设的单位或个人 |
| 征税对象 | 实际占用的耕地面积（平方米） |
| 计税依据 | 实际占用耕地面积 × 适用税额，**一次性征收**（不按年） |
| 税额幅度（按县级人均耕地） | ≤1 亩：10–50 元/㎡；>1≤2 亩：8–40；>2≤3 亩：6–30；>3 亩：5–25 |
| 基本农田 | 按当地适用税额 **150%** 执行 |
| 纳税期限 | 纳税义务发生（收到办理占用耕地手续书面通知当日）起 30 日内申报缴纳 |

## 主要优惠

- **免征**：军事设施、学校、幼儿园、社会福利机构、医疗机构占用耕地。
- **减按 2 元/㎡**：铁路线路、公路线路、飞机场跑道/停机坪、港口、航道、水利工程占用耕地。
- **农村居民新建自用住宅**（规定用地标准内）：按当地适用税额**减半**；经批准搬迁、新建占用不超过原宅基地面积部分**免征**；烈士遗属/因公牺牲军人遗属/残疾军人/农村低保对象新建自用住宅免征。
- **🌅 sunset｜2023-01-01 至 2027-12-31**：对增值税小规模纳税人、小型微利企业和个体工商户**减半征收**，且可与其他优惠叠加（财税〔2023〕第 号延续，至 2027-12-31）。
- **用途变更补缴**：享受减免后改变原占地用途、不再符合减免情形的，应自改变用途之日起 **30 日内**按当地适用税额补缴；临时占用耕地期满之日起 1 年内复垦恢复种植条件的，全额退还。

## 审计 / 尽调关注点

- **拿地/基建环节必查**：房地产开发、产业园区、基建项目（如长兴新农都商铺/市场建设、农贸市场改扩建）涉及农用地转用或占用耕地的，应核实是否足额申报耕地占用税，计税面积与《建设用地批准书》/出让合同占地是否一致。
- **减免适用真实性**：学校、医院、水利工程等"免征"项目须取得对应资质/立项证明，防止以公益名义占地规避税款。
- **用途变更风险**：项目后期改变土地用途（如工业→商业）触补缴，需评估补税敞口并作披露。
- **申报 vs 账面 vs 合同 vs 资金**：核对"应交税费—耕地占用税"计提、完税凭证、土地出让/转让合同占地条款四流一致。
