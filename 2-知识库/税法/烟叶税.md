# 烟叶税

> 法律依据：《中华人民共和国烟叶税法》（主席令第六十九号，2018-07-01 施行，由暂行条例上升为法）。**2026 年无任何税制改动，法定税制长期稳定**。仅在烟叶收购环节、由收购烟叶的单位缴纳，行业覆盖面极窄（烟草公司及其委托收购单位）。

## 核心要素

| 要素 | 内容 |
|------|------|
| 纳税人 | 境内**收购烟叶的单位**（仅烟草公司或其委托单位有权收购，不含个人；是收购方直接纳税，非扣缴义务人） |
| 征税对象 | 烤烟叶、晾晒烟叶 |
| 税率 | **20% 比例税率**（法定，长期稳定） |
| 计税依据 | 收购烟叶实际支付价款总额 = 收购价款 ×（1 + 10% 价外补贴） |
| 应纳税额 | 价款总额 × 20% |
| 纳税期限 | 按月计征，纳税义务发生月（收购烟叶当天）终了之日起 **15 日内**申报缴纳；纳税地点为烟叶收购地主管税务机关 |

## 主要优惠

- 烟叶税**无普遍减免政策**（不适用六税两费减半等其他税种优惠）；法定税率固定 20%。

## 审计 / 尽调关注点

- **行业适用性识别**：烟叶税仅烟草收购行业涉及，非烟草企业（包括长兴新农都这类农产品交易市场）**通常无烟叶税涉税场景**，尽调中识别"是否收购烟叶"即可排除，不必深查。
- 若为涉农贸易/食品企业延伸尽调涉及烟叶收购子公司，则核查计税依据是否足额计入 10% 价外补贴、是否按月申报、收购量与完税凭证匹配。
- 与消费税区分：卷烟等烟产品在**生产/批发环节**征消费税（复合计税），与收购环节烟叶税是两个税种、两个环节，勿混淆。
