# CAS 3 投资性房地产

> 投资性房地产是审计高频科目——农贸/商业地产/园区运营企业常见。公允价值模式计量是尽调重点。
> 关联项目：[[长兴新农都净资产审计/主页]]

## 定义与范围

### 属于投资性房地产（CAS3-第三条）
- **已出租**的建筑物（含转租/整体出租）
- 持有并**准备增值后转让**的土地使用权
- 已出租的土地使用权
- 母公司出租给子公司的房产（合并层面按投资性房地产）

### 不属于（重点区分）
- 自用房地产（→固定资产/无形资产）
- 作为存货的房地产（房地产开发企业的商品房）
- 经营租入再转租的（不确认，但**转租收入**需关注）

## 两种后续计量模式（核心分叉）

| 维度 | 成本模式 | 公允价值模式 |
|------|---------|-------------|
| 折旧/摊销 | 计提（同固定资产/无形资产） | **不计提** |
| 减值 | 计提 | 不单独计提（公允价下跌计入损益） |
| 账面调整 | 成本-累计折旧-减值 | **按资产负债表日公允价值调整** |
| 公允价值变动 | — | 计入**当期损益**（公允价值变动损益） |
| 转换 | 可转公允模式（不可逆） | **不得转回成本模式** |
| 利润影响 | 折旧均匀摊 | 公允价值波动直接进损益（业绩波动大） |

### 公允价值模式适用条件（CAS3-第十条）
1. 公允价值**能够持续可靠取得**
2. 有活跃市场 + 可取得同类/类似房地产市价
3. 通常需**外部评估机构**年度评估支持（如长兴新农都聘请天源评估）

## 转换处理（重难点）

### 公允模式下的转换
| 转换情形 | 转换日公允价 vs 账面价 | 处理 |
|---------|---------------------|------|
| 自用/存货 → 投资性房地产 | 公允价 > 账面价 | 差额计入**其他综合收益**（处置时转入当期损益） |
| 自用/存货 → 投资性房地产 | 公允价 < 账面价 | 差额计入**当期损益**（公允价值变动损益） |
| 投资性房地产 → 自用/存货 | 无限制 | 差额计入**当期损益** |

> ⚠️ 转换日**公允价值高于账面价值**计入 OCI 的差额，处置时必须**结转至其他业务成本**（见处置分录）。

## 处置（出售/转让）会计分录

### 公允价值模式处置 5 步
1. **确认收入**：借：银行存款 / 贷：其他业务收入、应交税费—销项税额（一般9%/老项目简易5%）
2. **结转账面**：借：其他业务成本 / 贷：投资性房地产—成本、投资性房地产—公允价值变动
3. **结转累计公允价值变动损益** → 其他业务成本（冲销持有期累计变动的损益影响）
4. **结转转换日 OCI**（若存在）→ 其他业务成本
5. **计提税费**：借：税金及附加 / 贷：应交税费—土地增值税、城建税、教育费附加

处置损益 = 其他业务收入 − 其他业务成本（含 3、4 步结转）− 税金及附加

> 详见：[[投资性房地产-公允价值模式处置分录]]

### 成本模式处置
```
借：银行存款
    贷：其他业务收入（含税价分离）
        应交税费——应交增值税（销项税额）

借：其他业务成本
    投资性房地产累计折旧（摊销）
    投资性房地产减值准备
    贷：投资性房地产（原值）
```

## 披露要求（审计关注）
- 计量模式及依据（公允价值是否持续可靠取得）
- 公允价值的**估值方法、关键假设、输入值层级**（市场法/收益法、折现率、租金假设）
- 转换及转换日公允价、OCI 余额变动
- 受限（抵押）投资性房地产及金额（**抵押披露**：长兴新农都 16 项抵押涉邮储/工行/交行/中行）

## 审计程序要点
1. **外部评估报告复核**：评估方法适用性（收益法/市场法）、折现率合理性、与账面差异
2. **公允价值变动勾稽**：本期变动 = 期末公允 − 期初公允，是否全额入公允价值变动损益
3. **转换核查**：自用↔投资性房地产转换时点、OCI 处理是否正确
4. **处置核查**：5 步分录完整性、累计公允变动/OCI 是否全部结转
5. **租金收入**：与租赁台账、合同匹配（在租 vs 空置）
6. **权属/抵押**：产权证、抵押合同核对
