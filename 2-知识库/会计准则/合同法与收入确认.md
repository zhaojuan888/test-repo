# 合同法与收入确认

## 合同是收入的起点

CAS 14 第 4 条规定，收入确认的第一个前提是**合同存在**。合同条款直接决定五步法每一步的判断。

## 关键合同条款对收入确认的影响

| 合同条款 | 影响 |
|---------|------|
| 验收条款 | 收入确认时点——客户签收 vs 验收通过 vs 质保期满 |
| 退货权 | 可变对价——是否需要估计退货率 |
| 价格保护条款 | 可变对价——是否承诺退差价 |
| 排他性条款 | 履约义务——是单独义务还是与其他绑定 |
| 付款条件 | 重大融资成分——预收/赊销是否含融资性质 |
| 终止条款 | 合同期限——最短不可撤销期间决定合同期 |
| 知识产权条款 | 许可 vs 销售——控制权转移时点不同 |
| 背靠背条款 | 总额 vs 净额——企业是否有首要责任 |

## 实务中的合同陷阱

### SaaS 合同
"免费试用 3 个月后自动续费" → 合同开始日是签约日还是试用结束日？→ 签约日（试用是获客成本，不影响合同存在）

### 框架合同
"按实际下单量结算" → 不是合同（第 4 条：合同必须明确支付条款和具有商业实质）→ 每次下单才是独立合同

### 口头变更
微信/邮件确认交货日期提前 → 合同变更（第 9 条）→ 可能影响收入确认时点

## 与问询案例的关系

[[深交所某公司收入确认问询]] 中，发行人将 SaaS"签约即交付"等同于履约义务完成——错误。合同条款中的"持续服务"才是履约义务的本质，签约只是合同成立的起点。
