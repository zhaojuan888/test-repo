# 投资性房地产-公允价值模式处置分录

> 公允价值模式投资性房地产**转让/出售**时的完整账务处理。2026-08-03 长兴新农都尽调整理。

## 核心逻辑

公允价值模式**不计提折旧、不确认减值**，处置时要把 3 个"历史包袱"全部结转到处置损益：
1. 账面余额（成本 + 累计公允价值变动）
2. 持有期累计确认的**公允价值变动损益**
3. 转换日计入的**其他综合收益**（自用/存货转入且公允价>账面价部分）

处置损益 = 其他业务收入 − 其他业务成本（含结转）− 税金及附加

## 完整分录（5 步）

### 分录 1 · 确认处置收入（不含税）
```
借：银行存款 / 应收账款            X（含税）
    贷：其他业务收入           X ÷ 1.09（或 ÷ 1.05）
        应交税费——应交增值税（销项税额）  一般计税 9%
        ——应交增值税（简易计税）          老项目简易 5%
```

### 分录 2 · 结转投资性房地产账面余额
```
借：其他业务成本              （成本 + 累计公允价值变动）
    贷：投资性房地产——成本              成本
        投资性房地产——公允价值变动      累计变动（若在借方则反向冲销）
```

### 分录 3 · 结转持有期间累计公允价值变动损益
```
借：公允价值变动损益（累计为贷方余额时）／反向
    贷：其他业务成本
```
> 目的：把以前年度已计入损益的公允价值变动**还原到处置损益**，避免重复计入利润。

### 分录 4 · 结转转换日计入其他综合收益的差额（关键）
```
借：其他综合收益         （转换日公允价 − 账面价的差额）
    贷：其他业务成本
```
> ⚠️ 仅当该房产由**自用房地产/存货转换**为投资性房地产、且转换日公允价 > 账面价时存在。处置时**必须结转**，否则 OCI 永远挂账、处置损益被低估。

### 分录 5 · 计提转让相关税费（增值税外）
```
借：税金及附加
    贷：应交税费——应交城市维护建设税
        应交税费——应交教育费附加
        应交税费——应交土地增值税（如有）
```

## 数字示例（长兴新农都口径）

以某商铺为例（评估报告天源评报字〔2026〕第0136号，评估值 1,017,600 元）：
- 假设处置含税价 = 评估值（账面 ≈ 1,071,000 元，其中成本 582,483 元、累计公允变动 488,517 元）
- 增值税按 9% 一般计税

```
分录1：借：银行存款          1,017,600
         贷：其他业务收入      933,578（=1,017,600÷1.09）
             应交税费—销项      84,022

分录2：借：其他业务成本      1,071,000
         贷：投资性房地产—成本      582,483
             投资性房地产—公允价值变动  488,517

分录3：借：公允价值变动损益    488,517
         贷：其他业务成本        488,517

（本例无分录4——非转换产生，或转换日公允价未超账面）

处置损益 = 933,578 − (1,071,000 − 488,517) − 税费 ≈ 351,095 元（含税价口径下另减土地增值税）
```

## 易错点（审计重点核查）

| # | 易错点 | 后果 |
|---|--------|------|
| 1 | 处置前**未先确认期末公允价值变动**（评估值已变化） | 账面余额不准，处置损益错 |
| 2 | 漏结转**其他综合收益** | OCI 挂账，处置损益低估 |
| 3 | 漏结转**累计公允价值变动损益** | 利润重复计入 |
| 4 | 简易计税/一般计税选错 | 增值税错误 |
| 5 | 土地增值税未计提 | 税费低估 |
| 6 | 收入按含税全额入其他业务收入 | 收入虚增 |
