# CAS 1311 存货审计

> 对存货、诉讼和索赔、分部信息等特定项目获取审计证据的具体考虑。

## 核心要求

1. **存货监盘**：如存货对财务报表是重大的，必须实施监盘
2. **双向抽盘**：从账到物（存在认定）+ 从物到账（完整性认定）
3. **不可替代**：监盘是必须执行的程序，不能仅依赖函证或分析程序
4. **盘点日≠资产负债表日**：必须核查期间变动（利安达案核心教训）

## 特殊情况

| 情况 | 应对 |
|------|------|
| 存货存放地点特殊（如管道/水域） | 利用专家工作 |
| 第三方保管的存货 | 函证 + 检查保管协议 |
| 审计师无法参加盘点 | 另择日期监盘 + 核查期间变动 |
