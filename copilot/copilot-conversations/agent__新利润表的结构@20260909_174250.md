**ai**: "新利润表"通常指**企业会计准则下的利润表**（即财政部 2018/2019 修订后的报表格式），相比老版结构最大的变化是：营业利润的计算口径更完整（纳入其他收益、信用减值损失、资产处置收益等），并把"其他综合收益"和"每股收益"也纳入利润表正表。

下面是新版（企业会计准则完整版）利润表的结构骨架：

## 一、营业总收入
- 营业收入
  - 主营业务收入
  - 其他业务收入

## 二、营业总成本
- 营业成本（含主营业务成本、其他业务成本）
- 税金及附加
- 销售费用
- 管理费用
- 研发费用（**从管理费用中单独列示**）
- 财务费用（其中：利息费用、利息收入单独列示）

## 三、营业利润的加项与减项
- 加：其他收益（政府补助等）
- 加：投资收益（其中：对联营企业和合营企业的投资收益）
- 加：以摊余成本计量的金融资产终止确认收益
- 加：公允价值变动收益
- 加：汇兑收益
- 减：信用减值损失（应收款项等预期信用损失）
- 减：资产减值损失（固定资产、商誉等减值）
- 减：资产处置收益（损失以"-"号填列）

## 四、营业利润
= 营业总收入 - 营业总成本 + 上述加项/减项

## 五、利润总额
- 加：营业外收入
- 减：营业外支出

## 六、净利润
- 减：所得税费用（其中：当期所得税费用、递延所得税费用）

## 七、其他综合收益的税后净额
- 不能重分类进损益的其他综合收益
- 将重分类进损益的其他综合收益

## 八、综合收益总额
= 净利润 + 其他综合收益

## 九、每股收益
- 基本每股收益
- 稀释每股收益

[Timestamp: 2026/09/09 17:43:34]

**ai**: 你问的是 **2026 年新版利润表**，即财政部 2026 年 7 月 24 日修订印发的《企业会计准则第 30 号——财务报表列报》（财会〔2026〕11号）所配套的新利润表格式。这版是对接 IFRS 18 的重构，核心是**把利润表当期损益划分为"五分类"**，并新增了几个中间合计项目。

## 一、核心变化：损益"五分类"

新利润表不再沿用"营业利润—利润总额—净利润"的单一主线，而是把计入当期损益的收入、费用、利得、损失划分为五类：

| 类别 | 说明 |
|---|---|
| 经营类别 | 主营业务产生的损益（收入、成本、销售/管理/研发费用等） |
| 投资类别 | 投资收益、公允价值变动、利息收入等 |
| 筹资类别 | 利息费用、筹资相关损益 |
| 所得税费用类别 | 所得税费用 |
| 终止经营类别 | 终止经营损益（单独列示，不与持续经营混同） |

> 前四类合起来是"持续经营损益"，第五类单独列示。

## 二、新版利润表的骨架（合计/总计项目）

这是新利润表最重要的结构性变化，新增了三个中间合计项：

```
一、经营利润                      ← 经营类别损益合计（新增）
二、经营及投资利润                ← 经营 + 投资类别合计（新增）
     其中：经营利润及以权益法核算的投资产生的收益
三、持续经营利润                  ← 经营 + 投资 + 筹资合计，扣除所得税前（新增）
四、利润总额                      ← 持续经营利润 + 终止经营利润
五、净利润                        ← 利润总额 - 所得税费用
六、其他综合收益的税后净额
      (一) 不能重分类进损益的其他综合收益
      (二) 将重分类进损益的其他综合收益
七、综合收益总额                  ← 净利润 + 其他综合收益税后净额
```

合并利润表下，净利润和综合收益总额还需再分列"归属于母公司"与"归属于少数股东"。

## 三、利润表至少应列示的项目（第三十四条）

经营收入、经营成本、税金及附加、销售费用、管理费用、研发费用、信用减值损失、资产减值损失、非流动资产处置损益、投资收益、利息收入、利息费用、所得税费用、终止经营利润、其他综合收益各项目扣除所得税影响后的净额。

## 四、其他配套变化

- **管理层业绩指标披露**：企业若在报表外公开资料中使用了非准则要求的损益合计项目（如"调整后EBITDA"），须在附注单独披露其内涵和计算方法。
- **汇总与分解原则**：具有共同特征的项目汇总列报、不同特征的项目分解列报，不得因归集方式模糊重要信息。
- **"重要性"定义修订**：新增"模糊处理"情形——信息虽在报表中，但呈现方式不当、难以被使用者获取理解，视同省略或错报。

## 五、实施时间表（重要，还没全面生效）

| 企业类型 | 开始执行时间 |
|---|---|
| 境内外同时上市 / 境外上市并用准则编报 | 2027-01-01 |
| 其他境内上市企业 | 2029-01-01 |
| 执行企业会计准则的非上市企业 | 2030-01-01 |

允许企业提前执行；执行后即废止财会〔2014〕7号旧列报准则。
