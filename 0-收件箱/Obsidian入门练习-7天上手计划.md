# Obsidian 入门练习 · 7 天上手计划

> 目的：把"会用 Obsidian"从看视频变成**每天的动作习惯**。
> 核心一句话：文件夹管"存哪"，`[[wikilink]]` 管"想到哪"，MOC 管"看到全貌"。
> 配套资源：[[Obsidian学习资源索引]] · 周回顾用 [[周回顾模板]]

## 每日固定动作（5 步闭环，约 10 分钟）

- [ ] ① 捕获：新看到的文章/PDF/片段随手丢进 `0-收件箱`，**不当场整理**
- [ ] ② 加工：写一条原子笔记（一个笔记只讲一件事），打 `tags`，加 **至少 2 个 `[[wikilink]]`** 指向已有笔记
- [ ] ③ 归位：把加工完的笔记移到 `2-知识库` 对应区（按 PARA+JD 编号）
- [ ] ④ 连图：顺手更新相关 MOC / 给被链接笔记加反向链接
- [ ] ⑤ 回顾：用 [[周回顾模板]] 复习 14 天未动的旧笔记（系统会推，也可手动）

> 关键两步：**② 加链接**（决定库长不长得起来）+ **⑤ 周回顾**（决定记不记得住）。

## 分阶段练习

### Day 1 — 看视频 + 建第一个 MOC
- [ ] 看 🟢 必看第 1 条：WorkBuddy + Obsidian 搭建个人知识库（对照自己的 staging 管道）
- [ ] 挑一个已有主题（如"贸易真实性"），新建 MOC 笔记，用 `[[ ]]` 把相关笔记聚起来
- [ ] 跑一次 Dataview，确认 MOC 能自动聚合下属笔记

### Day 2–4 — 每天"加链接"刻意练习
- [ ] Day 2：捕获 1 条，强制加 ≥2 个 `[[wikilink]]`
- [ ] Day 3：同上，并尝试跨主题链接（如一条笔记同时连"审计程序"和"企业财务规范"）
- [ ] Day 4：复盘前两天笔记，补上遗漏的反向链接

### Day 5 — 第一次正式周回顾
- [ ] 用 [[周回顾模板]] 清空 `0-收件箱`
- [ ] 复习并标记旧笔记，把"待处理"改为"可用"

### 本周补强（图上蓝带还没接上的两块）
- [ ] 看 🟢 第 3/4 条：做**整库多端同步**（Obsync 只管微信，vault 本身靠 Syncthing / 国家队云盘）
- [ ] 看 🟡 第 6 条：做 **Git 备份**（vault 只在 D 盘，无版本历史 = 单点风险）

## 验收标准（怎么算"学会了"）
- [ ] 收件箱长期保持接近空（东西都流转到了 2-知识库）
- [ ] 任意一篇笔记能从一个 MOC 被找到，且至少被 1 个其他笔记反向链接
- [ ] 不用翻文件夹，靠搜索 + 图谱就能定位旧知识
- [ ] Git 仓库有提交记录、手机/其他电脑能打开同一个库
