# 审迹知识库 — 每日使用指南

> 每天最多 10 分钟。三件事：捕获 → 学习 → 复习。

---

## 早上：打开 Obsidian（1 分钟）

1. 打开 Obsidian，自动进入今天的 Daily Note
2. 快速扫一眼「系统推送」那篇需要复习的笔记
3. 设置一个心理锚点：今天要学一条什么？

---

## 白天：随手记（30 秒 × N 次）

遇到任何东西，不要犹豫分类，先记下来：

| 场景 | 记在哪 | 怎么写 |
|------|--------|--------|
| 客户给的资料里有异常 | Daily Note「新发现」 | `[[某科目]] 发现 XX 问题 → 待追加程序` |
| 看到同事发的处罚案例 | Daily Note「案例」 | `[[某案例名]] 涉及存货/收入，回头细看` |
| 准则判断不确定 | Daily Note「风险点」 | `[[CAS-14]] 这个交易是总额法还是净额法？` |
| 税务局新通知 | Daily Note「法规」 | `增值税留抵退税新规 → 待整理到 [[2-知识库/税法]]` |

> 不用写成完整的笔记。就一句话 + 一个双链，周末再原子化。

---

## 下班前：每日进步（4 分钟）

打开 Daily Note，找到「每日进步」区域：

```
### 今日新知
- [ ] 一条准则/税法条文：[[...]]       ← 翻一张每日税务知识卡
- [ ] 一句自己的理解：                  ← 用自己的话写一行

### 今日复习（系统推送）
← 这里 Dataview 自动显示了最久没看的一篇笔记
- [ ] 已复习：[[...]]                  ← 打开读一遍，勾掉
```

**具体操作**：

1. 打开 `[[每日税务知识卡]]`——今天是第几天就翻第几条
   比如第 1 天："增值税三档税率分别是多少？"
   答不出来？点进 `[[2026增值税法-核心变化]]` 看答案
   
2. 在「一句自己的理解」写一行，比如：
   "快递按 6% 是因为收派是主要业务，运输是附带的"

3. 看系统推送的那篇复习笔记——花 1 分钟重温

4. 勾掉三个 checkbox

5. 把 YAML 里的 `learned: false` 改成 `true`

---

## 周末：整理（20 分钟）

1. 打开 `[[3-知识地图/学习仪表盘]]`——看 Streak 连续了多少天
2. 把本周 Daily Notes 里值得保留的条目拆成原子笔记 → `2-知识库/`
3. 用 `4-模板/` 里的模板创建——会自动带上完整的 frontmatter
4. 清理 `0-收件箱/`（如果有的话）

---

## 月底：回顾（30 分钟）

1. 打开 `[[3-知识地图/学习仪表盘]]`
2. 检查「知识盲区」——链接少于 2 条的孤立笔记 + 没有案例的准则
3. 补链接、补案例
4. 看一眼「知识库成长」表格——哪个知识域缺口最大

---

## 关键原则

| 做 | 不做 |
|----|-----|
| 每天 5 分钟写一句话 | 等"有时间了"再一起整理 |
| 先记下再分类 | 纠结该放哪个文件夹 |
| 用双链 `[[...]]` 随手连 | 写长篇大论才肯保存 |
| 周末花 20 分钟原子化 | 每天都整理（会累） |
| Strak 断了无所谓，第二天继续 | 断了就放弃 |

---

## 第一天就开始

现在就打开今天的 Daily Note：
1. 翻到 `[[每日税务知识卡]]` 第 1 条——增值税三档税率
2. 写一句你的理解
3. 系统推送那篇复习笔记（应该是你最久没看的）
4. 把 `learned: false` 改成 `true`
5. 去 `[[3-知识地图/学习仪表盘]]` 看 Streak 变成 **1**
