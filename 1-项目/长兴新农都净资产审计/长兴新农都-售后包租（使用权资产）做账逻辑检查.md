# 长兴新农都——售后包租（使用权资产）做账逻辑检查

> 针对「溢价售房 + 5 年返租」模式的会计处理复核。**事实来自** [[吴倍访谈-六项事项事实描述]] 事项四、事项六及凭证检查，**测算为按披露数据的重算，须与底稿核对**。

---

## 一、交易结构（已知事实）

| 要素 | 内容 |
|---|---|
| 对手方 | 村集体经济组织（非普通投资者） |
| 售价 | **12,500 元/㎡**（企业称溢价） |
| 返租 | 5 年，累计返租达房价 **40%**（年约 8%） |
| 商业目的 | 满足村集体经营性收入考核（"买房→收租→变经营收入"，另有政府补贴 60%） |
| 规模 | 返租合同约 **600 多套**（另 100 多套客户自营） |
| 到期安排 | 首批 5 年返租 **2027-2028 到期交房，不再续约** |
| 使用权资产 | 原值 **96,625,670.04**（企业底稿折现合计） |
| 折现率 | **4.65%**（依据"最早 5 年期利率"；现 LPR 约 3.5%） |

---

## 二、三层检查逻辑

### 第 1 层｜定性：这到底是不是"销售 + 租回"？

溢价 + 高回报返租 + 定期交房的组合，需先排除**形式重于实质**：

| 可能定性 | 适用条件 | 会计结果 |
|---|---|---|
| (a) 真实销售 + 真实租回 | 售价公允、租金公允、两交易独立 | 终止确认投资性房地产、确认收入；租回确认使用权资产 + 租赁负债 |
| (b) 溢价实为租金对价 | 售价显著高于市场价 | 售价拆分，**超出公允价值部分不作收入**，作租赁负债抵减或递延 |
| (c) 不构成销售（融资安排） | 保留与所有权相关的几乎全部风险报酬（如保底回购、到期交房承诺） | **不终止确认**投资性房地产，收款确认为金融负债 |

**检查动作**：
1. 取同期同区域可比成交价，算 12,500 元/㎡ 的**溢价率**；取同期市场租金回报率，与 **8%** 对比——若市场回报率远低于 8%，说明"租金"中实质含房价返还，倾向 (b)/(c)
2. 检查销售合同与返租合同是否**同一份协议或同时谈判签订**（一揽子交易）
3. 排查是否存在**回购承诺 / 保底收益 / 到期交房保证**——若有，直接冲击"控制权转移"（CAS 14 第 5 步）

> ⚠️ 售后包租类安排在房地产市场监管中属重点整治领域，**合规性披露**需同步评估（具体监管文号待核实）。

### 第 2 层｜计量：使用权资产与租赁负债

**① 折现口径错误（单利 vs 复利）——已量化**

- 企业底稿：398 份老合同按**单利**折现、新增合同按复利
- CAS 21 要求按**实际利率法（复利）**折现；单利折现因子 `1/(1+r×n)` > 复利 `1/(1+r)^n`，**单利会高估 PV**
- 全量复利重算 PV = **94,049,133.80**，低于企业数 **2,576,536.24 元（约 257.7 万）**
- → 使用权资产与租赁负债**同时多计约 257.7 万**，折旧与利息随之多计

**② 折现率选用需复核（方向相反的影响）**

- CAS 21 优先用**租赁内含利率**；无法确定时用**租赁开始日的承租人增量借款利率**
- 企业用"最早 5 年期利率"4.65%，而非各合同起租日的增量借款利率
- 若按现行 LPR（约 3.5%）+ 加点重算，PV 会**上升**——与①的单利修正方向相反，**两项须分别测算，不得相互抵销后净额判断**

**③ 折旧计提方法错误**

- 正确：使用权资产在**租赁期（5 年）内按直线法**折旧 = PV ÷ 5
- 企业：每期按**租金付款金额**同额计提折旧（"折旧 = 计提返租费 = 付款额"）

按披露数据粗略测算（**全量口径，实际须按每份合同起租日与剩余期限逐份重算**）：

```
年金现值系数 (4.65%, 5年) = (1 - 1.0465^-5) / 0.0465 ≈ 4.37125
年付款额  = 96,625,670.04 / 4.37125      ≈ 22,104,813
年直线折旧 = 96,625,670.04 / 5            = 19,325,134
年差异     = 22,104,813 - 19,325,134      ≈ 2,779,679（年多计折旧约 278 万）
```

→ 按付款额计折旧 = 把**利息成分也折了**，5 年累计多计折旧约 1,390 万（未考虑分期起租）。

### 第 3 层｜未确认融资费用：科目错报 + 截止性错报

CAS 21 要求租赁负债按实际利率法摊销，利息计入**财务费用**。企业实际：

| 问题 | 事实 | 影响 |
|---|---|---|
| **科目错报** | 未确认融资费用计入"服务成本"，结转主营业务成本 | 财务费用 vs 营业成本列报错报 → **毛利率、EBITDA、财务费用率等分析指标全部失真** |
| **未按月摊销** | 期初未确认融资费用借方余额 **477.8 万** 未按月摊 | 各期费用期间错配 |
| **年末一次性调整** | 202512 记-0002 一次性转出 **2,336,630.02**（借：服务成本 100 万 + 冲累计折旧 148.5 万 + 冲租赁负债 15.2 万） | 典型**截止性错报**，且一笔分录同时冲三个科目，需核实依据 |

## 三、审计程序清单（可直接执行）

- [ ] 取返租合同台账（600+ 套），字段：合同号 / 起租日 / 面积 / 售价 / 年租金 / 期限 / 折现率 / 折现方式
- [ ] **逐份按复利重算 PV**，汇总后与企业 96,625,670.04 比对，量化差异
- [ ] 折现率复核：取各合同起租日的增量借款利率（同期银行贷款利率或 LPR+加点），做敏感性测算（3.5% / 4.65% 双档）
- [ ] 售价公允性测试：12,500 元/㎡ vs 可比成交价 → 溢价率；年租金 8% vs 市场租金回报率
- [ ] 检查销售与返租是否构成一揽子交易（同一协议 / 同时谈判）
- [ ] 排查回购承诺、保底收益、到期交房保证条款
- [ ] 使用权资产折旧测算：按 PV÷租赁期 直线法 vs 企业实际（=付款额）
- [ ] 未确认融资费用：按实际利率法编制**月度摊销表**，比对入账科目与期间
- [ ] 核实村集体"政府补贴 60%"的书面依据（访谈陈述，需取证）
- [ ] 复核 202512 记-0002 的调整依据与 supporting
