# 土地增值税测算模型（长兴新农都 一二期）

> **用途**：为 `土地增值税测算模型_一二期.xlsx` 提供口径与公式骨架。**不替代底稿数字**，所有输入须由项目取数回填。
> 定性依据：[[土增税处置备忘-非房开旧房口径与收购窗口方案]]、[[浙江省土地增值税补充通知-95浙地税三38号]]、[[土地增值税征管口径-2026年第3号公告]]

---

## 一、测算前提（先定性，后计算）

| 前提 | 结论 | 依据 |
|---|---|---|
| 纳税人性质 | **非房地产开发企业** | 项目事实 |
| 加计扣除 | ❌ **不得加计 20%**（该优惠仅房开企业开发新房适用） | 用户既有结论，2026年第3号公告未改变 |
| 新旧房分档 | 一二期 **2017 年建成**；浙江口径"连续使用 1 年以上**或**未使用 3 年以上 → 视作旧房" | 浙地税三38号**第五条（仍有效）** |
| → 分档结果 | **2017-2019 年销售且未使用的批次 = 新建房**（可据实扣开发成本）；**2020 年起销售批次 = 旧房** | 第五条 + 备忘结论 1 |
| 预缴依据 | 已按收入 3% 预缴；依据**不是**浙地税三38号第六条（预征部分已废止），而是**《实施细则》财法字〔1995〕6号第十六条** | 浙江省补充通知效力核实 |

> ⚠️ **必须按销售批次分档测算**，不能全项目一个口径——这是模型最大的敏感度来源。

## 二、扣除项目构成（按批次分档）

### A. 新建房批次（2017-2019 销售且未使用）

| 项目 | 内容 |
|---|---|
| 取得土地使用权所支付的金额 | 地价款 + 契税等 |
| 房地产开发成本 | 土地征用及拆迁补偿费、前期工程费、建筑安装工程费、基础设施费、公共配套设施费、开发间接费用 |
| 房地产开发费用 | 利息（据实或按地价+开发成本之和的 5% 以内）＋其他（按 5% 以内/10% 以内） |
| 与转让房地产有关的税金 | 城建税、教育费附加、**地方教育附加**、**印花税**（2026年第3号公告明确可扣） |
| ~~加计 20% 扣除~~ | ❌ 非房开不适用 |
| 浙江额外扣除 | 粮食附加税、粮食补偿金、水利建设专项资金（浙地税三38号第十一条，**部分废止，待核实**） |

> 增值税为价外税，**不计入**扣除项目。

### B. 旧房批次（2020 年起销售 / 已使用满 1 年）——三选一

| 方法 | 扣除项目 | 新农都适用性 |
|---|---|---|
| ① **评估价法** | 评估价格（重置成本 × 成新度折扣）+ 取得土地使用权支付的金额 + 转让税金 | ✅ **主路径**（自建房无购房发票） |
| ② 发票法 | 购房发票金额 ×（1 + 5% × 持有年数）+ 转让税金（财税〔2006〕21号） | ❌ 自建房无购房发票 |
| ③ 核定征收 | 无评估价**且**无发票时，依财税〔2006〕21号 + 征管法 35 条 | ⚠️ 前提不成立（可取得评估价） |

- 自建房可参考"**建造价格 + 地价款**核定扣除基数"口径（深圳规程第38条）
- 访谈披露：**三期采用重置成本法清算**，且"重置成本较高、扣除多、可少缴税，但存在后续稽查风险"——**一二期是否可采用同一口径需与主管税局确认**

## 三、税率表（四级超率累进）

设 `R = 增值额 ÷ 扣除项目金额`

| R | 税率 | 速算扣除率 |
|---|---|---|
| ≤ 50% | 30% | 0% |
| > 50% ~ 100% | 40% | 5% |
| > 100% ~ 200% | 50% | 15% |
| > 200% | 60% | 35% |

**免税**：普通标准住宅，增值额未超过扣除项目金额 **20%** 的免征（条例第8条）。住宅部分需先按现行口径确认是否属普通标准住宅（浙地税三38号第二条已废止）。

## 四、Excel 公式骨架（公式驱动，不贴死值）

```
【每批次一行】
B 转让收入(不含税)     = 含税收入 ÷ (1 + 增值税税率或征收率)
C 批次定性             = "新建房" / "旧房"        ← 按销售年份与使用情况判定
D 扣除-地价款          = 取数
E 扣除-开发成本/评估价  = 新建房:开发成本；旧房:重置成本×成新度   ← 仅取其一
F 扣除-开发费用        = 利息 + MAX(0, MIN((D+E)×5%, 实际其他费用))
G 扣除-转让税金        = 城建税+教育费附加+地方教育附加+印花税(+浙江三项)
H 扣除项目合计         = D + E + F + G
I 增值额               = B - H
J 增值率 R             = I ÷ H
K 适用税率             = IF(J<=0.5,0.30, IF(J<=1,0.40, IF(J<=2,0.50,0.60)))
L 速算扣除率           = IF(J<=0.5,0,    IF(J<=1,0.05, IF(J<=2,0.15,0.35)))
M 应纳土增税           = IF(J<0,0, I*K - H*L)
N 普通住宅免税调整      = IF(AND(普通标准住宅, J<=0.2), -M, 0)
O 应纳(调整后)         = M + N

【汇总】
P 应纳合计             = SUM(O)
Q 已预缴               = 取数（现填 22,220,000，待核实）
R 应补缴               = P - Q
S 滞纳金               = Σ(各笔 R_i × 滞纳天数 × 0.0005)   ← 自纳税义务发生日起算
```

**滞纳金起算**：各笔转让的纳税义务发生时间按浙地税三38号**第十条**（一次性收款=收款当天；分期=本期收款当天或合同约定应收日；预收=收到预收款当天），**自次日起按日万分之五**。

## 五、⚠️ 数据口径矛盾（须先解决，再谈测算）

| 来源 | 日期 | 表述 |
|---|---|---|
| [[吴倍访谈-六项事项事实描述]] 事项三 | 2026-08-06 | 按 3% 预缴 **2,222 万**；非房开口径应纳约 **1.31 亿**；预计补缴约 **1.09 亿** |
| [[土增税处置备忘-非房开旧房口径与收购窗口方案]] | 2026-08-28 | 非房开口径应纳约 **1.31–1.48 亿**；抵减已预缴后**需补提 148,518,486.14** |

**两处需核实**：
1. `148,518,486.14` 是**应纳总额**还是**补缴净额**？
   - 若为应纳总额：补缴 = 1.485 亿 − 0.2222 亿 ≈ **1.263 亿**，与访谈口径 1.09 亿相差约 **1,700 万**
   - 若为补缴净额：则应纳 = 1.485 + 0.2222 = **1.707 亿**，与访谈 1.31 亿差 **4,000 万**，差距更大
2. 1.31 亿 → 1.48 亿的**区间上移原因**是什么（新增批次？扣除口径收紧？滞纳金并入？）

> 在口径澄清前，模型输出的任何"补缴数"都只是**区间估计**，不能直接入账。
