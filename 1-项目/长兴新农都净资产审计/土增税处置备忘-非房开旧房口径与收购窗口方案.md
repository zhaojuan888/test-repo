# 土增税处置备忘——非房开旧房口径与收购窗口方案

> 2026-08-28 咨询结论整理。关联：[[主页]]、[[吴倍访谈-六项事项事实描述]]

## 一、事实链（截至 2026-08-28）

- 长兴新农都：**非房地产开发企业**，自行开发农贸市场＋住宅；
- 一二期 **2017年建成**；转让与过户均在 **2021年前**完成；
- 2017年按浙江文件预征率上限 **3%预缴土增税**（预售阶段）；
- 此后税局**历年口头催缴**（无书面文书），企业因资金困难未结算；
- 基准日 2026-06-30，收购方杭州萧山产业发展集团，净资产收购审计进行中；
- 测算：土增税非房开口径应纳约 **1.31–1.48亿**，抵减已预缴后需补提 **148,518,486.14**（账面无余额）。

## 二、五条核心结论

1. **新旧房定性**：浙江口径（[[浙江省土地增值税补充通知-95浙地税三38号]]第五条）"连续使用一年以上**或**未使用三年以上→视作旧房"；一二期2017年建成→**2020年起无论使用与否全部视作旧房**；已售部分只能按**旧房转让**（评估价法/核定征收），开发成本不能按实际发生额据实扣除→补提只增不减。
2. **预征+结算依据**：同文件第六条允许"预收金额1%-3%内预征"＋"竣工结算后清算、多退少补"，**未限定房开企业**→"非房开无预缴+清算依据"的抗辩**不成立**，税局要求结算有省级文件直接支撑。
3. **非房开无91号文项目清算程序**，但税局可依：省级文件要求结算申报；财税〔2006〕21号＋征管法35条**核定征收**（旧房无评估价无发票）；纳税评估/稽查（参照启东永业机械案：2007年转让2025年追缴）。
4. **追征期**：税局"**年年口头催缴**"＝权利持续主张→**追征期抗辩失效**；口头催缴可构成"通知"，拒不结算→"经通知申报而拒不申报"**偷税定性**（无限期追征＋罚款0.5-5倍）风险高；国税函〔2005〕813号"已申报欠税不受追征期限制"可能被援引。
5. **处置路径**：借**收购窗口主动谈**——核定征收（金额锁定）＋分期缴纳（征管法31条延期，最长3个月/协商分期）；收购协议**原股东兜底**（本金+滞纳金+罚款）＋专项保证金；**收购款支付路径防税局冻结扣划**（共管账户）；依第九条**定期申报通道**规范化。

## 三、会计/审计处理（基准日 2026-06-30）

- 确认**应交税费——土地增值税** 1.48亿（税局已主张、义务明确、金额可可靠估计；已从"预计负债"升级）；
- **滞纳金**自各笔转让纳税义务发生日（95浙地税三38号第十条）起算，日万分之五，需测算并披露敞口；
- **持续经营**：结合收购方注资承诺评估；收购不确定则考虑"与持续经营相关的重大不确定性"段落；
- **披露**：已售未结算、历年口头催缴、存在核定征收及罚款风险。

## 四、法规依据清单

| 文件 | 要点 |
|---|---|
| 《土地增值税暂行条例》第10、12条 | 转让合同签订7日内申报；先税后证 |
| 《实施细则》（财法字〔1995〕6号）第7、16条 | 扣除项目；竣工结算前可预征、结算多退少补 |
| (95)浙国税外127号/(95)浙地税三38号 第5、6、9、10、11条 | 浙江新旧房界定；预征1%-3%+结算；定期申报；纳税义务时间；浙江额外扣除项 |
| 财税字〔1995〕48号 | 新建房/旧房界定原则；旧房评估价扣除 |
| 财税〔2006〕21号 | 旧房发票加计5%/年；无评估价无发票可核定 |
| 国税发〔2009〕91号 | 清算规程（仅房开企业，非房开不适用） |
| 国税函〔2005〕813号 | 已申报/已查处欠税不受追征期限制 |
| 征管法第31、32、35、52条＋细则83条 | 延期缴纳；滞纳金；核定；追征期3/5年/无限期 |
| 国家税务总局公告2026年第3号 | 印花税+地方教育附加纳入扣除（[[土地增值税征管口径-2026年第3号公告]]） |
