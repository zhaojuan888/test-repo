## 2. 对齐（10 分钟）

```dataview
FROM "1-项目"
```

### 逾期未完成

```dataview
TASK
FROM "1-项目" OR "6-每日笔记"
WHERE !completed AND due AND due < date(today)
SORT due ASC
```

### 停滞项目检测

```dataview
FROM "1-项目"

```

## 3. 知识（10 分钟）

### 本周新增笔记

```dataview
TABLE type AS "类型", category AS "分类", file.cday AS "创建日期"
FROM "2-知识库"
WHERE file.cday >= date(<% tp.date.now("YYYY-MM-DD", -7) %>)
SORT file.cday DESC
```

### 新笔记链接检查

```dataview
LIST
FROM "2-知识库"
WHERE file.cday >= date(<% tp.date.now("YYYY-MM-DD", -7) %>)
  AND length(file.outlinks) < 2
```

### 孤儿笔记（长期无链接）

```dataview
LIST
FROM "2-知识库"
WHERE length(file.inlinks) = 0 AND length(file.outlinks) = 0
  AND file.ctime < date(<% tp.date.now("YYYY-MM-DD", -30) %>)
SORT file.ctime ASC
LIMIT 5
```
