# 税务专题笔记模板（tax_clause）

> 用于新增税种 / 税收政策笔记。统一 frontmatter，便于「税法政策月度复核」自动化识别有效期、清理失效项。

## 字段规范

| 字段 | 取值 | 说明 |
|------|------|------|
| type | `tax_clause` | 税种 / 税收政策笔记固定值 |
| category | `[税务, 税种名]` | 受控词表 |
| tax_type | 税种名 | 便于 Dataview 聚合 |
| regulation | `"《…》(施行日期)"` | 主要法律依据（含冒号/特殊符的值用双引号包裹）|
| source | 公告 / 文件号 | 政策出处 |
| tags | `[…]` | 受控词表标签 |
| status | effective / pending / draft / sunset / expired | 有效期状态 |
| effective_date | YYYY-MM-DD | 施行日 |
| expiry_date | YYYY-MM-DD 或 `""` | 失效日，空 = 长期有效 |
| updated | YYYY-MM-DD | 末次复核 |

## 正文结构（建议）

1. **法规依据引用块**（`>` 行）：法规名称、发布 / 施行、背景
2. **核心要素表**：纳税人 / 征税对象 / 税率 / 计税依据
3. **主要优惠**：含 sunset 项须标注截止日
4. **审计 / 尽调关注点**：风险点 + 程序（可列表）
5. **关联**：wikilink 到相关税种、项目、审计程序

> 原则：只描述**现行有效**政策，已废止 / 到期 / 被取代的不收；税率速查优先用 CCTAA 智能图表「税率查询工具（Tax Rates Tracker）」。
