# <主题> — 企业财务规范

> **视角说明**：本笔记从**企业财务自身**角度，回答"我作为企业财务应如何把账做对、把内控建好、把流程跑顺"，与审计笔记（"怎么查你 / 哪里会出错"）互为镜像。

## 一、为什么要规范（动因）
- 合规动因（准则 / 税法 / 内控规范强制要求）
- 风险动因（防止哪类差错 / 舞弊 / 处罚）
- 效率动因（标准化后减少返工、便于系统落地）

## 二、会计政策与核算规范（编制者角度的准则落地）
- 关键会计政策选择（在准则允许范围内如何选定并书面化）
- 具体核算处理要点（科目、时点、计量、列报）
- 会计估计的确定方法与复核机制（如减值、预计负债模型）

## 三、内控与流程标准化
- 不相容职务分离要求
- 审批权限矩阵（金额分级 / 岗位）
- 关键流程 SOP（起止、责任人、单据、系统节点）

## 四、与审计关注点的双向对照

|------------------------|----------------------------|
| <从对应审计笔记摘风险点> | <企业应建立的制度 / 模型 / SOP> |

## 五、落地清单 / 自查表
- [ ] 会计政策是否已书面化并经审批
- [ ] 关键估计模型是否建立且有期末复核痕迹
- [ ] 不相容职务是否实际分离
- [ ] 流程 SOP 是否与系统权限一致
